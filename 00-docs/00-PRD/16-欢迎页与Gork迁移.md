- [已完成] 独立欢迎页默认显示，进入后恢复已有对话；新建对话使用现有工作空间持久化流程。
- [已完成] “下次直接进入工作室”保存到浏览器 `astra.skip-welcome.v1`，可在欢迎页取消；顶栏星光按钮随时重新打开。
- [已完成] 继续卡只读取当前实际对话标题与是否已有工作；返回欢迎页不清空消息、草稿、附件、成果和当前右侧视图。
- [已完成] 复用既有 Gork 原角色 / renderer / catalog，打招呼改变表情与问候，支持暂停、系统减少动效、隐藏 / 离屏停止；离开欢迎页卸载该角色。
- [已完成] 对话顶部保留 Gork；新对话只展示欢迎区域的一个动态化身，不重复显示顶部化身。

## 界面与状态

采用纸白、淡蓝背景、本地苹方、28 / 14 / 13 / 12px 字号层级。亮色默认，深色由用户选择。桌面双列，手机纵向布局并允许整页滚动，不压缩正文。Gork 是同一工作化身，欢迎页不添加另一个助手身份。

工作室在欢迎页出现时保持挂载，但整个容器 `hidden`，不可见画布由现有可见性观察停止。欢迎页离开后卸载。Ctrl / Cmd + K 在欢迎页不打开隐藏的工作室对话框。进入后焦点交还输入框；当前成果全屏时交给可见顶栏入口。

这是浏览器内个人界面偏好，不写入冻结引擎的项目默认配置，不影响其他用户或原项目。偏好写入失败会提示。工作空间载入错误时仍可进入查看恢复提示，而不把用户困在欢迎页。
