## 尺寸与字体

- 1440×900：双栏工作区、首页、深色和浅色复核均截图检查。
- 1366×768：双栏及输入区在视口内，整页宽度等于 1366。
- 768×1024：成果区覆盖式展开，关闭回到对话；整页宽度等于 768。
- 390×844：成果区与对话分别可用；整页宽度等于 390，表格在 380px 局部容器内横滚 610px 内容。
- 运行态核对苹方字体：正文 14px，面板标题 16px，任务标题 20px，按钮 / 下拉 / 表格 13px，辅助文字 12px；导航会话字号已收口至 13px。扫描未发现可见业务文字小于 12px。
- 截图位于本项目 `Codex-Temp/acceptance/`，含首页、工作区、浅色复核、窄屏表格和旋转星图。`font-evidence.json` 保存主体字体证据；导航字号修正后另经浏览器读回为 13px。
