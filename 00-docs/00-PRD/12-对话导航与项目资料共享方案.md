# 对话导航与项目资料共享方案

日期：2026-10-06。状态：产品方向已确认；下述导航与数据能力待实施，当前软件仍为 v0.2.2。

## 已确认的四项决定

1. 对话优先。打开即可与智算工作，不强制先创建工程项目；相关对话可归入项目。
2. 用户始终面对同一个智算，由 Gork 陪伴。专业能力在任务中调用，不要求先选择或切换智能体。
3. 同一项目内的对话共用项目资料与背景。
4. 左侧保留独立“资料库”入口，可直接查找和维护知识、经验、规则与模板。

原功能全部保留、Astra 与原工程隔离、亮色默认、优雅规范 UI、对话卡片、右侧专业成果与临时全屏继续适用。

## 菜单结构

```text
智算 Astra · Gork                  [收起]

＋ 新对话
⌕ 搜索对话

项目                              [＋]
  ▸ 某某管道工程
  ▸ 另一项工程

最近对话
  勘察测量控制价编制
  核对结算资料
  ……

资料库
设置
个人信息
```

“某某工程”等名称仅说明结构，不在正式界面预置假项目或假对话。空状态提供真实创建入口，不显示虚构数量。

### 每个入口只承担一种职责

| 入口 | 用户目的 | 打开后的行为 |
| --- | --- | --- |
| 新对话 | 开始一件新工作 | 进入空白智算对话，输入区就绪；可以不关联项目 |
| 搜索对话 | 找回以前聊过、做过的事情 | 搜索真实保存的对话标题与正文；可按项目缩小范围；打开后恢复该会话 |
| 项目 | 按实际工程组织相关工作 | 展开项目内对话；可进入项目资料与项目背景、新建项目内对话 |
| 最近对话 | 继续最近开展的工作 | 按最近活动展示对话，同一对话只是一条记录，可带简短项目归属 |
| 资料库 | 管理可复用的专业资料 | 进入公共资料与项目资料的管理视图；保留直接查找、导入和维护能力 |
| 设置 | 调整工作室偏好与运行配置 | 主题等通用设置集中管理；工具专属设置在对应工具内 |

项目区与最近对话是同一条对话的不同查找方式，不复制会话或成果。默认新对话为独立对话；从项目的“新对话”入口创建时明确带入该项目，输入区可见项目归属，避免静默沿用上一次项目。

点击项目的展开箭头展开对话；项目名称进入该项目概览，展示项目背景、共享资料和相关对话。切换时保留当前草稿和未完成状态。

## 左、中、右三个区域的职责

- 左侧：选择正在处理的哪段对话、哪个工程项目；寻找资料库。
- 中间：始终与智算交谈，Gork 表达真实执行状态；通过卡片确认操作、查看回执、打开成果。
- 右侧：显示当前引用的计算表、报告、风险、来源、项目资料或专业工具；可临时全屏，返回后保留对话与草稿。

页眉使用真实对话标题或“新对话”，不能把所有对话统一写死成“最高投标限价编制”。专业任务名称在对应任务卡中显示。

Gork 是统一身份。勘察测量、结算审核、知识查询等是智算可调用的能力；未来扩展其他专业时复用能力注册与成果呈现，不再给用户增加一排助手身份。

## 旧菜单的去向

| 当前入口 | 调整后的去向 | 保留要求 |
| --- | --- | --- |
| 新建任务 | 新对话 | 对话可包含多个业务动作，不等于立即启动一次计算 |
| 智能体工作室 | 不再作为重复一级菜单 | 品牌入口可回到对话工作区，切换视图不重置正在处理的对话 |
| 我的任务、最近任务 | 最近对话、搜索对话及项目内对话 | 业务运行挂在所属对话中；历史成果仍能查找、恢复 |
| 造价工程师 / 智能体选择卡 | 统一的 Gork 与智算身份 | 专业能力选择移至输入区，不再用打开设置的按钮冒充切换助手 |
| 专业能力与工具 | 输入框旁的“工具”入口 | 保留完整能力目录、真实已接通状态及工具直接操作 |
| 任务轨迹与依据 | 当前对话的任务卡 / 更多操作、右侧详情 | 按真实业务任务与运行版本展示，不放成跨任务的一级页面 |
| 项目星图 | 更多视图中的“能力星图” | 当前是能力关系示意，不能因移入项目而冒充真实项目关系或地理地图 |
| 工作室设置 | 设置 | 保留原有设置，专业参数仍归对应工具 |

原系统的地理地图、完整项目看板和未来真实项目关系图继续保留在功能矩阵中；当前能力星图不能代替它们。移走一级菜单不等于删除功能。

## 共用资料的含义

```text
公共资料库
  标准与知识 / 经验池 / 计价规则 / 模板
                   ↓ 按适用范围引用
工程项目
  项目背景 + 共享资料
       ├─ 对话 A：控制价编制 → 本次输入快照、计算表、报告
       └─ 对话 B：风险复核   → 引用共享资料或已有成果、形成复核记录
```

资料库提供统一管理入口；“公共资料”与“项目资料”在界面中明确区分范围。项目详情里的资料区与资料库里的对应项目区访问同一份记录，不生成两份互不相干的文件。

- 项目资料只在所属项目内共享。对话中可从项目资料选用文件，不必重复上传。
- 上传时明确显示保存范围。项目内上传默认归入该项目资料，独立对话附件默认只属于该对话；文件可以被选入业务任务。
- 项目背景共享；其他对话的完整聊天内容不自动混进当前对话。用户可明确引用别的对话成果。
- 共用资料不等于共用一份正在编辑的计算表。每次正式执行保存所用资料版本与输出副本；人工修改和成果仍归属于具体任务，防止一段对话的修改静默影响另一段。
- 公共知识、经验和计价规则维持原有适用范围、审核与来源约束。项目资料不能未经确认改变基价、系数或正式规则。
- 未来资料更新不回写已完成任务的历史输入；新任务选择新版本，旧成果可追溯。

## 对话、任务、成果分清楚

| 对象 | 含义 | 界面位置 |
| --- | --- | --- |
| 对话 | 用户持续开展一件工作的交流空间，包含消息、附件、草稿与操作卡 | 左侧可查找与恢复，中间持续展示 |
| 业务任务 / 运行 | 对话中发起的真实转换、匹配、预警、复核等业务执行 | 消息卡、任务详情与轨迹 |
| 成果 | 某次运行形成的表格、报告、复核结果及版本 | 卡片入口、右侧成果区 |
| 工程项目 | 多段相关对话的归属与共享资料范围 | 左侧项目分组、项目详情、资料库 |

当前独立宿主的 `/api/astra/runs` 是业务运行列表，不能直接更名为“对话列表”后声称已完成。新导航需要真实会话存储与关联关系。

历史只有成果、没有保存聊天的运行，可按原项目名展示“历史成果”并继续工作，明确缺少原聊天；不得生成伪造的历史消息。后续新对话需要跨刷新恢复正文、卡片、草稿、资料与业务成果关联。

## 实施顺序与验收

以下为实施基线；v0.3.0 已完成本地会话、导航、资料共用与主线回归。模型上下文编排、完整原知识库维护和跨对话成果引用等后续能力仍按功能矩阵推进。

| 顺序 | 工作 | 完成标准 |
| --- | --- | --- |
| 1 | 会话与项目数据基础 | 真正保存会话、项目归属、资料范围、消息 / 卡片 / 草稿及业务运行关联；运行数据保存在 Astra 独立目录 |
| 2 | 重排左栏与当前对话操作 | 新对话、搜索、项目、最近对话、资料库、设置职责清晰；移走的能力仍可从工具 / 当前任务进入；Gork 统一身份 |
| 3 | 项目资料共享与公共资料库入口 | 同项目不同对话可选用同一资料，其他项目不可误取；版本可追溯；每个管理模块如实标记接入状态 |
| 4 | 业务与视觉回归 | 对话切换 / 刷新不丢状态，旧任务与成果可恢复，表格面积与全屏行为保持，V3.1 流程与隔离通过 |

重点场景：独立临时咨询；同项目中编制与复核两段对话；从资料库直接维护资料；搜索并恢复旧会话；处理旧成果但不伪造旧聊天；切换项目时防止错用文件；资料更新后旧成果仍能解释来源。

界面仍遵守 28 / 20 / 16 / 14 / 13 / 12px 字号、亮色默认、菜单可收起、窄屏可用、键盘操作、状态反馈与 Gork 动效生命周期。以实际功能完成与浏览器证据验收，不能只凭菜单截图完成核销。


## v0.3.0 实施边界

对话、项目、资料已独立持久化；独立对话可归入项目（附件随之共享），已有项目的对话暂不跨项目搬移。资料库支持不可变版本上传 / 查找 / 下载 / XLSX 选用，不自动加入检索索引。旧业务运行保留真实恢复说明，不补造历史聊天。项目背景可共同查看与维护，当前没有宣称已加入未接通的大模型推理。
