# 项目看板迁移与验收

版本：v0.5.0；日期：2026-10-06。

## 范围与来源

按用户“项目看板也要接入”的要求，复用原 `frontend/src/components/project-dashboard/` 九个文件、项目版本趋势及所需图表基础组件。Recharts 固定为与原项目相同的 3.10.0。来源、原始 SHA256 与 Astra 适配后 SHA256 记录于 `17-项目看板来源.json`。

业务聚合继续使用冻结引擎的 ProjectLedger / project_dashboard；只新增 Astra 路由适配。没有改动价格、系数、规则、Excel / Word 生成或原项目代码。

## 已接通需求

- [已完成] 五项 KPI：累计、本月新增、已完成、待复核、存在高风险；保留预警未运行提醒。
- [已完成] 新增 / 完成趋势、项目状态分布、风险排行、匹配质量、模型调用趋势与模型分布、五阶段处理漏斗、原条件来源分布；无数据时显示原因，版本不足不画假趋势。
- [已完成] 时间与上一周期对比、专业能力、状态、来源、风险、质量、名称 / 编号搜索、图表及漏斗阶段下钻。应用 / 取消、筛选标签清除、分页与排序保持同一过滤口径。
- [已完成] 历史项目详情、处理版本、关联业务任务、协同摘要、成果可用性及实际 Excel / Word 下载。
- [已完成] 从运行继续对话、打开计算表、查看 Word；只按真实 job 关联已存对话，没有旧聊天记录时明示恢复提示。保留待重算标志。
- [已完成] 左栏“项目”旁的看板入口、专业工具入口、任务协作模式对话入口；右侧成果区 / 全屏 / 汇报模式，五秒延迟预加载、筛选状态保留。
- [已完成] Astra 工作区历史回填与最近 60 次运行列表，旧记录不按同名文件自动拼成项目。
- [已完成] 苹方字体、语义 token、亮暗模式、图例尺寸、窄屏内部滚动、原生弹窗焦点和 Escape 分层退出。汇报模式暂停后台 Gork 动画。

## 接口与数据边界

沿用 `/api/projects/dashboard`、`/api/projects`、项目详情 / runs / tasks / artifacts / artifact download。新增的 `POST /api/projects/backfill` 只扫描 Astra runtime；`GET /api/projects/{project_id}/runs/{run_id}/result` 在核对真实项目归属后调用 Astra restore，保留 `astra-edit-state.json` 的待重算状态。

- 左栏对话项目是资料与会话分组，业务看板项目是原引擎的稳定业务 ID，两者不按名称强行合并。
- 原聚合字段 `total_runs` 是筛选后的最新任务摘要数，界面明确为“最新任务摘要”；完整版本数量见项目详情。回填回执中的运行数来自完整台账计数。
- 来源分布沿用原组件条件，仅有一个实际来源时不生成冗余来源图。
- 模型调用图表只统计本工作区原引擎审计和本工作区历史提示词记录，暂不含 WeKnora 旁路问答。未配置模型时如实为空。
- 不接入原项目的运行台账、外部协同库、账号或密钥。知识问答、协同派发、地图等未完成项不因本轮看板上线变成“全量已迁移”。
