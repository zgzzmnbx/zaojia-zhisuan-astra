# 智算Astra 产品总览

版本：v0.2.0。当前阶段：独立机械编制主线，完整功能迁移进行中。

## 产品目标

把造价智算现有专业能力重新组织成对话驱动的智能体工作室。用户说目标、附资料，系统展示可核验的计划与动作，复杂专业信息在右侧展开；整个过程保留同一项目、任务、运行、工作表、业务行和成果版本。

## 已确认要求

1. 现有功能一个不少。界面简化不能成为删除业务能力的理由。
2. 全部工作在用户指定的独立目录进行，原项目和运行数据不变。
3. 审美完全重构，优雅、美观、规范、现代；默认亮色、对话主导，左侧对话、右侧专业信息。
4. 使用 daisyUI + Tailwind，借鉴 assistant-ui、CopilotKit、Open Canvas 的结构与交互。
5. 可使用成熟 GitHub 3D 项目，不重复造引擎。3D 服务于项目、任务、知识和成果关系。
6. 面向其他专业智能体扩展；造价是首个专业适配，不能把造价特定字段散落到通用外壳中。
7. Gork 小黑人作为智算化身，来自指定 Gork 工程，不丢失或随意替换。

## 交互结构

- 项目导航：项目 / 会话 / 专业能力 / 知识，不以十几个专业模块挤占主要视野。
- 左对话：输入、附件、专业能力、模式、工具执行、人工确认、结果回执与来源引用。
- 右成果：计算表、复核、报告、依据；其他工具按需展开。支持收起与临时全屏，返回时保留对话与草稿。
- 完整能力目录：保留旧模块所有操作入口，按任务语义整理。
- Gork：欢迎与最新助手消息使用原角色。后续真实事件分别驱动处理、疑惑、确认、完成；不得用时间动画伪造成功。
- 星图：任务与依赖关系的空间化视图，普通按钮可完成相同导航；示例关系不称为数字孪生。

## 业务边界

价格、双系数、预警和报告继续遵守原系统专业规则；AI 只在获批边界内提出建议。机械模式独立离线，三字段分别确认，取消后晚到结果不得覆盖人工修改。知识问答不反向裁决数字。协同必须确认受众，送达状态只能来自真实回执。

## 阶段区分

v0.1.0 是固定示例设计基线，保留于 design.html。v0.2.0 建立独立业务环境、React 正式壳与机械编制主线，V3.1 双答案已核对。AI / 知识 / 协同 / 工作量等剩余模块仍待接入；全量功能等价只能在操作级矩阵全部核销后确认。
