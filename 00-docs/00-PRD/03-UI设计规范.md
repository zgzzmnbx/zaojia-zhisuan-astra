# UI 设计规范

## 2026-10-07 交接优先约定

本节覆盖下方历史条目中的旧导航 / 顶部 Gork / 暂停偏好：保留 dot 的 60px 图标栏、纯聊天 / 448px 项目摘要 / 可拖双栏 / 应用内全屏四形态，以及标题内表格、风险、文字报告页签。Gork 在输入区持续播放、不显示暂停按钮，260ms 跟随；不可见和全屏时停算。手机顶部两行排列，保留飞书 / WeAct 实际状态与全部入口。状态检测只读，配置不代表已连接。其余字体、语义色、状态保留和业务门禁继续有效。

独立 Astra 设计方向：默认亮色工作室，以纸白内容、浅灰导航、克制蓝色主操作及少量青绿 / 琥珀状态组织界面；石墨深色作为可选模式。日常表格保持清晰、平面和专业；3D 用于任务关系，不妨碍复核。

- 字体：本地 `Zaojia PingFang SC`，正文 400、强调 500/600、标题 700；数字等宽。
- 字号：页面标题 28px、模块标题 20px、面板标题 16px、正文 14px、控件 / 表格 13px、辅助 12px，统一 `--dws-font-size-*`。
- 桌面：项目导航支持顶栏按钮收起 / 展开；收起后释放的宽度优先给对话，保留右侧成果宽度，折叠偏好保存在 `astra.sidebar-collapsed`。展开时为原导航布局；余下区域左右分配给对话与成果，支持成果放大与收起。Grid/Flex 约束动态高度，输入区固定在当前视口内。
- 窄屏：初次进入与新建任务优先展示聊天，成果按需覆盖在同一任务之上，可随时收起返回对话；项目菜单为可关闭侧栏。不得压小业务文字来掩盖溢出。
- 主操作使用当前主题的深色强调色，文字固定白色；经验提示琥珀，缺失依据红色，确定状态绿色，主题切换不改变含义。
- daisyUI 使用按钮、菜单、聊天、标签、输入、下拉、表格、页签、折叠、模态、步骤、提示等真实组件；Tailwind 构建 CSS。
- Gork 保持原版对话陪伴位置：有消息时常驻对话窗口顶部，不随消息滚动；新对话保留欢迎区的小人。消息头像与执行卡静态显示，只有可见的当前化身运行动画。全屏成果、移出视口或页面隐藏时暂停；默认减少动效时静态显示，用户显式点击播放后仅开启 Gork 动效。
- 3D 星图按用户要求呈现缓慢的银河流动：旋臂、星尘、公转均属于装饰，不能冒充业务流量。提供暂停 / 复位，悬停功能节点时停止公转；隐藏、离屏时暂停，离开销毁；默认遵循系统减少动效，用户可以主动开启并记住选择。保留普通成果入口，WebGL 失败提供降级。
- 正式工作室的数字、任务与成果必须来自当前独立业务；固定设计样例仅留在 design.html，明确标注。能力星图为结构示意，不能伪装成业务测量。

## 持续验收标准

1. 默认亮色；首屏无深色闪烁。主按钮、禁用、悬停、选中、错误状态使用统一语义色，标题 / 正文 / 辅助层级明确。
2. 用户在聊天中完成主要任务；右侧是同一任务的细节视图，可临时全屏并用 Escape 返回。保留消息、草稿与任务上下文。
3. 宽表只在成果内部滚动，禁止把整页撑宽；数字便于扫描，表头可读、完整字段通过 title 或全部列查看。空数据不能伪装成 0。
4. 检查 1440×900、1366×768、768×1024、390×844 的实际浏览器画面；亮色为主、深色复核。不得只以 CSS 源码和构建替代视觉检查。
5. 使用原生按钮、表单、dialog 与清晰的可访问名称；焦点可见、Enter 发送、Shift+Enter 换行、中文输入法组合期间不发送。
6. 每次新增能力一并设计加载、空、失败、未接入、待确认及恢复状态；不以假成功、假进度或占位按钮掩盖实现缺口。

## 表格显示面积

- 顶部将 Sheet 切换与常用操作合并为同一条紧凑工具栏，宽屏用页签，成果区较窄时改用下拉框；不重复显示成果标题，不保留无操作意义的完成按钮或未接入按钮。
- 筛选、搜索、重算和列设置合并；搜索输入框按需展开，保留清晰的名称、悬停提示与键盘操作。
- 预览范围和下载合并到单行底栏，表格滚动区弹性填满剩余高度。普通业务表格保持 13px、辅助 12px，不以压小字号换面积。
- 低频设置放弹窗；保留真实待重算、错误或定位失败提示，不能为面积隐藏关键业务状态。

## 对话中的卡片语言

- 消息由简短解释与结构化卡片组成。确认卡承担下一步决策，结果卡展示实际回执，成果卡打开右侧工作区；简单解释仍可使用正文，不为每句话增加边框。
- 采用统一的标题、状态、内容、动作层级；一张卡以一个主操作为先。资料和依据明细按需展开，低频细节保留右侧。
- 数量、风险、文件入口只来自真实业务响应。卡片保留当次回执快照；运行中只显示不定进度，不能杜撰完成率。
- 操作必须绑定输入会话与任务，历史文件的确认卡不可操作新文件。已完成结构转换 / 匹配的确认按钮锁定，任务恢复保持真实待重算状态。
- 成果卡不在左侧再放大表格；右侧表格沿用紧凑工具栏和原有显示空间。窄屏卡片自然换行，统计随卡片宽度切换列数，成果入口改单列，输入区保持可见。
- 卡片规范属于通用展示层，价格 / 系数与人工审核语义由原业务适配器提供。未来其他智能体可复用卡片模型，不依赖字符串猜测业务结果。

参考来源（2026-10-06 核对）：[assistant-ui 工具渲染](https://www.assistant-ui.com/docs/api-reference/tools/rendering)、[CopilotKit 对话内组件](https://docs.copilotkit.ai/generative-ui/your-components/display-only)、[Open Canvas 成果协作](https://github.com/langchain-ai/open-canvas)。本轮借鉴结构与交互，仍使用本项目 React + daisyUI 实现，未声称集成这些项目的智能体运行时；Open Canvas 仓库已归档，仅作交互参考。


## 导航与知识模块

- 左栏只组织对话、项目和资料；专业工具放输入区，架构图从工具进入。知识库范围与来源详情归右侧，阅读 / 提问仍回到当前对话。
- 原架构图、二维文章网络、能力星图分开命名。图与大表均支持成果区全屏；图形离开后卸载。
- 原组件迁移需补齐 Astra 语义 token 与容器，不仅复制 TSX；检查窄成果区的工具栏、检索栏与关系抽屉是否重叠。
- 保存状态必须可见，失败保留草稿并提供导出；协同的草稿 / 发起 / 送达严格区分，检索摘录不标作模型回答。

## 欢迎页

- 欢迎页沿用纸白、克制蓝色、本地苹方与统一字号；Gork 使用既有 renderer / catalog，保持原角色。展示工作方式，不展示虚构业务统计。
- 主入口进入已恢复的工作室，另提供新对话；继续卡只展示真实当前对话。跳过偏好可撤销，顶栏保留返回欢迎页按钮；往返不卸载工作室状态。
- 欢迎页隐藏工作室画面与交互，离开后卸载欢迎角色；对话空态避免同时显示两个动态 Gork。支持动效暂停、系统减少动效、页面隐藏 / 离屏停算。

## 项目看板

- 右侧承载项目统计与明细，左栏“项目”旁只增加轻量看板入口；不恢复一组全局一级菜单。项目总览与最近运行记录分开，原统计图不可删除或默认折叠。
- 使用原 Recharts 图表、语义颜色、统一字体与响应式容器；业务表头 / 控件 13px、图表标注 / 辅助 12px。保留真实空态，不制造波形或进度。
- 筛选与详情用原生 dialog，支持焦点约束 / Escape / 返回焦点；汇报模式保留筛选、草稿与结果，后台 Gork 暂停动画。
- 图例与图表 SVG 分别设定尺寸。深色用语义表头、网格、轴标签与高对比主按钮；历史宽表在自身区域水平滚动，不挤宽整个页面。

## Gork 动效

- 复用原表情姿态，待机小幅呼吸、间歇张望；输入焦点专注、真实检索 / 处理分开，失败停留疑惑。点击依次招呼 / 眨眼 / 点头 / 害羞，单次约 3 秒，900ms 防连点，不抢工作状态。
- 转换、匹配、人工修改保存成功才显示短暂开心；不以动画计时产生业务成功，不从历史结果重播。
- 小人本身轻微变形，周边布局固定；按钮支持键盘与可见焦点，桌面悬停 / 焦点出现暂停按钮，暂停后保留播放入口，触控常显。
- `astra.gork-motion.v1` 仅存当前浏览器偏好，不写业务默认配置；欢迎页与对话共用。系统减少动效默认静态，主动开启只覆盖 Gork canvas，不放开其他页面动画。

## 专业模块工作区

- 全部工具按四组卡片组织，左栏仍只组织对话 / 项目 / 资料。原复杂表单按需在右侧打开，保留全屏；不再展示第二套导航或动态 Gork。
- 当前附件、工作表与 job 来自同一对话。跨对话更换容器，离开暂停重图形；实际成功回执产生聊天成果卡，失败与未配置提示真实可见。
- 知识回答可整理为候选草稿，保留来源、结论、范围和人工核对；点击按钮不等于批准记忆。双路回答分别展示，停止丢弃晚到结果。
- 专业组件沿用本地苹方、13px 控件、12px 辅助与图表标注；亮暗主题同步，窄屏使用内部滚动和表单换行。懒加载失败保留聊天并提供重新载入。

## 多主题约束

- 默认 Astra 蓝 + 亮色；提供翡翠绿、北境蓝、丝绒紫、秋日铜、石墨灰。颜色和明暗为两个独立维度，浏览器本地持久化，首屏同步。
- `appearance.css` 统一表面、文字、边框、主操作和强调色；daisyUI 语义 token 与原专业组件通过隔离适配映射。主按钮底色与文字强调色分开，深色主题的链接不得直接复用深色按钮底色。
- 切换只改主题属性与 CSS，不重建聊天、Gork 或专业 iframe；保留草稿、滚动、表单和任务上下文。
- 价格、风险、待确认等状态色独立；Word 原稿、地图底图、固定架构图和外部数字化助手文档保持其自身颜色语义。
- 配色卡使用空间微缩预览、名称和选中标识；支持键盘、可见焦点、恢复默认，主题窗口在小屏内滚动。

## Gork 控制台联动卡片

- 通过对话或专业工具进入右侧，不增加一级导航。显示控制台版本、设备连接及来源 / 跟踪状态；未连接、旧版本、暂停、异常明确区分。
- 使用共享主题、本地字体和既有 12—20px 层级；亮暗、窄屏可操作，打开或刷新状态不清除草稿。只读检测不等于代为启用机器人。
