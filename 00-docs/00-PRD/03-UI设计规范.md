# 智算 Astra UI 规范入口

当前设计标准：**[Astra UI 设计标准 1.0.0](../../DESIGN.md)**，2026-10-07。

本文件为项目接入索引。完整配色、字体、间距、布局、daisyUI 组件、卡片、图表渐变、动效、状态、可访问性及跨项目复用方法统一放在根目录 DESIGN.md，本文件不再维护第二套视觉数值。

## 后续开发规则

- 新组件只依据 DESIGN.md 与 daisyUI 设计，不再参考智算 2.0 或其他旧版界面。
- 旧项目仍可核对业务功能、价格规则、数据和操作语义；复用业务不等于复用旧外观。
- 一个窗口一条主标题栏。标题、页签、状态与操作优先合并，必要专业工具最多再占一行，不连续叠多层标题。
- 默认仅设计和验收桌面，除用户明确要求不处理平板 / 手机。
- 优先扩展本项目已有组件，新增样式必须使用统一 token、字号、状态与动效约定。
- 视觉改动同步更新 DESIGN.md；业务范围与验收状态仍记录在当前版本计划和功能保留矩阵。
