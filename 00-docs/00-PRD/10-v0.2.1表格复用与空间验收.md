# v0.2.1 表格复用与显示面积验收

日期：2026-10-05。范围：Astra 前端表格复用、布局与预览设置；独立宿主仍沿用 v0.2.0，业务引擎未改。

## 原表格复用

- 原智算 2.0 使用 React 原生 HTML table，并非 AG Grid / Handsontable / Univer。
- `03-Src/studio/table/legacy-preview.ts` 提取原 App.tsx 的 37 项类型、常量和纯显示函数；只扩大 boolean 单元格类型兼容、移除无用途的外部类型依赖、增加模块导出，不改数字与规则裁决。
- `legacy-source.json` 保留来源文件、SHA256、原声明行号；`legacy-defaults.json` 冻结原项目 previewColumns 默认列、表头、字符数及列宽。原文件 SHA256 复核一致。
- 结构沿用 Sheet 页签、可调整列宽的表头、有限列宽、两行文本、固定右侧行操作；原匹配颜色、预警颜色、两位小数、核心表空量过滤、合计保留与 Excel 行号定位复用。
- 重复表头如两个“小计”使用列索引区分，支持同时显示、分别隐藏；保留原默认标签匹配。
- 预览表头通过现有 `/api/preview/refresh` 重读，不改 Excel 结构。独立本机偏好存 `astra.preview-columns.v1`，不写回原项目配置。存储不可用时保留会话设置并提示。

## 显示面积

- 去掉重复“填价结果预览”标题、大统计区、“已完成匹配”按钮、重复任务编号和底部隔离状态栏。
- 一条工具栏合并统计、空量筛选、搜索、公式重算和列设置；Sheet 页签独立一行，支持触控滚动与方向键 / Home / End。
- 搜索输入框按需展开；低频列设置进入弹窗。关键待重算、错误和定位失败提示保留。
- 底部范围说明与 Excel / Word 下载合并。固定依据列缩至 52px，移除未接入的 AI 按钮；AI 功能仍保留在迁移矩阵。
- 字体仍为自托管苹方：表格 / 按钮 13px、辅助 12px、成果标题 16px；没有通过缩小字号换面积。

最终双栏 / 窄屏结果区的表格滚动区实测（包含表头）：

## 保留边界

- 当前仍是原引擎前 50 行预览，不声称全量 Excel 浏览；完整数据通过 Excel 下载。
- 人工编辑继续使用 Astra 已接通的留痕弹窗，公式、隐藏 / 受保护单元格及系统列由原后端校验。未复制原内联编辑的全部状态机。
- 依据与候选在同一右侧成果区展开，未恢复旧窗口层级；完整 AI 三字段候选确认仍待接入。
- 不改变原项目、不重启其服务、不初始化 Git、不提交或推送。全部改动位于独立 Astra 目录。


## 后续 UI 小修：侧栏收起与两行合并

- 用户新增要求：左侧菜单可收起，把空间让给对话；表格操作栏与 Sheet 页签合为一行。
- 顶栏左侧按钮收起 / 展开菜单，桌面折叠状态记在本浏览器 `astra.sidebar-collapsed`；手机保持抽屉菜单，支持关闭按钮、遮罩、Escape、焦点循环和关闭后焦点归还。
- 收起侧栏不卸载对话与成果。1440 × 900 下，对话宽度从 570.88px 增至 794.90px，右侧成果保持约 627.10px，消息、草稿及当前 Sheet 保持。
- Sheet 页签和筛选 / 搜索 / 重算 / 列设置合为一行。成果容器不超过 1000px 时改为原生工作表下拉框；统计移至底栏。搜索依旧按需展开。
- 同视口表格滚动区从本页前一版的约 573px 增至约 611px；1366 × 768 为 479px，768 × 1024 为 756px，390 × 844 为 578px。四种尺寸整页无横向溢出，工具栏保持单行。
- 13 项既有前端测试与生产构建通过。浏览器核对键盘收起、刷新后折叠偏好、Sheet 下拉 / 页签切换、全屏恢复、对话草稿、手机焦点循环、inert 遮挡及亮暗模式。
- 此项按 UI 小修处理，版本保持 v0.2.1，不改业务代码、不重启后端、不新增存档。README 与 UI 规范已同步。
