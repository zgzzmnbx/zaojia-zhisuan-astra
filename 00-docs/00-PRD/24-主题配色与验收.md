# v0.6.1 主题配色与验收

日期：2026-10-06。范围仅为独立智算 Astra 的外观与偏好，不修改计价、规则、模型、报告内容或原项目。

## 交互与设计

| 配色 | 参考 daisyUI | 方向 |
| --- | --- | --- |
| Astra 蓝 | Corporate | 纸白与克制蓝，默认 |
| 翡翠绿 | Emerald | 自然绿与浅绿色表面 |
| 北境蓝 | Nord | 雾蓝、冷灰 |
| 丝绒紫 | Silk | 柔和绒紫 |
| 秋日铜 | Autumn | 暖纸与铜色 |
| 石墨灰 | Lofi | 低彩度灰阶 |

参考 [daisyUI 主题文档](https://daisyui.com/docs/themes/)，使用现有 daisyUI / Tailwind。六套均为适合专业工作台的调整版，并非原主题色值的完整复制。每套可单独选择亮色 / 深色，共 12 种组合。

- 欢迎页 / 工作室右上角圆形配色按钮、设置中均可选择；微缩空间预览、选中标识、键盘焦点及一键恢复默认。
- 默认 Astra 蓝 + 亮色，不跟随系统自动切暗。`astra.appearance.v1` 只保存外观，刷新前由本地脚本读取；存储受限时本次仍可切换并明示不能保存。
- 主工作区、弹窗、表格、看板、专业 iframe 共享主题。正文 / 辅助 / 主按钮与强调色分开映射；风险 / 价格 / 待确认保持原语义。
- 切换不重建业务组件；欢迎页、对话、Gork 和专业表单继续保留。弹窗 Escape 关闭后焦点返回触发按钮。
- 正式 Word 内容、地图底图、固定架构图、外部数字化助手保留自身颜色，不重新染色业务文档。

## 本轮验证

- `npm test`：43 项通过；`npm run build`：TypeScript 与生产构建通过。保留原有大型地图 / Word chunk 与依赖 `use client` 构建提示，不影响构建成功。
- 浏览器逐一切换 12 组合：父工作区与专业 iframe 的 palette / scheme 一致，主按钮白字和表面色同步；10 条助手消息、当前任务与原草稿保持。
- 专业工作量表单临时取消“委托方备注”勾选，切换颜色及明暗后仍保留；验证后恢复原勾选，未执行工作量写入。
- 真实原表格在 Astra 蓝 / 秋日铜下保持 9 个当前可见行、相同草稿与绿色规则标记，表头表面色随主题变化；没有修改单元格或计算结果。
- 对比度：12 组合主按钮最低 5.20:1；正文 / 辅助 / 强调文字在纸面、画布、侧栏、柔和表面上的最低值 4.50:1。绿色 / 琥珀 / 红色业务状态继续用既有语义。
- 1440×900、1366×768、768×1024、390×844 截图检查：主题卡片清晰、无整页横向溢出；矮屏窗口内部滚动，字号未压小。移动端精简说明而保留六个名称与选择操作。
- 刷新恢复秋日铜深色；恢复默认返回 Astra 蓝亮色。Tab 有可见主题焦点，Escape 关闭并返回“主题配色”按钮。浏览器错误日志为空。
- 5189 独立服务健康 `ok`、版本 `0.6.1`。308 份原 / 冻结业务资产和 107 份原前端来源哈希均无变化。

证据：`Codex-Temp/acceptance/themes-v061/`，包括主题矩阵、对比度、表格状态、隔离记录及四种尺寸截图。浏览器尺寸仿真验证后已清除；页面恢复默认主题。
