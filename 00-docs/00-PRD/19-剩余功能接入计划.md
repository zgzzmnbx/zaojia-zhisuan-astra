# 剩余功能接入计划

最初基线 v0.5.1，2026-10-06；当前核对更新于 2026-10-07（UI v0.6.4）。以下接入分组已在 v0.6.0 落地。后续统一按 [迁移续办与验收待办](26-迁移续办与验收待办.md) 推进，不能将旧“待接入”重复当作未开发。

## 实施口径

保留 Astra 对话主线、原 Gork 和右侧成果区。复用原系统已经验证的专业表单、设置、复核与业务流程，不重新实现计价。新增同源隔离的专业模块层，移除重复的导航、欢迎页、助手栏，统一 Astra 字体、亮暗主题、间距和颜色。表格日常查看仍使用已迁移的紧凑表格，复杂操作按需展开。

专业模块只连接本目录 5189。原文件只读复制并记录来源；不复制运行库、环境文件或密钥。消息通过带当前对话上下文的受控桥接同步，过期结果不覆盖新对话。原工作表和业务规则不因视觉接入改变。

## 接入分组（v0.6.0 已完成界面与接口）

| 分组 | 必须保留的操作 | 验收 |
| --- | --- | --- |
| 工作量 | 双表 inspect、字段偏好、数量过滤、术语归并、双成果、应用到当前表 | 独立样本与下载；当前任务版本保护 |
| 经验池 | inspect、字段映射、指定有效列、导入、阈值和质量 | 仅写 Astra 工作副本，母版只读 |
| 结算 | 原规则卡、样本 / 上传、审核结果、问题定位与双成果 | 原样本实际审核 |
| AI / 行级复核 | 双模式、分析、取消、逐字段确认、候选采纳和留痕 | 机械不变、未确认不可写、取消 / 版本校验 |
| 报告 / 图表 | 原 Word 分页预览、原专业图表与下钻 | 实际报告与空态，不伪造完整结果 |
| 知识记忆 | 候选、编辑、提交、确认、拒绝、撤销、修订、失效、审计、胶囊 | 独立 SQLite 与项目范围 |
| 地图 | 原 L7 地理地图、展示地图、未定位列表、地点证据与确认 | 原实现状态保留，示意与真实分开 |
| Skill / Task | 推荐、只读治理、上岗证据、任务轨迹与血缘 | 原清单 / 快照，禁任意执行资产 |
| 协同 | 配置、通知、目录、派发、复核轮次、评论、回执和重试 | 界面 / 接口与真实外发验收分开 |
| 模型 / 问答 | 原模型通路、WeKnora、双路对比、取消、真实引用 | 独立连接配置；未配置不伪装在线 |
| 完整设置 | 原映射 / 预览 / 报告 / 模型 / 页面 / 通知设置 | 设置范围明确，避免修改正式资产 |
| 数字化助手 | 原独立服务薄容器、加载、超时、重试和独立打开 | 不启动或修改其他项目，联调状态如实标记 |

## 收口

逐项记录 UI、接口、自动回归、浏览器、真实业务五个层次，不以复用源码或有按钮替代验收。外部服务缺少独立配置时先完成可审查的界面与接口；不自动发送消息，也不读取原项目密钥。验证后更新当前计划、迁移矩阵、README、CHANGELOG 与来源清单。

## 2026-10-06 核销结果

上述分组的本地界面、原业务 API 和 Astra 入口均已接入。原运行应用 108 路径 / 118 方法组合没有未挂载项。当前附件、任务恢复与专业成果卡已贯通。

验证：43 项前端、59 项宿主、构建和 V3.1 双答案回归通过；真实工作量 / 经验池 / 记忆治理 / 结算 API 验证，浏览器检查地图、报告、图表、设置与窄屏。

仍待：独立模型与 WeKnora 凭证、真实 AI 增量和双路回答；双平台实际派发与多人回执；数字化助手运行联调；长报告与 Office 分页复验。当前不是“全部业务验收完成”。细节见 `22-v0.6.0迁移验收.md`。
