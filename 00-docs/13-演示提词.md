# 演示提词

演示模式下默认开启，文字位于屏幕右下角，灰色、10px，保留至下一步骤。可在 **设置 → 演示与调试 → 演示提词** 检查开关。

## 编辑正文

正式使用的文件是 `runtime/astra-service/config/astra-demo-cues.md`。每段用 Markdown 二级标题分隔，例如 `## 【P4】`。需按系统页面或操作自动切换的段落沿用 `## 标识 · 标题`，例如 `## workbench · 工作台`。以 UTF-8 保存后约5秒更新。也可在 **演示与调试 → 编辑提词** 选择段落并保存正文。

安装时仅在该文档不存在时放入初稿；程序更新不覆盖已有正文。初稿模板位于 `03-Src/reference-assets/demo-cues.md`，不要误改模板后期待正式页面立即变化。开发目录与正式目录的配置彼此独立。

## 切换方式

欢迎页、系统架构、工作台、字段结构、表格、单行填价、风险、报告、复核、项目看板、知识问答/文章库/图谱及数字化助手有对应页面提示。上传、转换、批量匹配、预警、报告生成、问答完成、发送复核和数字化引导操作也会切换。重新到达同一页面或再次触发入口可再次显示对应段落。

鼠标移到提词上，或用 Tab 聚焦，会出现上一段、段落选择、下一段。它们只切提词，不操作系统。飞书/WeAct外部客户端的查看与审批、外部问答、总结和答辩由演示者手动切段；不根据旧回执假定本轮已完成。

## 初稿与保护

来源为用户指定的《造价智算_总决赛1.0_录音原话与时间轴_41段.docx》第08—41段，共34段；保留讲解原话，删除“听不清”等转写标记及播报故障插句。原始 Word 保持只读。提词是演讲内容，不表示当前任务结果已被再次核验。

每段最多4000字，全文最多128KB。读稿失败时保留上次可用的提词，约5秒重试，编辑窗口会提示原因。首次读取失败且没有缓存时，右下角显示重试状态。并发编辑遇到版本冲突时保留当前草稿，可重新读取后再保存。
