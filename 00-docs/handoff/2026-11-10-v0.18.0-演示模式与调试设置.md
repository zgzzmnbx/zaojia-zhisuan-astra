# 演示模式与调试设置

日期：2026-11-10。UI v0.18.0，宿主 v0.12.0。

## 使用方式

顶栏“返回欢迎页”和亮暗主题按钮之间新增“演示”开关。设置 → 演示与调试集中管理下列选项。

| 选项 | 默认 | 生效范围 |
| --- | --- | --- |
| 演示模式 | 开启 | 总开关；关闭时停用下面三类预设 |
| 单行填价预设 | 开启 | 沿用表2第6行、3203 元/个及已有精确要素匹配条件；不自动确认写入 |
| 风险报告预设 | 开启 | 沿用带【演示】标记的文件触发五万元固定风险正文 |
| 知识问答预设 | 开启 | 沿用固定问题的预设答案及展示等待；关闭后使用正常问答路径和所选引擎 |

首次没有配置文件时全部开启，保持原有演示表现。主动修改后持久保存；重启不重置。顶栏即时保存，设置页调整后点击“保存设置”。总开关关闭不清除分项选择，重新开启恢复之前的分项组合。

配置由本机服务统一维护于业务运行目录 `astra-working-assets/demo-settings.json`；采用版本校验及原子写入。窗口切回和可见页面定期同步，拒绝旧窗口覆盖新设置。保存失败明确显示错误，不冒充已生效；配置损坏时停用预设并提示检查，不静默恢复开启。

设置页另提供运行日志、机器人联动入口。进入调试页面不会自动发消息或触发设备。现有成果、任务、人工写入确认及外发授权不随演示总开关变化。
