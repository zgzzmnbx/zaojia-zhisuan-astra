# 夜览候选 Demo v1.0.0

2026-10-25，正式版本仍为 v0.11.18，未整合候选效果。用户看图确认后再进入正式改造。

入口：[打开独立 Demo](http://127.0.0.1:5189/night-demo/index.html)。源码与复现命令：[Demo README](../../03-Src/studies/night-demo-v1/README.md)。

## 本轮画面

| 区域 | 改善 | 尚存差距 |
| --- | --- | --- |
| 全景 | 大屏顶部和关键节点形成白芯蓝晕；主建筑明暗更易辨认；外围灯光降低密度和亮度 | 仍需用户判断整体是否足够有夜间氛围；大屏亮度可继续收敛 |
| 储罐 | 灯带与灰蓝罐身分离，罐身轮廓更清楚 | 局部烘焙细边仍会被蓝色识别遮罩选中；尚未制作精细灯带遮罩 |
| 管道 | 管道、支撑和地坪的层次更可见，避免整体压黑 | 没有新增真实窗灯反射、投影或水面场景倒影 |

候选使用方向性明暗与小幅立面补光近似，不声称为真实光线追踪。白天、几何、冻结资产和原业务工作台没有合入候选更改。

## 验收

- `npm test`：374/374；V11 专项：50/50；`npm run build`：通过；独立 Demo 构建：通过。
- 浏览器 A/B 同一相机：全景、储罐、管道、大屏四组原始截图，JS/资源错误为 0。
- 日间候选开关前后画布 SHA256 完全一致：`8f2105907993c59ff1d60c07549268990133be6fad605b754d2107408e04fa26`。
- 灯芯滑块确实改变渲染，恢复候选默认有效；所有模式切换不改变相机。
- 浏览器没有业务 API 请求或非 GET 请求，localStorage 前后相同。
- 拖动旋转、暂停、恢复播放、系统减少动效均通过；独立 Chromium 确认 `document.hidden=true` 后帧数保持不变，返回前台恢复。自动化默认焦点模拟会使隐藏状态失真，最终使用无默认覆盖的 CDP 连接复验通过。
- 正式运行目录 492 个既有输出与沙盘源码文件 SHA256 不变，独立目录之外未发布更改。
- 视觉验收待用户确认；测试通过不代表用户认可候选画面。
