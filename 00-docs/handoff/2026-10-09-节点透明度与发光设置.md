# 节点透明度与发光设置

日期：2026-10-09。UI v0.9.45，设计规范 1.0.21。

按用户要求，保留十类低饱和分组颜色，恢复调色前的自发光及光晕，并将节点显示参数交给用户调整。右上角星图设置增加四项滑块：

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 节点不透明度 | 0–100% | 100% |
| 自发光强度 | 0–100% | 22% |
| 光晕强度 | 0–200% | 100% |
| 光晕大小 | 1.0–3.5 倍 | 2.2 倍 |

不透明度越高越实，球体和光晕同步淡入淡出；标签与选中轮廓保留，避免零透明度时无法辨认当前节点。光晕强度按原始基础透明度 0.1、选中 / 悬停 0.18、弱化 0.015 成比例调整。自发光与半径同样平滑过渡，沿用原场景，不重置旋转和光流相位。

继续使用 `astra.knowledge-galaxy-settings.v1` 保存设置；旧偏好缺失的新字段自动补默认值，原有旋转、缩放、节点大小及连线设置保留。恢复默认仍覆盖整套星图设置。

主目录与活动 worktree 各 180 项测试、类型检查及生产构建通过；保留已有大 chunk 提示。浏览器实际加载 v0.9.45，在 1742×956 桌面全屏中验证：

- 新字段默认值与实际 Three 材质一致：球体 1、自发光 0.22、光晕 0.1、相对半径 2.2。
- 不透明度 0% 时球体 / 光晕归零；自发光、光晕强度及大小调至上限时，实际材质分别为 1、0.2、3.5 倍。
- 2D / 3D 切换重新创建星图后保留设置；本地存储包含四个新字段。
- Escape 关闭设置，重新打开正常；滑块键盘操作、面板滚动正常，浏览器错误日志为空。
- 验收后四个新增参数恢复本轮默认值，原有个人设置未重置。截图：`Codex-Temp/galaxy-opacity/final.png`。
