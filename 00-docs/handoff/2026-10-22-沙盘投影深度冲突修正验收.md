# 沙盘投影承影面深度冲突修正验收 · v0.10.78

日期：2026-10-22。任务：旋转沙盘时，左后最高楼投在楼前空地的影子整片一闪一闪；定位原因并修正，保持主光、PCSS、水景与 AO 效果不变。

## 原因

| 项目 | 结果 |
| --- | --- |
| 主因 | 日间投影承影面 `floorShadow`（透明 `ShadowMaterial`）只比地板高 5 mm：`y=-.705`，地板 `y=-.71` |
| 深度精度 | 沙盘相机距离 80–110、近裁面 `.1`、24 位深度；单步精度约 4–8 mm，斜视时视深度差约 2.5 mm，小于 5 mm 间距的两倍，深度比较随视角翻转，整片影子消失 / 重现 |
| 为什么只有该楼 | 只有最高楼的主投影大面积落在这层透明承影面上；其余影子落在不透明 GLB 底板材质，间距足够，未出现冲突 |
| 排除项 | 静态阴影贴图旋转变焦时 `shadowDraws` 不变（`autoUpdate=false`）；PCSS、主光 `38° / 42°`、AO、水景均不参与 |

## 改动

| 文件 | 改动 |
| --- | --- |
| `project-sandbox/scene.mjs` | 承影面抬到 `y=-.69`（离地 20 mm），`ShadowMaterial` 增加 `polygonOffset:true`、`factor:-1`、`units:-4` |
| `project-sandbox/contact-shadows.js` | 接触柔影贴地材质同样加 `polygonOffset`，避免同类深度冲突 |
| 未改动 | 阴影贴图尺寸与视锥、PCSS 采样、主光方向 / 强度、AO、水景、主题与业务状态 |
