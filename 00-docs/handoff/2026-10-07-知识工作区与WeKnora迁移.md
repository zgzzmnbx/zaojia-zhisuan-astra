## 来源与复用方式

- 原系统：`D:\Codex-Temp\260612-【ai大赛】-管勘智算-V2.0`，保持只读。
- WeKnora：`D:\Codex-Temp\260924-【WeKnora】WeKnora知识库`；复用其 Windows 本机 API `http://127.0.0.1:18091`，原文入口 `http://127.0.0.1:18090`，没有启动、修改或迁移其 Docker / 数据库 / VMware 备份。
