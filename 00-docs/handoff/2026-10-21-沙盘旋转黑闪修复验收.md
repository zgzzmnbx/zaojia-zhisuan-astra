# 沙盘旋转黑闪修复验收 · v0.10.70

日期：2026-10-21。范围：选中并放大建筑后，鼠标拖动旋转造成的整幅黑闪。已同步主目录与实际提供 5189 的活动工作区；通过服务端构建清单确认浏览器加载 v0.10.70 及两个光效模块的 SHA256。

## 复现与原因

- 修复前：报告建筑放大后连续拖动旋转，394 个有效画布样本中捕获 10 个整幅变暗样本。不是停用效果后认定修复。
- 光柱直接计算 `pow(1.-vUv.y,2.4)`，边缘插值超过有效范围时可产生无效浮点值，进入 HDR Bloom 后扩散至合成画面。真实 GPU 浮点回读覆盖边缘及上界精度误差，旧着色器 96 组中 16 组出现无效值。
- 同时消除光环/光带对有符号距离使用 `pow(x,2.)`，改为乘法平方；保护光环中心角度；最终合成忽略 NaN/Infinity，保留已绘制的建筑画面。
- GLSL 对负底数 pow 的行为没有保证，见 [Khronos GLSL 规范](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html)。浏览器复现和 GPU 回读是本次结论的直接依据。

## 实现范围

只修改 `focus-glow.mjs` 与 `focus-bloom-renderer.mjs` 的数值处理。保留光柱、脚下 Bloom、双层光环及独立开关，不改模型、法线、主光、保存参数、业务状态、染色及装配动画。另新增可重复执行的 GPU 回归生成器。

## 回归、构建与性能

- 主目录 `npm test`：375/375；活动工作区：373/373。两处历史测试基线不同，本轮无失败。
- 两处 `npm run build` 均成功，包括类型检查；保留既有大 chunk 提示。
- GPU 测试：三个生产着色器 × 四种 UV 范围 × 八个时刻，共 96 组，全部输出有限值且无 WebGL 错误；修复前边缘/上界用例可稳定失败。
- 停止像素采样、镜头完全停稳后约 60 FPS；1.2 秒内遮挡深度额外绘制 0 次。暂停聚焦动效后连续 0.8 秒渲染帧及光效时钟增量均为 0；关闭聚焦辉光释放其渲染目标。
- 连续旋转采样包含 GPU 回读与截图开销，采样时的帧率不作为性能基准。原任务流程没有执行外发或重新计算。

可重复 GPU 回归（已有 Playwright CLI 浏览器会话中执行）：

```powershell
node tools/generate-sandbox-focus-gpu-check.mjs Codex-Temp/focus-gpu-check.cjs
npx --yes --package @playwright/cli playwright-cli -s=astra-merge run-code --filename Codex-Temp/focus-gpu-check.cjs
```

生成器读取当前生产材质 shader，不维护另一份公式；无效浮点或 WebGL 错误会直接抛出失败。
