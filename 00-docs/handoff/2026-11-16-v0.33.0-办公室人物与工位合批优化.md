# 办公室人物与工位合批优化 v0.33.0

日期：2026-11-16。已部署正式 UI v0.33.0 / host v0.14.5。

## 改动与保留

人物只合并同父节点、同材质的刚性零件：腿裤/鞋、头部皮肤/头发/五官。28→15网格/人，8人224→120。头部转向、呼吸、独立手臂关节和手部目标仍按原函数更新，原有形状、三角面、材质和命中轮廓保留。新增几何在人物重建和卸载时释放，原共享几何不提前释放。

工位在同房间、材质、照明角色、顶点格式与可见性边界内合批。每个源工位的显示器位置/朝向以顶点属性保存在合批几何，夜间shader按各自绑定计算蓝色溢光；不把一个工位的蓝光套给整间房。无屏幕绑定的未知工位继续隔离，屏幕、透明物体、动态人物保持独立。原命名节点/锚点隐藏保留，原烘焙UV、法线、贴图和全部画面默认参数不改。67个屏幕仍可用原滑块控制。

现有静态合批从1955源片段/402批变为2019源片段/136批；日间启用网格789→355。未简化GLB、未降低分辨率，日间三角面237381、夜间237781的每帧提交量前后完全一致。

## 同条件性能比较

使用同一台机器、同一Edge会话、相同默认视角和参数，开启人物动作，暂停自动旋转。对比前后均禁用浏览器后台/遮挡节流，避免1 FPS后台限帧污染。每个条件预热后采样7秒，丢弃前两帧；依据应用真实渲染回调采样，CPU数为JS更新与提交耗时，不代表GPU执行时间。像素绘制尺寸分别为1525×942、2485×1382，未改变DPR。

| 1600×1000 | 夜间 | 59.23 → 59.95 | 839 → 405 | 14.46 → 8.76 ms | 16.8 → 16.8 ms |
