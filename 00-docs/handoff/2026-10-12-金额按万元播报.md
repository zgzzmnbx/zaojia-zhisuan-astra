# 金额按万元播报

UI v0.9.106 / 宿主v0.9.9。达到10000元后，阶段语音中的金额按万元播报，Decimal精确除以10000并去掉末尾零，不额外再报元。例26728500.00元 → 2672.85万元；9447173.00元 → 944.7173万元；9999.99元 → 9999.99元。

语音与显示模板共用严格的amount_summary校验，spoken参数仅作用语音变量。原始快照仍使用CNY/yuan，并绑定成功attempt；含税/不含税与公式重算未确认提醒、自定义模板和300字截断保护保留。数字变化会自然产生新语音缓存键；相同全文与音色配置继续复用既有控制台缓存。
