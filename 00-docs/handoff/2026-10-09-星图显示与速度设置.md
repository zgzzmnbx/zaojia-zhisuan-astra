# 星图显示与速度设置

日期：2026-10-09。UI v0.9.43，设计规范 1.0.19。

## 交付

鸟瞰连线及其光流默认亮度为原来的 25%，选中关联仍保留 100% 默认强调。3D 星图右上角“设置”按钮打开紧凑面板，包含以下实时滑块：

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 旋转速度 | 0–3 倍 | 1 倍 |
| 画面缩放 | 0.6–1.8 倍 | 1 倍 |
| 节点大小 | 0.6–1.8 倍 | 1 倍 |
| 光流速度 | 0–3 倍 | 1 倍 |
| 鸟瞰连线亮度 | 0–100% | 25% |
| 关联连线亮度 | 0–100% | 100% |
| 连线粗细 | 0.5–2 倍 | 1 倍 |

滑块支持键盘方向键 / Home / End；Escape 优先关闭设置并归还焦点，点击面板外收起。提供“恢复默认”，数值写本地独立 `astra.knowledge-galaxy-settings.v1`；非法字段 / 非有限值 / 越界值经校验，存储失败时显示“仅本次生效”。

调速平滑修改实际每帧时间增量，不用时间乘以新速度造成光点瞬移；节点、亮度与线宽平滑插值。缩放在原镜头方向渐变，观察状态中的返回镜头同步缩放；不更换图实例或关系几何。用户主动放大可能缩小可见范围，仍可用缩放或聚焦按钮恢复。手动暂停、减少动效、隐藏停算与无关关系不显示流光继续生效。
