# 知识图谱三维星云

需求开始于 2026-10-08，验收完成于 2026-10-09。功能版本 v0.9.37，设计规范 1.0.15；交付运行构建已包含同期 v0.9.38 普通知识问答改动，未回退其源码、配置或文档。

## 来源与实现

- 复用已安装的 [vasturiano/3d-force-graph](https://github.com/vasturiano/3d-force-graph) 1.80.1（MIT），官方提供 Orbit Controls、自动环绕、连线粒子和暂停 / 恢复示例。官方文档于本轮在线核对，没有新增依赖或 CDN。
- 使用现有 Three.js 0.186.1、three-spritetext 1.10.0 与 Astra `03-Src/galaxy.js` 银河资产。能力星图的示例业务节点未复制；知识节点仍来自当前 50 篇文章 / 74 条关系。
- `KnowledgeGalaxyView.tsx` 作为新的懒加载入口；`knowledge-galaxy.js` 仅适配渲染、环绕、点选、搜索高亮、缩放与资源释放。`knowledge-galaxy-layout.mjs` 克隆业务对象后生成展示坐标，不修改原关系、ID、正文或知识库。
- 三维节点具有纵深，环绕视角使节点产生可见旋转；背景银河旋臂独立流动，关系线带流光。悬停 / 搜索 / 阅读 / 拖动时停止自动环绕；标签保持屏幕 13px 字号。悬停摘要不拦截节点点击，关联按钮在选中后显示。
- 二维图谱保留，WebGL 上下文失效自动降级；原文章阅读、关系列表及键盘搜索入口保留。
- 可见性、系统减少动态效果与显式动效偏好沿用。渲染回调内的唤醒延迟到 microtask，防止在上游 RAF 标识回填前重入；卸载释放观察器、计时器、材质、银河资源和 WebGL 上下文。

## 验收

- 主目录与活动 worktree 各 173 项前端测试通过；类型检查和正式构建通过。保留既有大资源 chunk 提示，无构建失败。日志：各工作区 `Codex-Temp/knowledge-galaxy-3d/`。
- 实际桌面 1280 × 720：50 篇 / 74 关系正常渲染；进入自动深色，离开文章库恢复 light；未写入自动明暗偏好。
- 浏览器只读读取真实相机：1.5 秒内从 `(363.397, 85, 69.590)` 变为 `(345.702, 85, 131.872)`，autoRotate 为 true；确认三维运动实际发生。
- 关闭后连续稳定测量：renderer 帧数保持 2710，相机位置不变，autoRotate 为 false。后台唤醒会为交互短暂绘制，因此未用跨工具截图差异代替连续计数。
- 搜索“培训”显示两篇文章，点击“生产准备与培训费用”进入原文章卡；直接点击三维节点“管道清管试压与干燥置换”也进入原文阅读。均为现有只读流程，未调用问答模型或改价格。
- 手动二维切换正常；通过 WEBGL_lose_context 模拟故障，实际显示“3D 暂不可用，已切换二维图谱”。随后重新进入可恢复三维。
- 模拟 prefers-reduced-motion 且无显式偏好时默认关闭；主动开启后 aria-pressed 为 true。验收结束已撤销媒体模拟，恢复用户要求的动效开启；临时调试探针与测试标签已清理。
- 最终预览图：`Codex-Temp/knowledge-galaxy-3d/final.png`。本轮未提交 Git、推送、部署、修改旧工程或进行外部协同发送。
