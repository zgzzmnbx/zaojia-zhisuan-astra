# 全屏悬浮智算验收

版本：UI v0.6.9，2026-10-07；后端保持 v0.6.2。

## 来源与范围

参考原项目 `D:\Codex-Temp\260612-【ai大赛】-管勘智算-V2.0` 的 `frontend/src/styles.css`（`.is-ai-collapsed > .ai-dock` 浮动入口）及 `frontend/src/components/ZhisuanAvatar.tsx` 的交互 / 可见性处理。原项目只读；当前形象仍复用 Astra 已有的原版 Gork canvas、catalog 与 renderer，不复制旧 SVG 角色替代 Gork。本轮新增四角拖拽和页面顶层适配。

## 当前行为

- 应用内全屏以及窄屏专业内容视图显示 64px 悬浮头像，默认左下角，留出导航和底部工具条；平时头像仍在输入区。
- 鼠标 / 触屏拖动，松手吸附最近四角；点击显示四角按钮，方向键切角，Home 复位。仅 `astra:floating-gork-corner` 保存位置，不改会话或任务数据。
- 拖动限制在视口内；取消、失焦、页面隐藏和尺寸变化恢复停靠。ResizeObserver 同步响应导航和顶栏几何变化。
- 手动 Popover 位于浏览器页面顶层；模态 dialog 打开时挂入该 dialog，保持可操作。头像以外区域点击穿透。
- 复用原眨眼 / 鼠标平滑跟随，真实工作 / 错误状态优先。同源专业 iframe 的指针转换为外层页面坐标；外部 / opaque sandbox iframe 保持隔离，不放宽权限。
- 全屏时输入区 Gork 暂停，退出后悬浮 Gork 卸载，输入区恢复；不新增 RAF 循环，不连接硬件或外部服务。

## 验证结果

- `npm test`：95 项通过（新增位置容错、四角边界、拖动越界与键盘选择测试）。Gork 原始资源一致性、眨眼配置、单 renderer 与清理测试保留。
- `npm run build`、`npm run build:frontend-debug`、输入区与四形态 SSR 检查通过。
- 1440 × 960 亮色及深色、390 × 844 窄屏视觉检查通过；默认左下避开导航，窄屏与桌面切换重新计算停靠边界。
- 四角拖拽、点击位置选择、方向键、Escape 取消通过；拖动结束不误开位置菜单。
- 桌面与窄屏返回切换、刷新恢复右上角通过；验收后位置恢复左下角。Chrome 触屏事件实际拖动停靠右上角通过。
- 模态弹窗内的浮动头像通过 `elementFromPoint` 命中顶层本人，可拖动 / 键盘操作；关闭后回到 body 顶层。
- 原 renderer 浏览器采样 316 帧，眨眼开合值覆盖 0.05—1；指针左右切换后头部角度分别为正 / 负。同源专业 iframe 实测角度约 34.05 / -2.25。
- 全屏活动头像数量 1，输入区暂停；退出后悬浮数量 0，输入区活动头像数量 1。
- 截图与操作记录：`Codex-Temp/floating-gork-*`。没有修改业务字段、启动计算、发送外部消息或进行设备联调；不代替原 Excel / Word 和外部平台业务验收。
