# 办公室周边建筑与首页光影对齐

版本：UI v0.34.4 / host v0.15.0；日期：2026-11-17。

## 结果与边界

办公室周边139栋建筑与全部原道路，直接复用正式首页V11柔白烘焙。保留办公室现有位置、比例和高度；本轮不改变主楼及九层材质、人物、业务数据、选人复核或外发逻辑。夜间继续取原UV、顶点色与旧材质颜色；新增贴图只在日间采样。

此前差异来自两套烘焙：办公室使用AgX展示转换和部分边缘纯色修补，首页使用Standard sRGB柔白烘焙。先前全局提白、对比度压缩不足以还原首页的方向明暗、真实遮蔽与细腻阴影。

## 实现

- `tools/office-twin/transfer-context-bake.py` 按世界坐标逆变换逐三角面匹配首页正式模型：建筑15012面、道路9290面，所有源三角面均覆盖。逐角校验误差小于0.0001，转移首页原UV和两张原PNG。
- `public/office-twin/models/astra-context-v1/` 是本地私有派生资产；纹理与首页逐字节同哈希。原H1 GLB哈希保持 `c805ae3f8074f3c9cba9c36249401c97bd4a9b13c5d57ce236fc66a5032a2545`。
- `astra-context-bake.js` 仅给对应私有几何加独立UV属性。原UV、颜色和索引语义保留；失败时完整回退，卸载恢复原几何并释放派生资源。与既有工位合批隔离，无新绘制批次。
- 日间按首页 `baked-surfaces.mjs` 的纹理采样与道路雾白映射显示，不再给周边建筑追加AgX修正。周边及地面亮度默认105%、地面`#f5f7fa`；主体/室内的现有默认值不改。明暗层次80%对新贴图为中性基准，用户调节仍有效。
- 办公室自有台座108面及连续底板保持原专属烘焙，避免照搬首页主建筑的遮挡轮廓产生黑块。原个人参数不覆盖；用户可“画面设置→恢复默认→保存参数”采用新基准。

- `npm test`：501/501通过；正式源码基线构建通过。
- 真实GPU对照：从正式首页读取原城市几何、首页同哈希贴图及105%亮度，与办公室实际运行材质在同机位、同尺寸、还原同尺度后比较786432像素。平均RGB差异0.00001144/255，最大差异1/255，超过2/255的像素为0。办公室仍保留自身几何高度比例，未宣称两张完整布局截图逐像素相同。
- 实际浏览器：整楼、展开9F、九楼切换；日夜显示；独立亮度滑块、恢复默认、保存；隐藏停帧与返回复用实例均通过。真实3D拖动石萌和演示人员，均在框内显示标签；仅owner同步宿主选人，未发送真实复核。
