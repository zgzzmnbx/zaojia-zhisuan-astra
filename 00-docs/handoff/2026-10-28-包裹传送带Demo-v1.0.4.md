# 包裹传送带 Demo v1.0.4 · 轨道穿楼修复

2026-10-28，独立候选，正式 Astra 仍为 v0.11.19。

## 问题与处理

上一版相机有避障，但实体轨道未按建筑轮廓校核。实际发现风险到报告段横穿管廊和报告楼，表格大屏附近贴入构件，部分收件门架过近。

- 风险段改走管廊前侧和右侧；报告段沿楼外通道转弯。
- 表格与知识段改走建筑之间的通道，收件门架同步移到外侧。
- 配置统一放入 `conveyor-route.json`；Blender 带面、支架、门架、运输关键帧和导出时间轴同步重建，信息管由同一份导出路线生成。伴行偏移收至 0.60，留出东侧楼墙与景观之间的净空。
- 保留清单、填价、风险、报告、协作、表格、知识顺序，浅色玻璃材质、窄带面、原版流光、雨雪和太阳；全程随新路线变为约 38.3 秒。
