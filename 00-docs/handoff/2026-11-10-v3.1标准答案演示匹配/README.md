## 功能与使用

候选版在“设置 → 演示与调试”增加 **3.1 标准答案匹配**，默认开启，同时受顶栏演示模式总开关控制。用户仍执行导入、确认结构并转换、开始批量匹配；批量填价阶段直接使用已核验的本地答案快照，不读取计价库、不执行系数查库或模型推断。结果卡明确标记“演示标准答案 · 未查询计价库”。

- 仅输入 SHA256 为 `81e562f874b16d75024bf7d02055e03f7afd929e3382433c633cf9cf9b1559c7` 的原版 3.1 样例，且三个工作表、表头行、价格/系数物理列、范围与匹配选项一致时命中。名称不是判断依据，同名改过内容不能套用答案。
- 100行中99行填入，原有价格保留1行；表2 H5=50000、H6=3203。保持当前输入、公式、格式及后续风险流程。
- 关闭总开关或分项开关，或修改文件、映射、工作表范围、数量筛选、人工确认候选，均走原有匹配路径。切换开关本身不重跑任务、不改写已有成果。
- 答案、摘要和清单逐文件校验。命中样例但答案损坏时停止、显示中文错误、保留原成果；不静默发布错误结果。原批量锁、重复提交保护、发布前成果校验继续生效。
- 单行填价仍走原有候选、解释及人工确认流程。不能把本次“批量匹配不查库”理解为整个演示都不依赖任何规则资产。
- 结构识别、公式重算、经验池风险检查、Word生成仍实际执行。该功能消除批量匹配的查库结果变化，不承诺文件锁、磁盘、Office或现场设备永不故障。
