# v0.11.12 · 卡通河流与浮动小船

2026-10-24。源码候选完成，尚未部署；正式 5189 保持 v0.11.8，视觉验收由用户看图确认。

## 画面与交互

水体改为三渲二表现：青色分层水面、柔白断续波峰、轻微真实高度起伏。波浪沿现有河道的 -X → +X 方向推进，从默认鸟瞰画面的左上游向右下游流动。保留源河道三角形轮廓，只对私有副本细分，不移动两岸、建筑、桥梁或底座。

三艘低多边形小船缩为上一版夜间船的 48%，沿河轻缓漂移。船体高度由同一水面波函数采样，俯仰参考水面坡度；夜间保留十二个微小灯点，日间关闭灯点。原始白色预设优先恢复原河面。

入口：**视图 → 河流 · 卡通三渲二**。

| 控制项 | 行为 |
| --- | --- |
| 卡通水体 | 开启新水面；关闭恢复源静态河面 |
| 波浪流动 | 冻结/继续水面与浮船共享时钟，不跳回起点 |
| 小船浮动 | 显示/隐藏卡通水面的小船 |
| 流速 | 0–100%，零值停流 |
| 波浪起伏 | 0–100%，调节真实几何起伏与小船升沉幅度 |
| 夜览 → 小船星光 | 卡通水体开启时控制船灯；水体关闭时沿用上一版夜间小船行为 |

继续遵循“保存当前参数”整套显式保存；旧启用值 false 不被升级覆盖。默认整套方案的水体仍为关闭，用户打开即可试用。旧质量/反射/Bloom 数值保留兼容读取，当前卡通模式不执行平面倒影或写实高光，也不再显示这些无效控制项。

## 验证结果

- `npm test`：372 通过，0 失败。
- `npm run test:sandbox-v11`：46 通过，0 失败；新增波浪传播方向、源资产隔离、小船与水面同步、离屏/暂停/减少动效/零值和参数往返测试。
- `npm run build`：通过。
- 真实 Chromium / WebGL，1754×956、DPR 1：日夜画面、三项开关、正常动画推进、暂停稳定、参数保存刷新恢复通过，控制台错误 0。
- 卡通水体关闭时，白天和夜览同机位静态画布与 v0.11.11 基线 PNG SHA256 相同；白天开启再关闭亦相同，原始白色预设恢复相同。动画播放会推进既有信息流相位，因此完整场景的静态像素对比在减少动效及同相位条件下进行，不将正常信息流移动误判为水体污染。
- 实际后台验证：独立 Chromium 用 CDP noDefaults 接入，`document.hidden=true`；间隔一秒帧数、水体时钟、小船时钟均不增长。离屏冻结另有单元测试。
- 当前应用不再加载旧法线纹理或生成河流平面反射目标；160 个源河面三角形细分为 2560 个私有三角形，无额外独立 RAF。未进行持续前台 GPU 帧率基准测试，不承诺固定 FPS。
