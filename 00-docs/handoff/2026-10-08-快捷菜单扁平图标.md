# 快捷菜单扁平图标 · v0.9.28

用户要求优化输入区快捷菜单、更换好看的扁平图标。本轮使用 Phosphor Icons Core 2.1.1 的 Duotone SVG：仅保存需要的 31 个图形，保留 MIT 许可证、来源与原文件 SHA256。常用 14 项及全部功能 28 项共用按功能 ID 的映射；表格、Word、风险报告、进度采用不同图标。图标本地打包，无运行时外链请求或新增 npm 依赖。

菜单改为透明按钮底、36px 浅主题底块 + 28px 双色图标、轻分组线，文字仍为 13px。图标采用当前主题可读强调色；禁用保持文字原因与原逻辑。不改变业务路由、匹配、发送或任务数据。
