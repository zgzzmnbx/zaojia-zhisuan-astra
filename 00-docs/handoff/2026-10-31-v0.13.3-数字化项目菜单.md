# 数字化项目菜单修复 · v0.13.3

2026-10-31。用户反馈：顶部“当前测算项目”展开后半透明、内容重叠。

## 根因与修改

实际 Edge 页面复现：daisyUI 启用 `appearance:base-select`，`::picker(select)` 继承项目按钮透明背景，计算值为 `rgba(0, 0, 0, 0)`。菜单处于顶层，但透出了 iframe 内容。

- 仅在 `03-Src/modules/digital_cost/digital-cost.css` 为该选择器菜单指定不透明主题背景、文字、边框、宽度与限高滚动；当前项及悬停/键盘焦点使用浅底强调。紧凑按钮保持原尺寸。
- `DigitalToolbar.tsx` 拦截该选择器的 Escape 冒泡，保留浏览器原生关闭菜单行为，避免触发宿主全局 Escape 收起数字化内容。
- 项目列表、任务切换协议、禁用判断和独立模块服务不改；数字化模块保持 v0.10.0，宿主后端保持 v0.9.16。
