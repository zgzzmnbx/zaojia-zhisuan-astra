# 知识图谱临时深色与银河流动

2026-10-08 · UI v0.9.35 · DESIGN 1.0.14

## 行为

知识图谱可见时使用 useAppearance 的临时深色覆盖，原持久明暗偏好不变。切文章 / 问答页签、关闭内容、返回欢迎页后恢复原偏好；图谱内手动切明暗只作用于本次打开，下一次打开重新深色。系统架构图使用既有优先覆盖；其窗口打开时卸载背后图谱。

背景新增银河光带、远近两层星尘和两层漂移星云，周期 26–48 秒，慢速往复。节点画布移除整体漂移动画，保留布局、缩放、搜索与选中行为。所有装饰层 pointer-events:none / aria-hidden，不表达真实数据流。

沿用 Astra 独立动效开关；减少动态效果在无显式偏好时默认关闭，用户主动开启可覆盖。IntersectionObserver 与页面 visibilitychange 控制动画暂停及 force-graph pauseAnimation / resumeAnimation，暂停时取消拖动惯性 RAF；离开卸载释放观察器和监听器。
