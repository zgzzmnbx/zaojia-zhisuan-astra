# 装配视觉样板 v1.0.0 验收记录

日期：2026-10-30。范围：独立样板，用户确认后再考虑正式接入。正式产品版本不随样板升级；源目录同时有其他 v0.11.35 改动，本任务没有将其发布。

## 实现

1. 动画：增加横向散开与竖向抬升，短暂展开后按建筑、构件高度错峰回收，加入弧线路径；保持刚性平移，未加入旋转。完整可见时间约 4.65 秒。
2. 黑边：原烘焙接触阴影在拆分时暴露。候选扩大中性暗面识别范围，按位移保留临时补光，临时材质按建筑隔离，避免共用材质的退出时间串扰。
3. Blender：实际运行 Cycles 六朝向白面漫反射烘焙，导出工程、PNG 与方向光照 JSON；运行时只在候选装配片元中采样方向结果。没有宣称逐栋建筑重烘焙，也没有改冻结模型或日间完成材质。
4. 暂停保留当前画布；重播销毁旧实例，创建新的独立播放资格；减少动效直接归位。

## 验证结果

- npm test：385/385 通过。
- npm run build：通过；构建产物未覆盖正式入口。
- 候选专项测试：2/2，通过原始与调节材质、实际七建筑运动、源属性/几何/材质/着色器完整恢复、减少动效与打断、临时资源只释放一次。
- 两份专用 Vite 构建通过；保留既有 chunk 体积提示。
- 真实 Chrome 浏览器：同机位 1600×1000，500/1800/3200ms 截图及归位画布。归位前后 PNG 字节完全一致；控制台无 error，页面无异常。
- 浏览器交互：重播、暂停冻结时钟且画布可见、直接归位、减少动效通过；录像已生成。
- 后台可见性实测未通过验收条件：自动化浏览器切换标签后 document.hidden 仍为 false，因此本轮不能确认真实后台冻结；记录保存在 browser/background.json。普通暂停已通过，但不替代真实后台验收。

## 视觉观察与边界

拆分时灰黑轮廓减轻，构件高低与散开幅度更明显。少数底座/河岸已有黑缝仍可见；本轮没有通过永久抬亮成品来掩盖它们。当前取正式内置亮度，画面偏明亮，没有调整最终曝光。尚需用户看动态样板确认展开幅度与节奏；测试通过不等于视觉通过。正式夜景、真实业务全链路、正式环境性能不属于这次白天独立样板验收。
