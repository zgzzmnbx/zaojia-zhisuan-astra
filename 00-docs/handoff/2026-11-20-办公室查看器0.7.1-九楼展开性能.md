# 办公室查看器 v0.7.1：九楼展开性能

## 复现与定位

在正式工作台打开「多人复核」，从整楼点击 H1 的「9F–造价中心」。用本机 Chromium（D3D11、1536 × 1060 CSS px、DPR 1.25）测第一次和随后两次展开；计时取移动阶段连续渲染帧间隔，不用左下角平均 FPS 代替。测试拦截业务写请求，不发送复核。

- 原版在托盘展开约 90% 时显示人物。CPU 采样集中在人物标签的 `offsetWidth/offsetHeight`：逐人修改样式再测量，反复强制布局。三次打开均可复现约 350 ms 的停顿。
- 合并标签测量之后，重复展开已顺畅，但首次展开仍出现一次约 0.9 秒的长帧。隔离试验中，原预热只画过日间离屏缓冲和夜景通道，补画实际日间输出与日间景深通道后，该尖峰未再出现在候选版的同场景三轮采样中。

## 修改范围

标签先统一更新文字和显示级别，再集中测量，最后按原优先级避让、定位。移动只更新发生位移的楼层及其后代，不重算 H3 和街区；仅在聚焦人物时提前更新目的地人物锚点。沿用同一渲染上下文，在加载阶段用 32 × 32 缓冲预热，随后恢复原尺寸。未改动画时长、分辨率、模型、灯光、景深强度或复核功能。

## 验收口径

同一工作台分别验证自动入场、九楼标签悬停、中途移出还原相机、点击进楼、日夜景深、人物标签选人、减少动效、隐藏停帧。查看器单独升至 v0.7.1；模型仍为 porcelain-0.7.0，工作台与后端不随之升版。原始采样、截图、隔离构建和回滚清单留在 `Codex-Temp/office-lift-perf/`，不是其他设备的帧率承诺。
