# 预设答案展示动画验收

- UI v0.9.57；设计系统1.0.28。
- 用户要求前四个示例问题在展示答案前播放4秒象征性加载动画。
- 复用原WorkingCard和daisyUI spinner，标题“正在展示预设答案”，副文案“4 秒示意动画 · 非模型生成”。不把动画伪装成检索进度或模型生成。
- 按原预设问题文本识别；动画与真实读取并行，二者完成后展示。实际读取超过4秒时继续等待真实响应；读取失败不发布答案。普通问题、推荐题弹窗与历史恢复不加延迟。
- AbortSignal停止定时器，保留当前会话校验和晚到回执丢弃；不改原答案、引用、表格、图表与计价规则。
