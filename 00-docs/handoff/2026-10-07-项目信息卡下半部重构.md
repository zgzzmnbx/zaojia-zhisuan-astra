# 项目信息卡下半部重构

2026-10-07，UI v0.9.2；宿主源码仍为 v0.9.0。

## 改动

- 保留上半部金额与费用图表；下半部改为匹配进度、风险复核、资料折叠行与统一底部入口。去掉重复的项目名、文件名和展开状态下的大段常驻说明，保留必要审核语义。
- 风险复核展示四级计数、最高等级事项及真实偏离率，可进入原风险图表页。风险数值、等级和定价均不重新计算。
- 原先恢复任务只在打开风险页时读取明细，导致项目卡长期显示“明细待载入”。现在恢复已检查任务即按当前 job 读取；失败可重试，15 秒超时，切换会话取消请求并校验上下文，忽略晚到结果。
- 短窗口内部滚动、底部入口吸底；使用主题语义色与可读强调色，新增区域淡入支持系统减少动效。

## 验证

- `npm test`：127 项通过，新增最高风险选择、原数组不变和不同 job 隔离检查。
- `npm run build`、`npm run build:frontend-debug`：均通过，包含 TypeScript 检查。
- 浏览器沿用当前 V3.1 演示任务的真实成果：99 / 100 行匹配；自动读到高风险 1 项、低风险 1 项，最高事项偏离 11,598.6%。未重跑价格、公式或预警计算。
- 1478 × 993 桌面卡完整显示；1366 × 768 内部滚动且底部入口可见；390 × 844 无页面横向溢出，亮暗下均检查了下半部，资料展开 / 收起及风险页入口通过。
- 浏览器临时拦截风险接口返回 503：显示读取失败而非零风险；解除拦截后点击重试，恢复真实两项风险。该合成故障仅用于浏览器验证，未修改业务资料。
- 验证截图与脚本位于忽略目录 `Codex-Temp/project-card-*`，不提交用户输入或运行数据。冻结引擎、原工程、价格规则与外部发送状态不变。

## 边界

短窗口通过内部滚动查看全部信息，不通过缩小业务字体挤入一屏。没有进行新的 Excel / Word 标准答案或外部协同验收；本轮验证范围为卡片呈现与风险读取。
