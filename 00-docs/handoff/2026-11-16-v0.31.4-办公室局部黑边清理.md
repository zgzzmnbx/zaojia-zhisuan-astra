# 办公室局部黑边清理

UI v0.31.4，2026-11-16。

## 范围与原因

检查整楼、主楼屋顶/外立面、周边建筑/街道，以及 R_W、R_NE、R_NW、R_E、R_SW、R_SE、R_RECEPTION、R_PANTRY 八个区域。异常集中在靠墙柜体部分面、柱面少量 UV 区域，以及 W_E_MS_S_cut 柜后墙上沿。射线核对表明是原贴图的纯黑遮挡残留，不是需要整体提亮的阴影。

先试验了 Blender 5.2 Cycles 柜体局部重烘焙，但原共享 UV 岛重叠及整体照明差异使个别柜顶变灰，因此未采用该候选。最终从原图集按实际几何 UV 面做离线修复，用同一面健康区域拟合柔和颜色梯度；完全遮挡的白柜面用相邻白柜方向色基准恢复。仅在确定的面内平滑修复异常暗区，不对全场景设亮度下限。
