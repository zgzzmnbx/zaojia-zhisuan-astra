# v0.40.1 复核人选标签取消

2026-11-17 · UI v0.40.1 / host v0.16.0。正式宿主 PID 26000 保持。

## 操作

- 已选人名右侧 × 取消该人选；原人员列表、3D人物拖入和详情卡选择仍可使用。
- 按住已选标签移动超过7px后，拖出虚线复核框并在办公室页面内松手，取消该人选；拖回框内保留。拖动时显示将取消的人名。
- Escape、浏览器失焦、指针取消、页面隐藏、上下文/版本变化中止手势；页面外松手不取消，避免误操作。
- 删除按钮使用原 togglePerson(id,false)，保留真实石萌权限及其他员工仅演示规则。未修改业务发送、审批回执、工位配置、模型、光照或人物动作。
- 每人独立可访问名称，26px点击区；键盘Enter/Space使用原生按钮行为，删除后聚焦下一标签或复核框。
