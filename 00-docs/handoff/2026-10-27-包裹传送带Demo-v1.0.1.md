# 包裹传送带 Demo v1.0.1 验收记录

任务日期：2026-10-27—28。状态：独立候选，供用户视觉评审。正式 Astra 保持 v0.11.19，未接主业务，未提交或推送 Git。

## 本轮变化

1. 使用 Blender 5.2.2 LTS 重建轨道与动画，顺序固定为：清单导入 → 智能填价 → 风险复核 → 报告生成 → 协同复核 → 专业表格 → 知识检索。六段实体轨道与七个收件门架，约 41.7 秒。
2. 带面由蓝灰改为浅白，保留细分隔线与柔白护栏。蓝色信息管以实体管线沿传送带旁伴行；原冻结模型资产未改。
3. 增加晴朗、雨、雪选项，雨雪强度可调；太阳独立开关与亮度。实时天气不改建筑烘焙贴图，不额外载入其他沙盘版本。太阳作为场景中的暖白光源，影响新模型受光，不重新计算原建筑烘焙阴影。
4. 新增包裹第一视角：镜头位于包裹上方，提前观察轨道前方，弯道平滑转向；相机位置、目标和视角约 1.65 秒过渡。按七个建筑实际三角面预计算高度场，近障碍时自动抬升。拖动或滚轮退出自动跟随，恢复自由观察。
5. 一轮运输结束停靠，重播从第一站重新开始；用递增请求编号处理反复跳转到同一个时间点。

网页：[本机独立 Demo](http://127.0.0.1:5189/parcel-demo/index.html)。右侧天气和太阳设置，顶部“包裹第一视角”，原跟随视角保留。

## 边界

- 这是运输与天气视觉演示，站点停靠不代表真实业务完成率。
- 第一视角为有避障抬升的包裹随行视角，近高构件时会暂时升高，保证镜头不进入建筑；视觉舒适度仍由用户确认。
- 带面暂未制作机械履带滚动，未制作包裹开箱、建筑内部收件、夜间天气或真实任务事件接入。
- 雨雪为轻量实时粒子，不模拟地面积雪、积水或新的建筑湿润材质。
- 浏览器性能样本仅为本机独立 Demo，不代表正式业务并发负载。

README、PRD、场景入口、独立 CHANGELOG 和项目经验已同步。Demo 版本 v1.0.1；正式 package.json 与正式 CHANGELOG 保持 v0.11.19。视觉确认后，再决定正式整合。
