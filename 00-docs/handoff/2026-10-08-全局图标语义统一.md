# 全局图标语义统一 · v0.9.30

## 范围与实现

将工作室公共 SVG 与原有 42 个组件的 Lucide 导入统一为本地 Phosphor Core 2.1.1 图标，扩展到导航、设置、任务卡片、看板、知识库、专业 iframe、Word 预览及复核 / 协作等模块。共保留 105 个所需图形，原 SVG 几何与浅面透明度不变，MIT 许可证及每个图形的权重 / SHA256 均在 03-Src/vendor/phosphor-duotone/。

- icon-catalog.js 统一通用名称、旧 React 名称兼容、能力 ID 与页面意图映射；icons.js 输出工作室 / 历史静态预览 SVG，PhosphorIcons.tsx 为原专业 React 组件保留尺寸、class、颜色、ref 与 ARIA 属性。
- 业务 / 导航用 Duotone；关闭、方向、加减、加载用同库 Regular，保持小尺寸识别。不同名但同意图的入口共用图形，专业页面标题也从同一目录读取。
- 聊天、创建、历史分别使用对话、书写、回溯；资料库与数据库、Word 与风险报告、机器人与专业工具、空间星图与系统架构分别匹配实际含义。
- Sheet / 看板滚动、知识问题翻页、文档缩放及地图关闭的字符符号换成统一 SVG。图标填充跟随 currentColor，禁用 / 成功 / 风险保留原颜色与文字。旧 stroke 规则不叠加到填充图形。
- Gork、图表数据几何、地图、品牌及架构原始插图保持；冻结引擎未改。原业务路由与状态规则未改，不新增远程图标加载、npm 依赖或外部请求。旧 Lucide 依赖保留供既有隔离资源使用，自有 studio / professional TSX 已无直接导入。
