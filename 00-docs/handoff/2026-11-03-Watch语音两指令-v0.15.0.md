# Watch 智算语音两指令 · 2026-11-03

## 使用

电脑启动 Gork 与造价智算，刷新智算页面进入当前任务，并保留一个可见的智算工作页面。Watch 连上原控制台后，用现有按键录音方式说“查询进度”或“检查风险”。

- 查询进度：依据当前任务的真实忙碌、失败、匹配与风险检查状态回答，不估算百分比或完成时间；未检查与零风险分开。
- 检查风险：需要已有匹配成果且当前未执行其他任务；复用电脑原“检查经验池预警”处理器。先回答已提交，检查完成沿用原阶段通知。
- 目前只支持这两条业务指令；复合、否定或不匹配语句不触发业务，保留普通语音问答。
- 说话期间不要切换项目；多个可见智算页面、连接断开或任务变化会要求重新说一次。重启不补执行旧命令。

## 接口与权限

Watch → 原 Gork 录音/ASR → 固定短语识别 → Astra 当前页面既有业务处理 → Gork 原 TTS/Watch 输出。识别业务意图不调用回答模型；录音转写和语音生成仍沿用当前许可与云端配置。

固定端点 `http://127.0.0.1:5189/api/astra/gork/commands`，协议 `astra-watch-commands/1`。Gork 在录音前读取绑定，指令凭证独立于阶段通知。Astra `config/gork-commands.local.json` 与 Gork companion 根目录 `astra-commands.local.json` 只在本机保存，不入库、不记录密钥。当前已配置。

页面可见时每秒领取；七秒无心跳失效，单条十二秒截止。每个请求编号只领取一次，不重试提交，断线不补执行；已开始业务不能通过取消队列撤销。阶段通知原来的约十秒连接检查不变。
