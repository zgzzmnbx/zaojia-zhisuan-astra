# 对话留白滚动验收

- UI v0.9.56，设计系统1.0.28。
- 原因：纯聊天将整个 conversation 限制为980px，鼠标在两侧 workbench 留白上时，原生滚轮找不到消息滚动容器。
- 修复：conversation/messages覆盖整栏；消息以动态padding居中，标题和输入区保持980px上限。不增加JS滚轮转发，不拦截其他面板。
