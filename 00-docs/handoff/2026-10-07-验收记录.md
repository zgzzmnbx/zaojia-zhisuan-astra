# 交接版本验收记录

环境：助手云 Linux，Node v24.19.0、npm 11.9.0。测试对象为独立去资料化交接树，不是用户电脑或真实后端。

## 通过

- 原 `npm test`：43项。
- 新增项目/浮卡/四形态/Gork原版与平滑/工作区测试：44项。
- `tools/test-four-presentation.mjs`、`test-content-tabs.mjs`、`test-current-project.mjs`、`test-composer-companion.mjs`、`test-project-card-entry.mjs`、`test-legacy-system.mjs`、`test-example-settings.mjs`、`test-icon-rail.mjs`、`test-uploaded-example.mjs`：SSR、状态、回调、结构及合成数据检查。
- `tools/test-frontend-debug.mjs`：29项无表格数据/持久化/隔离检查。
- TypeScript；正式构建与显式frontend-debug构建。
- 正式构建特意在ASTRA_FRONTEND_DEBUG=1环境下运行，仍使用production配置，输出04-output；调试构建须显式flag，输出dist。
- 生产JS未包含检查过的mock拦截/注册标识；调试包不含私有样表数据，包含无资料提示；旧架构只在debug别名下打包。

迁移测试中原有两处Sites私有提交历史依赖已去掉，避免换仓库后git show失败；Gork返回入口断言更新为用户要求的图标aria-label/回调。

云浏览器此前返回ERR_BLOCKED_BY_CLIENT，本轮没有实屏截图、真实鼠标拖拽/命中或视觉断言。源码几何检查不能代替浏览器验收。需本地Codex按交接说明补测。

现有字体回退、较大bundle及lucide模块指令警告仍存在。依赖及lockfile未改。上传表格不进入分支或测试；调试报告是空态/模板，不是业务审核结论。

交接版额外删除网络适配器与欢迎示意中的全部表格夹具和模拟计算/风险/报告结果：保留空工作区、用户自行输入的项目/草稿及原界面组件。业务接口返回未接入，不提供假完成结果；该变化只在交接树，线上私有预览未改。
