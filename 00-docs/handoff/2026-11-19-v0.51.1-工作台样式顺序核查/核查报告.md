# Astra v0.51.1 工作台样式顺序核查

2026-11-19，以本机 5189 端口实际运行的 v0.51.1 为核查对象。办公室设置第一次接入构建前的正式版本为 v0.48.1。该版本留档与正式回滚备份中的入口文件、当代资源清单相符。

## 原因与影响

v0.49.0 将办公室任务设置加入工作台的多入口构建，共享样式的排列第一次改变。v0.50.0 又加入办公室综合设置，主工作台的通用样式排在组件样式之后。两条规则优先级相同时，浏览器采用排在后面的声明。快捷菜单组件和它自己的样式文件从 v0.48.1 到 v0.51.1 内容相同，实际画面却跟着外层构建发生了变化。v0.51.0 增加 H3 时沿用了这套顺序。

| 浏览器实测位置 | v0.50.0 | v0.51.1 |
| --- | --- | --- |
| 常用快捷菜单 | 按钮高 34px，第二行图标压住上一行文字 | 按钮高 68px，图标和文字完整 |
| 独立 Logo 与动效页 | 标题 28px、字重 700 | 标题 20px、字重 600 |
| Excel 计算表预览 | 表头 12px | 表头 13px |
| 对话卡片状态标签 | 字重 400，上下内边距 0 | 字重 500，上下内边距各 3px |
| 欢迎页预览卡片 | 部分小标题统一呈现为 16px、字重 700 | 按位置恢复各自的字号和字重 |
| 收起对话及 Gork 气泡 | 全屏浮层可盖白沙盘，气泡主体与尖角颜色可能分离 | 九楼仍可见，亮暗模式下气泡与尖角同色、文字为白色 |

快捷菜单和独立 Logo 页的截图来自两个版本的完整页面。其他参数用同一份页面内容依次加载历版正式样式测量。[旧版快捷菜单](快捷菜单-v0.50.0.png) · [当前快捷菜单](快捷菜单-v0.51.1.png) · [旧版 Logo 页标题](Logo页-v0.50.0.png) · [当前 Logo 页标题](Logo页-v0.51.1.png)

v0.49.1 也保留了第一轮顺序变化。与 v0.48.1、v0.51.1 相比，复核进度卡标题的字重、说明文字上边距及部分辅助文字颜色有差别。因此用 v0.48.1 检查办公室接入对宿主的影响。

## 当前正式版

- 对照 v0.48.1，将共享 CSS 展开到规则、声明、层级、媒体条件及优先标记。主工作台共有的 8,484 条记录顺序完全一致。逐项差异为办公室设置打开时的两条布局规则，以及 Gork 气泡正文最大高度的一条替换规则。
- 主工作台、专业工作区、独立 Logo 页、设计页这四个原有入口，脚本执行入口、模块预加载及样式文件的排列均与 v0.48.1 一致。专业工作区的 4,729 条、Logo 页的 4,608 条和设计页的 4,235 条样式记录逐项一致。共同使用的 19 个 CSS 文件中，18 个字节相同。项目看板、地图、地球、项目沙盘、Word 预览等按需加载模块的样式也在其中。
- 检查本代资源清单的 120 个文件和生成代码中 464 处本地资源引用。文件均可在正式目录解析。快捷菜单、侧栏、工作表、复核卡和复核工作流等九个选定源码文件也与发布办公室设置前一致。
- 在 Chromium 做了 84 次画面状态比对。76 次有 v0.48.1 对应入口，70 次测得的样式与几何均一致，另 6 次只测到 Gork 气泡正文最大高度的已知调整。剩余 8 次涉及后来新增的办公室设置和人员任务入口。84 次均有当前版本回测，自身比较差异为零。相同控件在多个状态中可能重复出现，次数不代表独立功能数。
- 桌面检查覆盖亮、暗工作台、两套架构图、八个 Astra 设置标签、快捷菜单两页、真实六个 Sheet 的工作簿、键盘切表、表格查找、列设置、风险、Word 预览、项目看板、文章库、公文转换、数字化造价嵌入、飞书和 WeAct 连接详情、复核确认卡、办公室三项设置、人员详情、楼层往返及收起对话后的场景保留。测试宽度为 1636、1280、1024px。专业页与旧人员任务页直接访问时各自采用默认主题，正式嵌入界面另行检查。

## 重新构建所得差异

从正式源码副本核对 464 条发布指纹，在独立目录连续执行两次 `npm run build`。首次从空输出目录构建，七个入口的资源类型与加载顺序相同，120 个资源中有 106 个与正式版文件名和字节都相同。差异追溯到共享 CSS 中五个带 `!` 后缀的工具类。去掉这五类规则及所属的空条件块，两份 CSS 的完整有序语法树一致。72 个 JavaScript 文件逐一替换对应资源文件名后，文本均一致。

这五类为 `range!`、`stack!`、`join!`、`hidden!` 和 `shadow!`。在正式页面的快捷菜单、Excel、Astra 设置、独立 Logo 页替换首次构建的样式，四处均没有元素使用这五类，样式及尺寸差异均为零。同一目录保留首轮输出重建，120 个资源全部与正式版逐文件匹配。这是本次可复现的构建差异，后续核对需看入口顺序和有效规则。[核查结果](核查结果.json)

## 两项仍可复现的工作台问题

这两项分别用完整的 v0.48.1 旧程序和 v0.51.1 正式程序操作复现。

1. **刚进入工作台，首次点侧栏“表格”的图标中央，有时不切页。** 浏览器记录到按下时的 SVG 节点在抬起前被替换，没有产生 `click`。点击按钮内边距、用键盘 Enter 或再次点击，可打开同一份六个 Sheet 的工作簿。
2. **1024px 宽的主项目沙盘首页，“展开对话”无效。** 鼠标和键盘都触发了按钮，`aria-expanded` 仍为 `false`，对话栏宽度仍为 0。切到“经典”后，对话栏展开为 964px，16 个常用快捷项可见。两版结果相同。本项测的是主项目沙盘首页。
