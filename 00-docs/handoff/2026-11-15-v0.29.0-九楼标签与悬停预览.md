# 九楼标签与悬停预览

正式 UI v0.29.0 / host v0.14.3，2026-11-15。

## 行为

整楼视图在九层右侧显示 **9F-造价中心**。标签锚定九层几何的屏幕投影，随相机移动，并避让左右浮动窗口。采用 Astra 的按钮、颜色、字体和边框，夜间提亮文字。

- 悬停：九楼伸出并沿用 v0.28.0 的近景镜头；标签固定在悬停前的屏幕位置，避免镜头移动使鼠标反复进入/离开。
- 移开：九楼收回，恢复悬停前的整楼镜头，而非重置用户原来的角度/缩放。
- 点击：确认进入九楼；不需要先完成悬停动画。
- 键盘：Tab 聚焦可预览，Escape 取消，Enter 或空格进入；不在 live region 播报反复预览。
- 预览期间暂停自动环游；手动切换视图或拖动镜头接管当前展示。正式进入办公室或使用普通展开视图时隐藏标签。

实现主要在 `public/office-twin/viewer/floor-label.js`。只涉及空间展示，不改变原多人复核、人物拖放、收件人权限、确认发送和光照默认。

## 浏览器支持

优先使用原生 `interestfor` / `interest` / `loseinterest`。只在缺少 `HTMLButtonElement.prototype.interestForElement` 时加载本地 `interestfor@1.0.14` 补充实现，BSD-3-Clause，保留原始压缩代码与 LICENSE/COPYRIGHT/来源说明。没有 CDN、没有修改 npm 依赖或正式依赖保护基线。Edge 实测使用原生 API，未下载 polyfill；其他浏览器的补充分支尚未做现场验收。
