# 星图观察范围与闪白修复

日期：2026-10-09。UI v0.9.40，设计规范 1.0.17。

## 修复内容

1. 观察镜头不再固定贴近节点到 82。按当前节点及直接相邻节点计算包围球，用画布纵横比和视野角确定距离，最低 210；整个范围在持续环绕时仍可见。原显示坐标和业务关系保持不变。
2. 直接邻居保留 0.95 不透明度、文字标签与高亮连线；无关节点淡化。选中球体放大从 1.9 倍降至 1.45 倍，光晕减弱。全屏画布给右侧详情让出空间，宽度变化重新适配关系范围。
3. 修复首次显示标签闪白：Three 在调用 scene.onBeforeRender 之前更新世界矩阵，原实现随后调整标签缩放却未同步矩阵，导致第一帧仍用原始 Sprite 尺寸。修复在回调末尾同步 camera 和 scene 世界矩阵，使镜头 / 球体 / 标签按同一帧状态渲染。

## 原因证据与实际验收

- 在旧 v0.9.39 上搜索“软件”，于 scene.onAfterRender 读取实际 matrixWorld 投影，捕捉 4 个首次可见标签高度约 **5604.88px**；它们 local scale 已缩小而世界缩放仍为 6.6。这一帧超大文字能覆盖星图，下一帧自行恢复。
- 新 v0.9.40 以同样方法采样 **3899 帧**、覆盖 25 个不同标题，最高投影高度 **17.16px**，超过 100px 的异常帧 **0**。包括首次搜索、缩放、关联节点切换、Escape 放回、分栏 / 全屏往返。当前控制台 error 记录为空。
- “生产准备与培训费用”取景距离约 **233.02**；三个直接邻居“专项评价及验收费”“概算指标的费用组成”“软件生产率与功能点单价”球体、名称与关系均显示，自动环绕仍开启；投影坐标位于画布范围内，右侧原文正常。
- 实际浏览器桌面为 1742×956，页面版本 v0.9.40。测试探针已移除，未持久化调试状态。
- 证据位于 `Codex-Temp/galaxy-context-fix/`：`before-projection.json`、`after-projection.json`、`neighbor-framing.json` 与 `final.png`。

两工作区各 `npm test` **175 项通过**，`npm run build` 类型检查及生产构建通过；保留既有大 chunk 提示。新增包围球测试覆盖窄画布、宽画布、双向关系、库已变异的 endpoint 对象、无邻居及数据不变性。
