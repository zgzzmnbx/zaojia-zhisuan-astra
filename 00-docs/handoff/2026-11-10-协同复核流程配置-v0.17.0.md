# 协同复核流程与配置 v0.17.0

日期：2026-11-10。UI v0.17.0，正式宿主保持 v0.11.0。

## 使用

在原来的“准备同事复核”或“查询复核进度”卡片中点击“复核流程”。工作台返回沙盘，打开无背景遮罩的悬浮窗口。拖动标题栏移动，右上角放大 / 还原；窗口受当前左侧聊天和右侧信息卡的实际边界约束，两侧仍能操作。空间不足时提示调整两侧宽度，不强行覆盖。

流程沿当前成果分支到飞书、WeAct，展示每位复核人并汇总。点击平台 / 人员进入配置或意见；“流程 / 配置（详情）”切换视图。本次分配与已有任务分开显示；准备新轮次不会把过去的通过状态带入本次配置。窗口关闭仅关闭视图，原聊天中的本次人员、时间、说明继续保留，刷新浏览器仍沿用原来的表单生命周期。

可配置平台启用、个人私聊 / 工作群、群、复核人员、截止时间和说明。与原表单共用 ReviewConversation 状态及 review-flow 校验 / 顺序投递，发送仍需明确确认范围；不新增串行审批规则、不通过画布拖线触发对外发送，不强制重算。
