# v0.36.0 空闲走动与三级名牌

日期：2026-11-17。正式 UI v0.36.0 / host v0.15.0。

## 交付行为

- 无待办且未选入本次复核的人员，在所属房间的通道散步、平缓转向并短暂停留；有待办的人员坐在工位打字/看屏。完成、通过、退回、取消等终态仍保留在详情中，不计入待办。
- 根据已有平面数据一次性建立房间网格，保留身体净距，排除墙、柱、桌椅和家具。路线只在同一连通区域内搜索，遇人阻挡后退回网格节点重新择路；不跨墙、不随机在整层任意取点。
- 演示样本保留六名有任务、两名空闲；有宿主任务的人员不再额外叠加样例任务。真实任务状态、收件人、确认与发送流程未改，动画不是实时人员定位。
- 名牌按投影到屏幕的1.7米人物参考高度分级：低于13px隐藏，超过17px进入姓名档，达到45px进入详情档，详情降到40px以下才退回姓名档。边界迟滞防抖；各档仍做重叠避让，近景标签高于头顶。
- 点击模型、姓名牌或右侧人员行打开完整人物卡：姓名、工种、擅长审核、当前状态、工位、任务状态和已有备注。工种/专长未提供时保留“待补充”，不编造真实资料。
- 拖动过程中暂停散步并切换悬提姿态；取消后继续空闲活动，选入任务后恢复工位工作。左右两个拖放入口继续有效。

## 性能与验证

- 行走复用原头、上身、手臂和材质，仅首次需要时缓存站姿腿部；每名步行人物18次绘制，原坐姿和悬提仍15次。没有逐帧重建网格或增加物理引擎。
- 运动沿用可见时钟；人物动作开关、减少动效、隐藏和卸载保留原停止/释放机制，不按后台经过时间追赶。
- npm test：509项通过。包含任务终态、三级名牌迟滞、通道障碍约束、暂停/长时间恢复、行走/悬提/坐姿切换和网格复用。
- 正式基线独立构建通过；未包含其他线程的未提交沙盘/Gork改动。全量核对399项构建源码及377项既有资源；模型、烘焙、光照参数未改。
- 内置浏览器实测：远景10.73px全部隐藏，中景26.20px仅姓名，近景158.95px展示任务与动作；完整人物卡、两人散步、暂停前后位置相同、取消拖拽、3D鹿学文拖到右侧恢复typing并出现演示标签、钱冬冬标签拖入左侧恢复typing并出现演示标签均通过。未触发任何平台实发。
- 本机验收画面可见60 FPS，仅为本轮观察值，不宣称所有设备或视角稳定60帧。截图 `Codex-Temp/office-idle-labels/near.png`；测试、构建、资源基线与发布证据在同目录。
