# 办公室中央楼层看板

正式 UI v0.30.0 / host v0.14.3，2026-11-15。

## 内容与统计口径

用户标出的中部上、下两块电梯核心筒区域改为平贴楼层的显示面，上方展示“天津运营中心 / 09F / 造价中心”，下方为当前成果复核看板。三维文字随视角、缩放和九层移动，使用 Astra 主题色与本地字体，日夜分别保持纸白和深色面板。

接入人员按当前目录稳定 ID 去重，不代表全楼实际编制或实时在岗人数。真实复核任务沿用当前成果已有接收人/平台记录，按复核人次计数，不声称是部门全部项目数。已通过、已退回与待处理按参与人状态统计，不借任务整体状态覆盖个人状态；演示任务单独计数，不混入真实完成率。无成果显示横线，回执失败保留快照并提示“状态待刷新”。

## 实现与性能

- 新增 `public/office-twin/viewer/office-board.js`，只读取已有业务快照，没有写接口、轮询或独立动画循环。
- 仅在加载实例隐藏指定 CORE 内部节点，外围墙、核心筒地板、办公区、工位与源 GLB 文件保持。`navigation-motion.js` 排除替换节点，避免楼层淡入淡出复活旧设施。
- 两张 1536×704 CanvasTexture，主场景只增两次绘制；数据或主题变化以及字体就绪时更新，同内容快照不重绘。场景卸载释放材质、纹理、几何与可访问文本。
- 看板独立于日夜烘焙/受光材质，夜景刷新不再次改写其文字颜色；辉光遮挡使用现有深度路径，不给整块面板泛光。
- 保留普通 HTML 的可访问摘要。modern-web-guidance 查询的 canvas 内容暴露指南需要 Origin Trial，本轮未启用实验特性，采用标准 CanvasTexture + HTML 摘要。
