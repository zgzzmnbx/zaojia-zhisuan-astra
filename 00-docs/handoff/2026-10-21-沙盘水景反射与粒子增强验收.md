## 水面反射

水面实例仍复用 A-C 材质，不替换模型或材质对象；本地 `water-sky.png` 生成的 PMREM 环境图继续作为 `envMap`。

| 参数 | 日间 | 夜航 |
| --- | --- | --- |
| 基色 | `#2f86ad` | `rgb(0.018, 0.075, 0.15)` |
| roughness | 0.055 | 0.07 |
| metalness | 0.5 | 0.58 |
| envMapIntensity | 1.3 | 0.9 |
| normalScale | 1.9 | 1.7 |

粗糙度降低与环境反射提高后，天空环境图在波纹法线上的高光更集中；低角度（22°）可见长条反射，高角度（45°）保留移动亮斑。关闭水景时逐项恢复 A-C 的 roughness / metalness / envMapIntensity / 光照图 / AO。

## 水面粒子

- 从 `lightingMaterials.waterMeshes()` 的真实河面三角面按面积概率采样 280 个世界坐标点，仅向上偏移 0.03–0.08，不使用随机平面撒点。
- `ShaderMaterial` 加法混合、`depthWrite:false`；日间 `#eafcff`、夜航 `#8bdcff`；点大小 1.7–4.3，透明度 0.95。
- 顶点着色器提供缓慢闪烁与轻微上下浮动；无贴图、无后处理、无额外 RAF。
- 随「水景质感」显示；减少动效时冻结时钟并保持静止可见；关闭、离屏、页面隐藏沿用场景停算；销毁时移除组并释放几何与材质。
- 纯色棚拍日间沿用既有门禁，不叠加水景与粒子；夜航可单独启用。
