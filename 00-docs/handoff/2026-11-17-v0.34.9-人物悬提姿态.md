# 人物拖拽悬提姿态

UI v0.34.9 / host v0.15.0，2026-11-17。

原拖拽仅冻结最后一帧坐姿，现用专门悬提姿态：腿向下伸直并略分开、脚尖略下垂，双手离开键盘垂到身侧，头轻微向下。既有鼠标抓取点与拖动平面保持；松手、Esc、pointercancel、窗口失焦等原结束路径清空dragPosition时立即恢复坐姿。动作暂停与减少动效不阻止交互姿态更新。

保持每人15个mesh、8人120个mesh。裤腿与鞋沿用合并网格，初始化时缓存坐姿/悬提两组位置和法线，仅状态改变时上传并更新包围盒；没有每帧重建几何、增加灯光或改业务选择代码。共享原几何不修改，其他人物保持坐姿。

505项测试与正式基线构建通过。新增回归覆盖双腿伸展、手离键盘、重复拖动不重传网格、松手精确恢复、共享资产不变及网格数。Edge真实鼠标检查暂停动作下拾取、Esc、框外松手、pointercancel，石萌与演示人员框内标签和明暗主题；只有owner进入原宿主选人事件，未发送真实消息。使用隔离工作区响应并拦截业务写入。

证据位于`Codex-Temp/office-lift-pose/`：`lifted-light.png`、`lifted-dark.png`、`drag-check.txt`、`tests.log`、`build.log`及正式发布记录。正式发布使用实际0.34.8基线，其余未发布改动保留；回滚目录与SHA256见该目录`publication.json`。
