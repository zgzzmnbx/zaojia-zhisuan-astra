# 办公室夜景局部照明

正式 UI v0.29.1 / host v0.14.3，2026-11-15。

## 问题与改动

原室内夜景仍以较强的均匀填充光叠加白天烘焙底色，造成背景变暗、地面和家具仍像白天。参照正式 `03-Src/studio/project-sandbox/night-city.mjs` 的低亮建筑底色与局部发光方式，降低室内环境光，按 `office_layout.json` 的真实房间范围生成 32 处灯具和光池。办公区冷色，会议、接待及核心交通区偏暖，储藏间保留暗部。光池在房间边界裁切，法线与原烘焙明暗参与受光，显示器保留蓝光及工位近距离溢光。

新增 `interior-light-plan.js`；`night-environment.js` 接入房间灯位、灯具和环境亮度。日景着色分支没有修改，灯具只在夜间显示。新增“夜间环境亮度”滑块，现有“室内照明”控制灯具和局部光池，“屏幕蓝光”仍单独控制。旧保存记录自动补齐新字段，恢复默认只预览，未覆盖用户保存参数。

这是既有白天烘焙模型上的局部显示照明，未重新烘焙物理夜景，不宣称实时阴影或物理全局光照。原模型、复核权限、确认发送、人物交互与业务数据均未改动。
