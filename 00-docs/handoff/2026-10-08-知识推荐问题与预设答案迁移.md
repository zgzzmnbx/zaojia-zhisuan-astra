# 知识推荐问题与预设答案迁移 · UI v0.9.36

本轮按用户明确要求补齐 `#知识库` 推荐弹窗、推荐题发送、前四道题的原版预设答案与小标记。沿用 DESIGN.md 1.0.14 和 daisyUI；原工程只读，活动运行目录与现有业务数据保持。

## 来源与适配

来源为智算 2.0 的 `AgentComposer.tsx`、`agentWorkspaceUtils.ts`、`KnowledgeQuestionSuggestions.tsx`、`knowledgeDemoQuestions.ts`、默认问题设置及 `backend/app/knowledge_demo_answers.py`。四份主要原文件 SHA256 见 `Codex-Temp/knowledge-recommendations/source-provenance.json`。预设数据已在 Astra 冻结引擎内，本次恢复主聊天消费及展示，不重复改写引擎。

- 输入单个 `#` 后空格补成 `#知识库：`；仅未填写问题的知识前缀展开推荐弹窗，18 题、每组 6 题。
- 选题只填入草稿并恢复焦点，发送才查询；关闭或 Escape 保留草稿。分页、逐条编辑 / 保存 / 恢复默认与专业入口共用原偏好。
- 保存前读取最新偏好，只修改当前题，保留其他设置及其他行未保存的编辑。测试修改已恢复，完整偏好与验收前一致。
- 前四道题显示原小圆点；识别依据是原问题文本，编辑成普通问题后不误标。预设题直接读取原解答，不依赖模型或所选增强引擎，也不修改引擎偏好。
- 回答保留原 Markdown 表格、来源和第 4 题的 16 根柱状图。原数值、单位、阶梯区间和最高值不变；图表使用主题色，尺寸显式覆盖全局 SVG 图标规则。
- 未手动指定知识范围时，选推荐题使用当前可用库，包括造价通用资料；手动选择的范围（包括空选择）保持。

## 未关闭门槛

当前宿主 `model_configured=false`，普通题使用已有本地原文检索降级，不伪造模型综合答案。普通题生成完整自然语言 / 表格答案的接口路径已保留，但需要独立模型凭证后的真实验收；本轮没有复制凭证或调用外部模型。前四题预设答案已完成，不受此门槛影响。T11 完整 AI / 双路对比验收及全量迁移不因此关闭。

本轮无宿主重启、业务重跑、自动发送、推送或部署。源码及验收文档同步到现有活动 worktree，运行库未移动。
