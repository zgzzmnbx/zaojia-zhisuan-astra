## 实现与范围

1. 参考 [pmndrs/env](https://github.com/pmndrs/env) / [Drei Lightformer](https://github.com/pmndrs/drei/blob/master/src/core/Lightformer.tsx) 的 HDR 发光面方法，使用原生 Three.js 创建主软箱、侧向条灯、顶灯和低强度补光。首次加载时生成本地 PMREM，随后释放临时灯板几何；不上传模型，不从外网读取环境图，不引入 React Three Fiber。
2. 参考 [Three.js PCSS](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_shadowmap_pcss.html) 的遮挡搜索与半影过滤；针对正交主光换算世界尺度。16 次遮挡搜索、32 次滤波，2048 阴影图，近接触较明确、远离接触处渐柔。使用本场景材质回调串联原染色与装配，不改全局 ShaderChunk、不新增整场后处理。
3. 曝光由 1.03 调至 1.08，背景混白由 0.42 调至 0.72；减少旧烘焙填光及主光强度，为棚灯与反射留下层次。储罐 / 管道粗糙度为 0.26 / 0.30，金属度仅 0.12 / 0.08，保持涂层观感。
4. 原 v2 GLB、几何、UV、角色映射、模型轮廓、装配时序、业务染色与聚焦辉光保持。夜航保留原 HDR / 光照 / PCF；关闭增强恢复原基础画面。原日间烘焙不照亮悬浮构件。

核心文件：`studio-environment.mjs`、`soft-shadows.mjs`、`render-profile.mjs`、`lighting.mjs`、`lighting-materials.mjs`、`scene.mjs`，均位于 `03-Src/studio/project-sandbox/`。来源与适配说明见该目录 `SOURCE.md`。
