## 工具与恢复

`tools/import-legacy-history.py` 默认只预检。独立 runtime 路径必须显式传入，`--apply` 才写入；`--model-audit` 同时导入不可变调用元数据。

```powershell
python tools/import-legacy-history.py --source-runtime 'D:/Codex-Temp/260612-【ai大赛】-管勘智算-V2.0/Codex-Temp/runtime' --destination-runtime '03-Src/engine/Codex-Temp/runtime' --model-audit --apply --report Codex-Temp/history-import-result.json
```

SQLite 只读快照读取原库，目标事务写入前备份。路径越界、未授权文件类型、身份冲突和不同内容文件均拒绝覆盖。导入回执记录来源、文件哈希和已导入 ID；重复执行不重复计数，也不覆盖在 Astra 中继续编辑的历史副本。运行文件只复制业务所需资料，不复制整个旧 runtime。

备份与回执位于目标 `astra-history-imports/b9bdd12c64643516/`。首次项目台账备份对应 `history-import-result.json` 中的 `backup` 字段；模型审计备份对应 `history-audit-import-result.json`。如需撤销，应先停止 Astra 写入、备份导入后新增业务，再根据回执定向移除导入 ID；只有明确可以放弃备份后的全部台账变化时才整体恢复数据库。不可直接用旧库覆盖当前在线库。

导入后的数据、备份、原始文件和完整报告均位于 Git 忽略目录，不上传 GitHub；Git 只保存工具、测试和汇总文档。
