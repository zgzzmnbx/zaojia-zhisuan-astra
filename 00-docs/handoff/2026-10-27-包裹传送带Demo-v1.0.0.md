# 包裹传送带 Demo v1.0.0 验收记录

日期：2026-10-27。状态：独立视觉候选已实现，待用户确认；未接入正式业务主流程。正式版本仍为 v0.11.19，未提交或推送 Git。

## 交付内容

- Blender 5.2.2 LTS 后台建模：柔白包裹、主题蓝交叉束带、纸质标签/条码、银灰传送带、白色护栏/支架、七个收件门架。
- 可编辑源工程：`05-视觉识别/02-3D场景/parcel-conveyor-v1/parcel-conveyor.blend`。
- 原生关键帧运输动画导出至 `conveyor-parcel.glb`，65 个网格，约 49.3 秒；包裹沿弯道转向并在七站停靠。建模脚本、时间表、Cycles 渲染一并保留。
- 真实网页：http://127.0.0.1:5189/parcel-demo/index.html 。全景、运输近景、模型特写、跟随视角、暂停、重播、变速、拖动时间、显示/隐藏方案。
- 在现有 V11 白色沙盘中展示，不加载归档的旧版沙盘模型。正式入口不引用本 Demo。

## 范围与参考

用户提供的视频截图用于确定“实体包裹沿高架传送带逐站投递”的视觉机制。X 页面返回访问限制，无法确认完整视频细节；未下载或复制视频模型。模型由本项目脚本新建，路线取自既有 pipeline-route.json 并局部加宽间距。

七站展示顺序不等于实际业务依赖，演示时间不等于业务完成率。无 /api 请求，不更改任务、成果或个人偏好。静态带面尚无履带机械滚动；未制作开箱、建筑内部接收、真实事件触发或夜间材质。这些不作为本轮已完成能力。
