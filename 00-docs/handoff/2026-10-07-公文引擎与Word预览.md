# 公文引擎与 Word 预览接入

2026-10-07，源码 v0.7.0，在 `codex/astra-ui-handoff-local` 独立工作区实施。

## 接入范围

- “文字报告”直接渲染真实 DOCX，不再通过提取段落的 HTML 冒充 Word。取消独立“Word 分页预览”按钮、报告内重复标题 / 说明及底部工具入口；页签下只有 44px 工具栏，包含文件名、适宽 / 缩放、下载和简短预览口径提示。
- 添加文件与资料库支持 DOC、DOCX、MD、Markdown；Excel 编制入口和当前工程结果保留。Word 可直接预览，Markdown 展示原文结构，旧 DOC 转换后预览 DOCX。
- 公文转换作为专业工具中的一个小功能，不建立另一个完整应用。只有打开对应文稿时，聊天末尾出现当前文件的临时转换卡；离开即隐藏，不重复追加历史提示。
- 点击转换后调用真实核心，生成独立公文版和检查 JSON；原文 / 公文版切换，预览与下载引用同一成果。转换成功才写聊天成果卡；复杂对象的复核提示保留。

## 预览来源

从原工程复用 `DocumentPreview.tsx`、预览工具函数、CSS 与深色显示投影；去掉与原项目校对、Mantine 界面版本和偏好存储的耦合。控件按 Astra 主题重写，主题只投影显示，不修改原 DOCX。

锁定 `@file-viewer/react@2.4.0`、`@file-viewer/renderer-word@2.4.0` 与 `@file-viewer/docx@0.3.27`，复用原四项补丁：分页下边距、表格间距、中文字体、中文 / 西文字体槽位。每次构建运行版本 / 补丁校验并同步本地 Worker，避免旧 Worker 与新主渲染器不一致。第三方许可证保留在 `public/file-viewer/licenses/`，源文件哈希见 `gongwen-preview-source.json`。

仅允许文档内嵌字体的本地 data/blob 来源，仍维持 `connect-src 'self'`。本轮未将字体二进制、私人样例或生成文档放入 Git。
