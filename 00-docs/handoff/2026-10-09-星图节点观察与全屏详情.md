# 星图节点观察与全屏详情

日期：2026-10-09。UI v0.9.39，设计规范 1.0.16。

## 交付行为

- 滚轮、放大与缩小按钮保持自动环绕；搜索、手动拖动、镜头过渡分别控制运动，不再把滚轮当成拖动暂停。
- 点击节点用 480ms 缓出镜头推近，并放大有立体高光的球体、显示观察光环、淡化周围节点。到位后围绕该节点缓慢旋转。
- “返回星云”“放回星云”、空白处点击或 Escape 恢复进入观察前的镜头位置。首次整体视角只存一次，连续观察关联节点仍可回到原视角。
- 全屏右侧浮窗显示当前节点原文、来源依据与关联节点；普通分栏保持原有聊天阅读入口。全屏往返保留选中与图实例。
- 正文请求按节点 ID 校验，切换 / 关闭取消请求，失败提供重试。装饰光环与标签不参与射线命中，避免误选后面的节点。
- 继续复用现有 3d-force-graph / Three 依赖，没有新增引擎。减少动效或手动暂停时直接定位；隐藏 / 离屏停止运行，退出销毁。
