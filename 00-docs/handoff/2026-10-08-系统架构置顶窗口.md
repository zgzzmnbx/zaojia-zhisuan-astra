# 系统架构置顶窗口 · UI v0.9.31

按用户浏览器批注，系统架构直接打开原生 `dialog.showModal()` 顶层窗口，覆盖工作台。标题、原图 / 动态横版切换、示意标识、独立打开与关闭合并到一条 44px 工具栏；取消外层导航、成果标题栏及常驻说明占用。

架构窗口独立于工作台呈现状态，不通过切换成果路由覆盖原面板。关闭卸载架构 iframe，恢复触发按钮焦点、原布局、草稿与明暗偏好。保持每次显式打开默认动态播放，支持手动暂停；后台暂停沿用原图逻辑。窗口遮挡时停止输入区与悬浮 Gork，避免遮挡图及不可见动画。

两份 Astra 独立图资产仅追加内联 Escape 消息适配，不修改源工程。图内 Escape 发给当前同源父窗口；接收端同时验证消息类型、当前 iframe 的 Window 与 sandbox origin，其他窗口伪造消息无效。沿用既有 CSP、sandbox 与离线资产，不新增外部请求。

## 验证

- 两工作区各 `npm test` 158 项通过，类型检查与正式 `npm run build` 通过；已有包体警告不影响构建。
- 1742×956：置顶窗口 1742×956，流程图 iframe **1742×912**，约 95.4% 视口面积。
- 1366×768：置顶窗口 1366×768，流程图 iframe **1366×724**，约 94.3% 视口面积。
- 浏览器实际 `:modal` 验证，底层布局不切换；从专业能力面板打开后返回同一面板，原草稿保持。
- 明暗实际 DOM 与存储偏好核对：窗口临时深色，关闭恢复亮色；已有深色偏好关闭后仍为深色。
- 系统减少动效开启时，按已确认的架构特例默认播放；实际 seek 调用随时间推进，暂停后停止推进。切换两图及重新打开默认动态通过。
- 关闭按钮、iframe 内 Escape、焦点恢复和 iframe 卸载通过；其他窗口伪造关闭消息被拒绝。页面与控制台错误均为 0。
- 主目录启动器 `-CheckOnly` Ready，活动工作区与实际业务 runtime 不变；前端构建更新无需后端重启。
