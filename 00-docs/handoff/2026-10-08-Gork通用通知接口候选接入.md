# Gork 通用通知接入与调试验收

记录 v1.0.0 · Astra v0.9.22 · 2026-10-08。保留原候选文件名，内容已更新为实施记录。

用户在控制台线程 01a102d1-f432-74a3-9f38-31f22522edb9 授权实施通用接口、两边配合、阶段设置和手动调试。Gork 负责来源登记、权限、队列与文字 / 表情 / 语音输出；Astra 判断真实业务阶段并提供消息，双方各自维护源码。

## 使用与启用

左下角设置 → **机器人联动** → **阶段设置 / 调试**。阶段设置提供 13 个阶段的启停、表情、单次 / 循环、持续状态 / 短提醒、文字、语音、时长、输出端、优先级和有效期。本地合成预览不会发送通知，切换分类保留草稿、停止隐藏预览；保存校验 revision，多窗口冲突不覆盖。

首次自动通知与声音均关闭。控制台须加载 v0.20.28-dev 或后续兼容版本，登记并启用 astra 来源及允许的显示端、声音端和优先级；凭据保存在活动工作区忽略文件 config/astra-gork-token.local.json，仅后端读取。旧任务哨兵与同 source 新推送互斥。音色、音量和云语音许可仍由控制台用户设置。

## 手动调试步骤

1. 在阶段设置保存配置，进入调试、选择阶段，点击 **发送阶段信号**。
2. 自动通知关闭时也可手动调试，仍须 Gork 来源启用与权限；未保存的草稿不能发送。
3. 匹配完成可选模拟金额，单位为元，文字与语音明确标注模拟数据；不读取真实项目金额。
4. 查看事件 ID、递增序号，以及桌面 / Watch / 声音的独立回执。202 入队或系统播放回执不等于实际听见。
5. 持续状态可手动报活，报活不重复语音；不报活按 lease 失联复位。**取消调试**仅取消当前独立调试任务；下一次发送使用新 attempt。远端未确认取消时显示等待重试。

调试任务为 debug-UUID，不写真实业务台账，不修改价格、风险或报告。隐藏调试页停止回执轮询；调试持续状态不自动报活。

所有前端请求只连接同源 5189；后端 SDK 正式仅连接本机 8766。

| 方法与路径 | 含义 |
| --- | --- |
| GET /api/astra/gork/notifications | 设置、阶段目录、默认值、来源状态、最近回执、旧哨兵只读状态 |

## 阶段与生命期

| 阶段 | 真实来源 / 边界 | 默认形式 |
| --- | --- | --- |
| conversion_start | 当前资料转换开始 | working 持续状态 |
| match_start | 当前规则匹配开始 | working 持续状态 |
| match_completed / match_failed | 本 attempt 实际完成 / 失败 | happy / confused 短提醒 |
| warning_start | 当前风险检查开始 | working 持续状态 |
| warning_completed / warning_found / warning_failed | 实际检查结果，未知数量不转零 | happy / confused 短提醒 |
| report_start / report_generated / report_failed | 最终风险报告生成及真实成功 / 失败 | thinking 持续状态 / happy 或 confused 短提醒 |
| review_requested / review_sent | 发起与真实送达分别处理 | curious / happy 短提醒 |

复用既有事件发布器和当前请求生命期，不修改冻结引擎。持续状态默认每 10 秒报活、30 秒失联复位，仅真实请求仍运行时自动报活；报活不重复语音。普通短提醒 TTL 30 秒，完成 / 失败默认 90 秒，可配置。

匹配完成只使用本 attempt 的已固化费用汇总快照，保留含税口径、元单位和重算未确认提示；不从当前可变工作簿补写历史金额。最终报告成功只来自显式最终风险 Word 生成，普通匹配 Word 更新不能替代它。

首次启用、重启和重新启用建立当前基线，不补播历史；网络工作独立线程，不阻塞业务发布。新阶段替换旧未发送开始状态；同载荷重试、过期不补播。取消仅限本 source，未确认取消持久重试，人工录音和其他来源优先级保持。
