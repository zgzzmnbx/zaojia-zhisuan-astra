# v0.35.0 左侧拖入复核与浮动卡片

日期：2026-11-17。正式 UI v0.35.0 / host v0.15.0。

## 行为与边界

- 3D 人物与原生人员标签/列表均可拖到左侧智算对话窗口。进入落点时高亮，松开加入当前成果；右侧成果卡落点继续可用。
- 右侧成果及已选人员、任务/人员/空间浏览区分为两个独立浮动卡片。任务和人员使用内部卡片，保留沉浸式背景、明暗主题、滚动、收起展开及画面设置。
- 悬提动作、松手和 Esc 恢复原坐姿保留。拖动不发送消息；石萌沿用原宿主选人，其他人仅演示分配，原确认与发送规则未改。
- 跨窗口消息校验 origin、source、context 和 revision；原生拖放仅为已接受的 copy 放行一秒完成窗口，解决 dragend 先于父窗口通知的时序问题。
- 办公室 iframe、改动脚本及样式带 v0.35.0 标识。正式页面已核验加载新模块和独立卡片，避免旧缓存混入。
