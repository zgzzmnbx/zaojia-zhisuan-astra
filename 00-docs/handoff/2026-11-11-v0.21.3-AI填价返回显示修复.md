# v0.21.3 AI填价返回显示修复

日期：2026-11-11。前端v0.21.3，宿主仍为v0.14.1。

## 复现与修复

用户反馈：匹配后进行后续操作，再点击单元格AI填价，有时只看到“重算公式与报告”，AI内容不显示。

独立正式副本中确认了一条可复现原因：先收起左侧对话，再从表格点击第6行AI填价。候选接口与分析正常返回，但填价入口只把布局切回分栏，没有清除独立的“对话已收起”状态。因此新分析已经存在，仍不可见。修复前浏览器断言为 `AI analysis is created but the conversation remains collapsed`。

修改 `03-Src/studio/App.tsx` 中的 `beginRowAssist`：显式展开对话，并沿用原有新卡片定位与表格分栏逻辑。程序行为改动只有这一处；公式、价格、系数、模型调用、标准答案和成果版本校验保持原样。

“重算公式与报告”本身仍可能是人工修改后的正常提示。没有通过隐藏提示或清除待重算状态来处理显示问题。正常展开状态下的连续后续步骤未复现同样的内容缺失，不能据此声称已排除全部其他间歇情况。
