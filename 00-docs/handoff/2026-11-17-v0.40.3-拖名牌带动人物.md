# v0.40.3 拖名牌带动人物

2026-11-17 · UI v0.40.3 / host v0.16.0。正式宿主 PID 26000 保持。

## 行为

- 头顶名牌使用原三维人物拖拽控制器，指针捕获在被拖动标签上；保留7px启动阈值及初始抓取偏移，人物位置随指针在原相机平面移动。
- 人物使用现有lifted姿态，标签活动显示“拖动中”；标签自身已跟随人物，不显示第二个姓名浮标。
- 点击与Enter仍打开详情；拖入右侧成果卡或左侧对话仍走原togglePerson与上下文校验，非本人只加入演示候选。右侧人员列表原生拖拽与已选人选×/拖出取消独立保留。
- 松手、Escape、指针取消/捕获丢失、失焦及卸载均释放人物并恢复相机控制。人物动作、材质、光影、任务和发送业务保持。
