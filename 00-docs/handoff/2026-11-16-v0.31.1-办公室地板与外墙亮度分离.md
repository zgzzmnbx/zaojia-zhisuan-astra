# 办公室地板与外墙亮度分离

正式 UI v0.31.1 / host v0.14.3，2026-11-16。

## 修复

glTF 底板含多个图元叶节点，原分类只匹配叶节点名，部分底板落入 shell；房间地板则与普通 interior 混合。本轮在合批前向父节点解析九层底板、核心区、走廊和房间地面，统一标为 floor；独立 shader uniform 控制日间亮度，静态合批和材质克隆保留角色。52 个地板渲染节点正确分类。

新增“楼层地板亮度”（40–180%，默认145%），“主楼亮度”改名“主楼外墙亮度”。室外地面、室内家具、外墙各走原亮度。旧个人方案缺少地板字段时，继承其主楼亮度一次；调节后与外墙独立，保存/重载/恢复默认使用既有机制。夜间地板进入已有室内局部照明，不受日间两项亮度控制。未增加贴图、实时灯或新循环，未重烘焙。
