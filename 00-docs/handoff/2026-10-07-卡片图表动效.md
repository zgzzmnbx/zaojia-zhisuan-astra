- UI v0.6.12，后端 v0.6.2 不变；独立 worktree，原工程只读。
- 统一实现：`03-Src/studio/entrance-motion.ts` 与 `entrance-motion.css`，由 App 安装和卸载。没有新增依赖、RAF 循环或定时器。

## 动效设计与范围

| 对象 | 表现 | 时长 |
| --- | --- | --- |
| 对话 / 项目 / 风险 / 工具 / 资料 / 看板指标卡 | 淡入、向上轻移 10px | 320ms |
| 项目信息、设置 / 连接等弹窗、看板详情抽屉 | 淡入、轻移 12px、微缩放 | 360ms |
| 费用与匹配进度环图 | 从起点描绘真实比例，中心文字轻显 | 740ms |
| 费用横柱、匹配覆盖、风险条 | 从左侧生长到真实宽度 | 680ms |
| 看板图形 | 从左向右揭示，保留既有交互 | 720ms |
| 金额 / 对话的展开明细 | 轻移淡入 | 320ms |

同批元素最多错峰 140ms，使用减速曲线。金额与业务状态立即显示真实值，不做滚数和虚假成功进度。原看板 Recharts 自带动画关闭，避免叠加；专业 iframe、Gork、能力星图保持各自原有动效策略。

## 状态与资源边界

- 单个 IntersectionObserver 在首次可见时播放；滚动离开结束，再滚回不重复。明确重开面板 / dialog / 明细允许重播。
- MutationObserver 只关注节点增删和 hidden / open，不观察主题、文本输入或 style；不重建组件、表格、会话和草稿。
- 动画完成后释放；离屏、页面隐藏、开启减少动态效果、节点移除、App 卸载时取消。基础样式永远是最终可读状态，浏览器缺少动画能力时直接静态显示。
- 系统减少动效同时取消正在执行的入场，保持金额、按钮与焦点可用；不覆盖用户先前对 Gork 的明确播放偏好。
