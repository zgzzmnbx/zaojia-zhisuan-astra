## 能力边界

- V11 的全部 20 个材质继续采用 `KHR_materials_unlit`；PNG、UV、细面 `COLOR_0` 和几何均保持源资产。NoToneMapping、曝光 1、sRGB 输出、toneMapped=false，未追加 AO、环境光、雾或实时阴影。
- V11 保留当前任务的七区标签、选择、自动聚焦、真实状态、详情和原业务按钮。任务进度在原进度卡表达；**没有把任务染色、实时射灯或实时水面叠进冻结材质**，这些能力明确由原效果模式提供。相关原光照参数在白色版中隐藏或禁用，原值保留。
- 用户选白色版时进入夜航，临时显示原模式并提示原因；回到日间恢复白色版。初次构件装配也使用完整原模式，归位后恢复；不移动冻结 V11 构件。
- V11 关闭城市同时隐藏 `background_city / background_street / background_ground`，换干净地面；七座主体和 `hero_site` 保留。原模式可选城市为私有干净几何与实时材质，删除配景顶点色，不使用烘焙地面/贴图。
- 主体、场地已有的间接光无法通过开关重新烘焙。139 栋城市为合并网格，不提供逐栋编辑。
- 景深编译/渲染失败会明确提示并回到清晰直出；模型加载失败保留上一模式；上下文丢失可重试重建。重试只重建表现层，不重跑业务。

| 原模式前后 | 固定机位的 camera/target/frame、renderProfile、lighting、effects、solid、water、paint、主题与 Logo 状态一致；截图留存。水面等时间效果和界面版本文字不作整页像素相等声明 |

| 后台与离屏 | 独立 Chrome CDP `noDefaults:true`，确认 `document.hidden=true` 后两模式帧计数不增长；离屏停止，前台恢复通过 |
| 减少动效 / 静止 | 白色版静止后停 RAF；减少动效停环游；非活动原模式帧数不增长 |
| 卸载与返回 | 切换简约视图卸载后，两套沙盘 context 均 lost、几何 buffer 释放；重新进入恢复保存模式，不重播已领取的装配 |
| 重复切换资源 | 10 次往返后 V11 仍为同一上下文、19 个 texture 句柄 / 100 个 buffer / 6 个 framebuffer；未持续增长。原模式随夜景后处理释放部分资源，未逐次增长 |
| 单元 / 回归 | `npm run test:sandbox-v11` 61/61；`npm test` 387/387；TypeScript 与 `npm run build` 通过 |
| 浏览器错误 | 正常场景无脚本 / shader 错误。受控 503 为预期故障，单独记录，不混记为正常运行错误 |

短时性能采样：高质量水面约 **60.7 FPS**；V11 景深 40% 环游约 **60.3 FPS**，各为约 3 秒采样。测试是目标机器实际 GPU 渲染，不是云端 mock；窗口、负载、DPR 不同会改变结果，不是帧率保证。

在原模式已载入、浏览器首次请求 V11 的条件下，点选到 V11 首次绘制约 **1373 ms**。测试资源由本机候选文件拦截提供，包含浏览器解析、GPU 上传与编译；不是公网下载或任意机器的冷启动保证，也不包含首次原场景装配等待。

11 张未压缩贴图按 RGBA8 + 完整 mip 链估算约 **154.7 MiB**；本视口景深颜色/深度目标另约 **34.8 MiB**，还需加几何、驱动开销和保留的原模式资源。WebGL 没有提供可靠的全进程 GPU 显存数值，此处是尺寸推算，不把纹理计数当作实际显存。切换缓存两套实例换取即时返回，卸载再释放；不是轻量资产优化版。
