# 沙盘储罐背光面环境光修正验收 · v0.10.77

日期：2026-10-22。任务：主光改为沿初始视角后，三根油罐的背光面仍明显比楼面黑；按实际环境光校正背光面亮度，并保持主光方向与已验收效果。

## 原因

| 项目 | 结果 |
| --- | --- |
| 主因 | 「水景质感」的 v2.2 建筑 AO 叠加到 `coated-tank` / `coated-pipe`，强度日间 `0.9` |
| 放大条件 | AO 只衰减间接光；储罐背光面没有直射光，仅剩环境光，被 AO 整体压暗 |
| 对比楼面 | 白墙为漫反射材质，且正立面有主光，视觉上受影响小 |
| 浏览器隔离 | 关闭「水景质感」后 AO 数从 62 降到 0，同一机位储罐背光面立即接近楼面亮度；主光、储罐粗糙度 / 金属感 / 环境反射均未变化 |

## 改动

| 文件 | 改动 |
| --- | --- |
| `project-sandbox/lighting-materials.mjs` | 本地 AO 仅用于建筑基底；`coated-tank` / `coated-pipe` 跳过 AO，日间与夜航一致 |
| `tests/sandbox-local-surface.test.mjs` | 增加储罐、管件夹具，断言日间 / 夜航均不接收建筑 AO，墙面仍保留 `0.9` / `0.55` |

墙面、地面、玻璃的 AO、水景法线 / 天空 / 280 个光点、主光 `38° / 42°`、太阳强度 `6.9`、环境反射与储罐材质参数均未改动。关闭「水景质感」仍逐项恢复原材质；已保存的开关偏好不受影响。
