# 沙盘光照试调与第一轮视觉样板

日期：2026-10-21。UI v0.10.61。当前状态：候选样板已接入实际 5189 产品，**等待用户看图确认，正式默认未改变**。

## 本轮范围与入口

以用户附件下半图为视觉目标，第一轮调整主光方向、明暗、白材质和管罐反射。原 GLB、几何、UV、区域身份与装配组件未修改；业务数据和操作入口保留。本轮没有引入路径追踪、屏幕 AO 或新的全场后处理。

入口：沙盘右上角 **视图 → 光照试调 → 载入参考样板**。可在「当前效果 / 试调效果」间切换。关闭面板继续看候选，顶栏「光照试调中」可重新打开；切回当前效果则还原原光照和材质。候选仅作用日间，夜航保留原泛光。

「保存我的参数」只保存参数，不保存启用状态；刷新或重新进入后仍以正式当前效果开始。用户视觉确认前，没有自动应用到默认的入口。业务染色仍由原「染色浓度」控制，对照截图使用 0% 白模；不是清空任务进度。

## 可调项目与四灯说明

| 分组 | 操作 | 主要解决的差距 |
|---|---|---|
| 主光 | 方位、高度、强度 | 明确受光面、背光面与投影方向 |
| 明暗 | 侧面/天空补光、环境反射、曝光、间接补光 | 防止全部表面被均匀抬亮，保留侧面体积 |
| 阴影与背景 | 阴影柔度、背景提亮 | 兼顾接地、交叠与明亮底色 |
| 反射灯板 | 四块分别开关、XYZ、宽高、亮度；俯视位置图 | 控制储罐竖向亮带与管道高光的位置、宽度、强弱 |
| 两灯/四灯 | 仅主灯与轮廓灯 / 四灯配合 | 比较主反射结构与额外补光是否使画面变平 |
| 材质 | 白墙粗糙度/微纹理，管罐各自粗糙度/金属感、反射强度，蓝色深度 | 干净白墙、连续反射、非自发光的蓝色 |

四块并非固定正确答案，也不是越多越好。本轮采用主反射灯板、侧后轮廓灯板、较弱顶部与正面补光。灯板当前朝向模型中心；位置图展示世界坐标 X/Z，Y 调高度。灯板属于环境贴图中的发光面，参与环境照明和反射，**不分别生成物体遮挡投影**；投影由独立方向主光与原柔影系统承担。没有宣称完成真实四盏面积灯或动态全局光照。

参考 [Drei Lightformer](https://github.com/pmndrs/drei/blob/master/docs/staging/lightformer.mdx) 与 [Environment](https://github.com/pmndrs/drei/blob/master/docs/staging/environment.mdx)（MIT）的发光面环境方法：针对图中储罐/管道缺少明确反射带的问题。沿用现有原生 Three.js 实现，没有为此引入 React Three Fiber 或 Drei 运行时，也未照搬一个不相干的演示场景。

## 技术验证与交付边界

主目录 `npm test` 362 项通过，活动工作区 360 项通过；保留各自独立测试集合。两边 `npm run build` 通过，包含 TypeScript 检查。实际 5189 构建为 v0.10.61，8 个变更运行时文件 SHA 与主目录、活动工作区一致。

真实浏览器已检查：参数即时变化、标量编辑不重捕获环境、灯板编辑重捕获一次、两灯/四灯、开关关闭灰色、保存及刷新恢复、Escape 焦点、1440×900 面板滚动、1920×1080 灯位图可读、日夜切换保留原 Canvas/聊天、四轮候选开关无纹理增长（17↔18）、静止 1.3 秒零新增帧。灯板修改防抖 180ms；捕获失败保留基础环境，单元测试覆盖旧目标保留和释放。

夜航候选自动不生效并释放候选环境，原夜航 Bloom 保留；夜航下切换候选不改变灯光参数。见 [夜航原图](../../Codex-Temp/sandbox-trial-v01061/night.png) 与 [灯位面板](../../Codex-Temp/sandbox-trial-v01061/panel-lights.png)。
