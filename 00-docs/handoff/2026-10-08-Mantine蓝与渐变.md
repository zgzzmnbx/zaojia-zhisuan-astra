# Mantine 蓝与渐变验收

- 日期：2026-10-08；应用 UI v0.9.24，设计标准 1.0.8。
- 新增主题 `mantine-blue`，名称 Mantine 蓝；主色精确 `#228BE6` / `rgb(34,139,230)`，亮暗均保留此色。
- 来源：[Mantine 官方默认色阶 blue[6]](https://github.com/mantinedev/mantine/blob/master/packages/@mantine/core/src/core/MantineProvider/default-colors.ts)。保留 daisyUI + Tailwind 与现有业务适配，无新增组件依赖。

## 实现

- 配色目录、首屏偏好白名单、主题预览及专业 iframe 共用现有外观来源。
- 主按钮 / 品牌标记使用 `#339AF0 → #228BE6` 静态渐变；选中态使用亮暗各自浅底渐变；图表沿用从当前主色派生的既有渐变。
- 主按钮文字 `#071D30`，亮色强调文字 `#1971C2`、深色 `#74C0FC`；hover 不变暗，禁用态独立。默认仍为 Astra 蓝亮色，原六套主题保留。
- 主题预览的渐变选择器限定自身配色节点，避免当前根主题改变其他主题的色块。
- 改动同步至启动配置指定的活动工作区；同步前比对文件，同步备份保存在忽略的临时目录，未重置已有改动或移动运行库。

## 验证

- D 盘主目录、C 盘活动工作区各执行 `npm test`：152 / 152 通过；各执行 `npm run build`：类型检查和正式构建通过。
- 真实本机 5189 页面、Edge 浏览器：1440×900 和 1366×768 亮暗设置截图及主聊天视图检查通过；实际页脚 v0.9.24。
- 计算样式核验：主色和图表基色精确 `#228BE6`，按钮实际渐变为 `rgb(51,154,240) → rgb(34,139,230)`；其他主题预览仍为自己的配色。
- 对比度：主按钮最小 4.81:1，亮色强调文字 / 纸面 5.02:1，深色强调文字 / 纸面 8.29:1。
- 主题切换保持当前草稿、对话和专业 iframe 实例 / 表单值；刷新保持配色 / 深色和当前草稿、对话；七套配色选择通过。
- 键盘 Space 选择、2px 焦点轮廓、Escape 关闭与返回设置触发按钮通过；浏览器无新增脚本错误。
- 本轮仅验收外观变化；未重新执行造价标准答案业务验收，宿主源码 / 控制台 / 设备未更改。

证据：`Codex-Temp/mantine-theme/` 下的 `browser-evidence.json`、`keyboard-evidence.json`、亮暗截图与测试 / 构建日志；活动目录保存其独立测试 / 构建日志。
