# 造价智算 · 蓝色阶梯 Z Logo

目录版本：1.0.8 · 2026-10-30；当前模型：**v1.2.2**。

只收录用户确认的蓝色阶梯 Z：上、下横梁及中间三阶方块；不收录其他候选标志。三维当前版为 13 个可独立旋转的立方体，支持打散、组装，底梁最右端为灵动块，并提供“造价智算”四字组合。

系统当前集成 **v0.9.115**：[Logo 与动效设置页](http://127.0.0.1:5189/logo.html) 汇集配色、八种姿态、单块互动、文字组合与导出；新增圆环旋转重组（10 秒）与波浪舒展（8 秒），保留 12 秒紧凑待机。新成果在 [LogoKit v1.0.3](06-复用组件/LogoKit-v1.0.3/README.md)，八套 GLB 各含 24 动画。原 Blender / 历史模型 v1.2.2 保留。
