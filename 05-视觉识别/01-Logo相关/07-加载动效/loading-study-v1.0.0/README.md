## 参数与接入建议

- 流光周期 2.6 秒；圆环展开 1.2 秒，之后每 4 秒转一圈。所有方块保持刚性，不通过缩小方块避让。
- 完成时最长约 1.4 秒归位；圆环先按最短方向对齐，再沿展开路径返回。任意阶段完成都可连续收尾。
- 正式接入时只由真实加载/任务生命周期驱动。未知进度不显示百分比；取消/错误应使用对应文案，不播放成功归位文案。加载完成后立刻允许用户操作，收尾动画不得阻挡业务。
- 页面版本支持暂停、减少动效、可见性/离屏停算、卸载释放。小尺寸预览复用主画面，无额外 WebGL 上下文。

## 构建与验证

在本目录运行 `npm test` 和 `npm run build`；依赖使用项目已有 Vite / Three.js，不安装第二份依赖。生成的单 HTML 可独立复制使用，不包含字体文件。

3 项样板测试通过：轮廓不变、循环连续、开合及完整旋转的碰撞检测、不同完成时刻的连续归位。根项目 389 项测试通过。已检查 Blender 渲染帧和生成 GIF；本轮启动本机预览服务被自动审批策略拦截，浏览器又禁止 file 协议，因此没有声称完成网页实播/交互验收。

`verification.json` 包含来源和产物哈希；`model.mjs`、`motions.mjs`、`motion-options.mjs` 为当前品牌模块的只读快照，应用源文件未修改。离线渲染过程脚本及帧在项目 `Codex-Temp/logo-loading-study/`；目录内同名脚本仅作来源留存，使用时按项目过程目录运行。
