# 造价智算 · 阶梯 Z 三维概念模型

版本：1.0.0 · 2026-10-13

依据用户选定的 `【5】ChatGPT Image 2026年7月25日 10_20_03.png` 重建：上下横梁与三个阶梯方块，共五个独立网格。属于可编辑三维概念模型，尚未作为正式品牌资产接入应用；保留原图的结构意向，不能视为对生成图片空间几何的逐像素复原。

## 查看

双击 `造价智算-3D-动效预览.html`，使用支持 WebGL2 的现代 Edge / Chrome 浏览器打开。所有代码与模型均已内嵌，断网可用，不需要安装 Node.js、Blender 或启动服务器。显卡驱动及浏览器硬件加速需可用。

- 拖动旋转整体，滚轮缩放；“正面”和“复位”提供按钮入口。
- 中间方块向前浮起 → 绕自身竖轴旋转一圈 → 回到原位。
- “旋转一次”或点击中间方块可重播；“播放动效 / 暂停动效”控制循环。
- 一次动作 3.5 秒，完整循环 7 秒；支持改变光照、深浅背景。
- 页面隐藏或离屏时停止渲染；系统减少动效偏好开启时，初始静止，用户仍可主动播放。

## 三维文件

`ZSuan-Stepped-Z-animated-v1.glb` 包含五个可单独编辑的部件、材质和原生动画轨道。可导入支持 glTF 2.0 的三维软件或播放器；对方软件须支持 glTF 动画才能播放。浏览器预览额外提供环境光、地面阴影和控制界面，这些展示设置没有加入模型文件。

动画名称：`Center_Block_Float_Turn_Return`。

需要修改形状、材质或动画时，可使用 Blender 导入 GLB；查看本次交付无需安装 Blender。
