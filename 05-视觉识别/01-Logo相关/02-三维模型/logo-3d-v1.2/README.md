# 造价智算 · 模块化三维标志

版本：1.2.0 · 2026-10-13

按用户最新确认重建为 **13 个独立立方体**：顶梁 5 块、底梁 5 块、中间阶梯 3 块。上下两排通常紧密连接，视觉上保持长方体；各块可以独立旋转、散开、重新组合。底梁最右端 `Lower_Cube_5` 是特别活跃的“灵动块”。

## 查看与使用

- `造价智算-模块组装与灵动块-v1.2.mp4`：Blender 原生渲染的完整循环，1280×720、30 fps、12 秒，无音轨。
- `造价智算-精细模型与组装动效.html`：离线交互预览，无需服务器。可选横式 / 竖式 / 仅图形，打散、组合、播放组装循环、暂停、拖动进度；从 13 块中选择任意一块，再选 X / Y / Z 轴旋转。
- `Blender-modular/造价智算-精细模型-组装-v1.2.0.blend`：可编辑工程，默认选中底梁最右端方块，空格播放 / 暂停，F12 渲染。已设置摄影机、灯光、材质、中文时间线标记。工程保存的高质量渲染设置为 Cycles / 64 samples / 1600×900。
- `Blender-modular/造价智算-横式组合.png`、`造价智算-竖式组合.png`：带“造价智算”四字的横式和竖式静帧。
- `ZSuan-brand-v1.2.glb`、`ZSuan-vertical-v1.2.glb`：包含 13 块图形及 4 个文字网格的横式 / 竖式文件。
- `ZSuan-icon-v1.2.glb`：仅 13 块图形，适合嵌入网页及其他三维场景。

网页默认选中“底梁⑤ · 灵动块”；也可点击模型中的方块选择。打散后可以单独旋转，再按“组合”回到完整标志。下载按钮导出当前选择的横式 / 竖式 / 仅图形模型。页面隐藏或离屏时停止渲染；减少动效偏好开启时初始暂停。

本机已安装 Blender，不需要再安装工具。独立 HTML 本身无需 Blender。

## 精细化处理

1. 修正旧模型阶梯与横梁相互穿入的问题，三维占用范围经碰撞检查。
2. 顶梁和底梁各由 5 个边长 0.68 的立方体组成，相邻中心间距 0.6802；极细接缝及小倒角让它们保持整体横梁观感。
3. 中间阶梯为 3 个边长 0.84 的立方体，阶梯之间及与横梁之间保持约 0.02 的接缝。行内倒角 0.004，阶梯倒角 0.014。
4. 所有图形块在动作中保持原尺寸，不通过缩小方块避让。单块旋转先向前移出，旋转后回到触发前的位置；整体拆解时外侧先离开，组合时内侧先归位。
5. 蓝色按高度形成深浅变化。同一横梁的 5 块使用一致材质，保持拼接后的完整性。
6. “造价智算”使用项目现有苹方中粗字体的四字轮廓生成三维网格，含细薄厚度和倒角。模型不依赖接收端安装字体；未附带完整字体文件。

## 动作编排

| 时间 | 内容 |
| --- | --- |
| 0–1.8 秒 | 完整品牌组合；底梁最右端方块先探出、独立旋转、接回 |
| 1.8–3.35 秒 | 13 块逐步分离，文字退出 |
| 3.4–4.9 秒 | 不同轴向旋转；灵动块多转一圈 |
| 5.0–7.64 秒 | 底排、阶梯和顶排逐步拼合 |
| 7.1–8.1 秒 | 灵动块最后完成归位 |
| 7.35–8.22 秒 | “造价智算”四字重新呈现 |
| 8.22–12 秒 | 完整标志展示；灵动块在 10.2–11.4 秒再次轻快翻转 |

每个 GLB 包含 16 条动画：`Assembly_Loop`、`Explode`、`Assemble`，以及 13 条独立方块旋转。Blender 用 NLA 轨道保存，默认只启用 `Assembly_Loop`。切换其他动画时应先停用当前轨道，避免多条轨道叠加。

## 重建

在 Astra 根目录，使用已有 Node.js 依赖：

```powershell
node "05-视觉识别/01-Logo相关/02-三维模型/logo-3d-v1.2/build.mjs"
node "05-视觉识别/01-Logo相关/02-三维模型/logo-3d-v1.2/verify.mjs"
```

`model.mjs` 管理立方体尺寸、拼接位置、灵动块身份及动画；`wordmark.json` 只保留四字轮廓。`extract_wordmark.py` 仅用于从本机已有字体重新提取四字，临时 Python 依赖保留在项目根目录的 `Codex-Temp/logo-tools-python/`（日常构建直接使用现有 `wordmark.json`，无需重新提取）。`build_blender.py --probe` 建立完整工程、静帧及视频测试帧；`render_movie.py` 从已保存的工程输出电影帧；`package_delivery.py` 合成视频和打包。Blender 脚本通过 `--python` 运行，脚本参数放在 Blender 的 `--` 后。

## 验证记录与边界

- `verification.json`：13 个真正立方体、恒定尺寸、全部 X / Y / Z 单块旋转、12 秒完整编排的 120 Hz 碰撞检查、打断动作后的组合 / 打散、三个 GLB 的重新加载、16 条动画、四字网格、暂停、循环与 HTML 内嵌资源检查。
- `blender-reopen-verification.json`：新进程重新打开 `.blend`，核验 13 块尺寸、NLA 轨道、灵动块单独动作与最后归位、文字、循环和保存的渲染设置。
- `blender-verification.json`：实际原生视频帧及渲染器记录。静帧使用 Cycles，短片使用 Eevee；不同于网页录屏。
- `delivery-verification.json`：视频编码、尺寸、帧率、帧数、时长及交付文件哈希。
- 本轮项目 `npm test`、`npm run build` 记录分别保存在 `project-tests.log`、`project-build.log`。

离线 HTML 通过脚本及资源检查。内置浏览器此前拒绝 `file://`，本次没有通过其他协议绕过，因此浏览器真实按钮、拖拽及明暗效果仍未完成实测。原生 Blender 动画验收不等同于网页交互验收。
