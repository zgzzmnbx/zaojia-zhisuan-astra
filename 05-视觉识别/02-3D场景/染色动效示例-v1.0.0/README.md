# 白模城市 · 染色动效示例 v1.0.1

独立视觉研究，不修改正式工作台，不读取或执行业务任务。使用原白模 GLB、Three.js 标准材质和局部着色器；无需新模型，也不使用实时后处理。

## 查看

5189 服务运行时打开 `http://127.0.0.1:5189/sandbox-color-study/`。

- 原始白模：全城回到未染色状态。
- 播放单楼染色：8 秒自下而上，默认知识检索；可切换七座建筑。
- 染色方式：新版局部雾蓝 / 原版薄层淡彩，同一视角和进度直接比较。
- 播放全城流程：28 秒依次完成，已经完成的建筑保留颜色。
- 全城完成：查看整体完成配色。
- 暂停 / 继续、进度滑块：观察推进边界；浓度范围 15–100%，默认 76%。浓度是染色混合比例，并非建筑表面积占比。

## 设计

新版使用统一雾蓝，为每座建筑限定重点立面：导入楼主体、填价罐体与后方厂房、风险亭及盾牌、知识楼玻璃核心、报告楼墙体、协同工作站、大屏玻璃条带。保留白色屋顶、楼板、底座与外部管线。知识楼原版未参与染色的玻璃核心现在成为主要着色区。

颜色自下而上推进，窄蓝色边缘增强工作中的辨识度；完成时边缘淡出，留下雾蓝立面。模型的共享原材质先克隆，未完成区域不会被其他建筑染色。区域遮罩针对当前 GLB 世界坐标定义，更换模型后需重新校准。源 GLB 不变，原目录路径保持兼容。

示例合成进度不可直接当作真实百分比。接入时优先用实际处理数量 / 总量；无量化进度只显示活动边缘，完成回执到达后再染满。失败 / 取消保持已到达位置并显示文字状态；重新运行和不同成果版本须独立处理。颜色不替代风险等级和人工复核。

## 构建

项目根目录执行：`node 05-视觉识别/02-3D场景/染色动效示例-v1.0.0/build.mjs`

输出只写 `04-output/sandbox-color-study/`。正式应用重新构建后需再次执行本命令。活动宿主若位于独立 worktree，将此输出目录复制至该宿主的同名静态目录。

## 验证

v1.0.1：主目录 306 项、活动工作区 304 项测试通过，正式构建与独立构建通过。浏览器核对起始白模、50% 下蓝上白、100% 完成色、全城完成与新旧切换。页面隐藏时暂停动画，静止状态停止帧循环。
