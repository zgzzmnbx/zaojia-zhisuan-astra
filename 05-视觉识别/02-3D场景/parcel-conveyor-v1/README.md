# 包裹传送带 · Blender Demo v1.0.4

独立视觉候选，正式 Astra 仍为 v0.11.19。未接业务任务、未合并正式沙盘。

- `parcel-conveyor.blend`：可编辑 Blender 工程，含柔白包裹、主题蓝束带、文件标签、浅色玻璃带面、支架、七个收件门架、摄影棚灯光和原生关键帧；两侧护栏已拆除。
- `conveyor-parcel.glb`：网页资产，65 个网格；导出的包裹运输动画约 38.3 秒。
- `timeline.json`：七站停靠与运输段数据，由建模脚本生成。
- `blender-detail.png`：Blender Cycles 实际渲染，非生成图片。
- `build_demo.py`：可复现建模、动画、GLB 导出和 Cycles 渲染脚本；用 `blender --background --python <脚本绝对路径>` 执行。脚本在独立后台进程内新建场景，不修改用户已打开的工程。

浏览器入口：http://127.0.0.1:5189/parcel-demo/index.html 。需要既有 Astra 本地服务与独立 Demo 发布文件。

风格：柔白微缩工业设备、蓝色束带、简洁标签；白天与现有 V11 沙盘搭配。参考用户提供的截图，X 链接受访问限制，未声称复刻完整视频。模型自行创建，无外部模型下载。

路线依据既有 pipeline-route.json，局部扩大间距以容纳实体传送带。演示依次经过清单导入、智能填价、风险复核、报告生成、协同复核、专业表格、知识检索；这只是展示顺序，不代表真实业务依赖或完成率。

已实现：包裹移动、弯道转向、七站停靠、暂停/重播/变速/拖动时间、镜头跟随与模型独显。带面与门架目前为静态模型，未制作机械履带滚动、包裹开箱或建筑内部收件动画；夜间材质和真实任务事件需视觉确认后再设计接入。
