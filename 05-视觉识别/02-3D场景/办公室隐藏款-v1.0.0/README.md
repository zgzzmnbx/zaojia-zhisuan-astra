GLB 为沙盘角色的独立站姿模型，内含骨架、左右翼关节，以及「日景」「夜景」两套材质选项。支持材质变体的查看器可以直接切换翼光。五份文件均已重新导入，核对了蒙皮、翼骨、尺寸和夜间发光色。办公室里的坐姿、行走和收翼由沙盘运行时驱动。

角色沿用原办公室 MIT 骨架与基础几何。五款发饰、衣饰、翼形与夜间材质为本次设计。每个 GLB 的资产信息随附原骨架授权全文。[基础骨架许可证](../../../public/office-twin/viewer/people/LICENSE.my-office.txt)
