# 纯色版光影 · 1.0.0

主沙盘可选日间预设，默认关闭；入口为「视图 → 纯色版」。

复用用户确认的 `../blender-web-study-v0.1.0/public/assets/` 中九张 Cycles 96 samples / OIDN 贴图、五块棚灯 PMREM、AgX 及银白管罐参数。不是静态背景图；相机、点击、染色和动画继续使用正式沙盘。

`tools/sandbox/derive-solid-lighting.mjs` 将样板世界坐标三角面匹配到 `lighting-v2/sandbox-surface.glb`。183,748 个三角面全部匹配，最大误差 0.000001213；源 SHA、分区及偏移记录在 `manifest.json`，UV 与逐面金属角色写入 `uv.bin`。原 GLB 不改。运行时展开索引并添加独立属性；所有原位置、法线、UV 和分区保留，装配连通组件与时序保持一致。外围棚拍地面扩展时同步延伸 UV，仅取原顶面，边界取样不拉伸建筑投影。

首次开启按需加载；再次切换复用环境和贴图。关闭或夜航使用原着色路径，且不修改其他已保存开关。装配期间暂用原动态照明，落定后恢复纯色版；业务染色仍作用于对应建筑立面。失败显示提示并保留原场景，退出场景释放派生几何、贴图和环境。

纯色版固定光影生效时，原日间材质、棚灯、烘焙与背景参数暂不可调，关闭后恢复。静态烘焙中的阴影属于此预设；原「阴影」开关继续控制实时阴影。原夜航泛光和聚焦辉光独立。

此资产派生自本项目自有模型与已确认的 Blender 光影研究，不新增外部素材。框架 Three.js 使用原有 MIT 许可；OIDN 仅用于离线去噪。
