## 视觉结果与限制

已将 Cycles 的静态漫反射和间接光转成网页光照贴图，96采样、每分区2048像素，经 OIDN RTLightmap 独立去噪。银白储罐与管道使用实时 PBR 反射，并补充竖向棚灯反射面。噪点和黑色接缝相较第一轮显著减少；静态材质最暗部分应用最低环境补光，因而与 Blender 原图仍有差异。蓝色信息管线主要使用静态漫反射贴图，不与 Blender 的完整镜面反射逐像素一致。

这是一份可交互视觉测试网页，不包含正式业务动画、夜航泛光、任务染色或交互标签。原产品功能保持原状，不能将本次独立验收当作正式产品集成验收。

构建器提示 Three.js 主包超过500kB；本地正常加载。初始 PMREM 编译有 ANGLE 浮点精度警告，画面正常、无 JavaScript 异常；没有将告警隐藏或计为零控制台告警。
