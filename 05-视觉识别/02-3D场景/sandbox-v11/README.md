# V11 烘焙城市沙盘实验

这是从当前远端 `main` 的 `d91b2297d9e962db4cfc3bf0469a8475f07ea7eb`（v0.10.74-water.4）建立的独立视觉分支。它保存实际可旋转模型、烘焙光照和外围城市，不是只有截图，也不替换正式工作室沙盘。

## 启动

在仓库根目录执行：

```sh
npm ci
npm run dev:sandbox-v11
```

浏览器打开 http://127.0.0.1:5189/sandbox-v11.html 。端口冲突会停止，不会抢占其他服务。必须通过 HTTP 访问，不支持直接双击 HTML。

正式生产构建也包含此独立页面：`npm run build`，然后 `npm run preview` 并打开上述地址。`/` 仍是原工作室。这个预览没有业务 API、登录、用户偏好写入或外部 CDN 依赖。

独立开发配置只扫描沙盘入口，避免当前主线普通 Vite dev 的 MapLibre worker 依赖预优化问题；没有为此修改正式地图代码。

## 包含什么

- 7 座原始业务主体建筑，名称与分区保留；配景沿用 V09 布局。
- 139 栋外围城市建筑、35 个街区、22 段街道，以及人行道、原场地、独立地面。
- 银白管线与冷白 / 科技蓝细节；实际 Cycles 静态烘焙。
- 标准 glTF 2.0：11 个语义节点 / mesh、20 个渲染 primitives / 材质、214,968 个三角形，11 张 PNG，2 个几何数据块。
- 旋转、平移、缩放、7 区聚焦、俯视、远景透视、配景显示、截图和可关闭的深度感知微缩景深。

目录：

- `public/sandbox-v11/model/`：唯一运行时模型、几何、贴图和逐文件 / bufferView SHA256 清单。
- `03-Src/studies/sandbox-v11/`：独立 Three.js 预览与景深源码。
- `sandbox-v11.html`：显式访问入口，不自动进入或修改业务状态。
- 本目录 `verification/`：冻结模型清单、7 区几何身份核验、拆分无损核验与交付验收记录。
- `tools/sandbox-v11/pack-baked-model.mjs`：可独立运行的无损 GLB → glTF 拆包器。

资产包约 38.48 MB，未做几何简化、贴图缩小或传输压缩。2 个 bin 分别为 12,369,840 与 10,148,112 bytes；它们是完整几何，不是 Git LFS 指针。没有另存一份重复 GLB 或巨大的 Blender 工程。效果图是离线烘焙模型参考，不是浏览器截图。

## 来源与颜色契约

原始几何来自同一仓库 main 的 `05-视觉识别/02-3D场景/lighting-v2/sandbox-surface.glb`：

- 原始资产 SHA256：`b96216c89edcb285b90c15aeb787b82c151e6bf4c6e2ad7418322cbb80ef5df2`。
- 最终冻结 GLB：`Astra-Context-v11-baked-clean.glb`，38,455,656 bytes。
- 最终 GLB SHA256：`9e3805133c5ebe77c15389ed416460ac7f2b923e0eb3f4f1067a5a8ce33bc45f`。
- Blender 4.3.2 / Cycles CPU；V01–V09 增加城市配景，V10/V11 制作和修复烘焙。
- V09 → V11 的 7 区坐标、拓扑和世界变换不变，主体共 122,532 个三角形；仅拆分材质和细面 corner color。核验记录不等于生产动画兼容性承诺。

所有材质使用 `KHR_materials_unlit`。大面使用经过 AgX +0.30 展示转换的 sRGB PNG；细小面使用采样所得的同一光照结果，在线性 `COLOR_0` 中保存，材质白色且不另乘纹理。此混合编码修复小于 texel 的 UV 岛产生的黑斑，不能删除顶点色或再次应用色调映射。

运行设置必须保持 `NoToneMapping`、曝光 1、输出 sRGB，不追加 AO、阴影、雾或第二套光照。景深是运行时深度后处理，不烘进纹理；关闭时直接渲染清晰模型。

## 明确边界

本版是冻结光影视觉候选，不是完整生产功能迁移：

- 不接业务任务染色、构件装配、真实任务聚焦、射灯或夜航切换。原工作室的全部原链路保持不变。
- 光照方向、间接光与遮蔽固定，隐藏外围城市不会重新烘焙主体光照。
- 水面反射和高光为静态近似，不等于 main 上实时 water.4 水效。
- 139 栋配景在烘焙时合并为城市 mesh，不承诺逐栋编辑 / 业务拾取。
- 目前不是性能优化包。首次加载、GPU 纹理内存和景深成本需在目标桌面设备上实测；静止 / 离屏 / 后台停止绘制。
- 原始中间 Blender 场景和采样缓存未放入 Git。此分支可运行和审查最终成果，但不能从 main 一键重新烘焙。拆包器仅需原始冻结 GLB，可无损重新生成发布结构，不是完整建模 / 烘焙流水线。

## 后续接入生产前的门禁

1. 保持 7 区原业务身份，并逐项设计染色、装配与烘焙材质的隔离或回退，不直接替换主线 GLB。
2. 对日间 / 夜航、任务失败 / 取消、连续聚焦、几何归位和水效开关分别验证。
3. 验收真实 WebGL 画面、景深 shader、目标 GPU 内存 / 帧率、冷加载和释放。构建 / CPU 测试通过不能代替 GPU 验收。
4. 只有显式确认后才选择默认启用或合并，本分支不会自动合并 / 部署。

```sh

npm run build
```

本次 20 项新增检查及全部 407 项测试通过，正式构建与 TypeScript 检查通过。PNG / 几何 SHA、98 个 bufferView、实际 GLTFLoader 材质和颜色契约已核验。Node 图像上传 / 部分渲染器为 mock，不声称 GPU 成功。
