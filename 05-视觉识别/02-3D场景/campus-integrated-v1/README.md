# 方案一建筑重塑 v1.1.0

2026-10-30 · UI 分支预览 v0.11.38 · `codex/conveyor-integrated-white`。

用户要求保留七栋建筑的业务身份、位置及顶部功能标识，同时按方案一改造建筑主体；不是冻结旧建筑造型。新主体与加厚传送带一起在 5190 预览，正式 5189 不由本分支覆盖。

## 模型

`campus-integrated.blend` / `campus-integrated.glb` 包含七栋新主体、14个按区域与材质合并的网格。`build_model.py` 在独立 Blender 后台进程重建，使用原世界坐标。

- 导入馆：蓝色凹窗、整片圆角屋檐、两层实心基座。
- 知识楼：五层连续层板、统一窗格和转角柱。
- 填价站：三座主罐、单根汇集管、统一后方控制楼，减少零散设备。
- 风险管廊：连续设备基座、三根主干管和共同支座、整合前端控制室。
- 报告馆：凹入竖窗、连续檐口、简化屋顶与基座。
- 协同馆：把分散盒子合并为一座低层横向建筑。
- 表格楼：新实心背板、加厚顶框与侧框，保留原表格显示面。

顶部数据表、书本、算盘、盾牌、叠页、协同节点及表格显示面从冻结模型复制原三角面、UV和材质，世界位置不变；不重新画功能图标。实现位于 `architectural-campus.mjs` 与 `campus-symbols.mjs`。新主体沿用原分区，因此点击、标牌、染色和装配仍归属同一业务节点。

新模型没有贴图或外部依赖，采用顶点方向光及局部AO，白色基材适配现有145%模型亮度。冻结源文件和路线哈希保存在 `manifest.json` / 传送带清单；原文件保持只读。

复现：`blender --background --python build_model.py`。模型构建并不替代网页构建，必须再运行 `npm test`、`npm run build` 并检查独立预览。
