# 造价智算 · 白模空间交互样机

版本：0.1.0 · 2026-10-13

根据本轮选定的白色工业园区参考和追加要求，用 Blender 5.2.2 LTS 实际建模。三维沙盘是主界面，采用白色建筑、蓝色水系及柔和落影；聊天与功能操作采用半透明毛玻璃浮层。所有几何为本轮原创示意模型，不代表真实项目 BIM 或计算结果。

## 打开与交付文件

- `白模空间-独立预览.html`：独立可交互预览，模型和运行代码已内嵌，可用桌面浏览器直接打开，不需启动服务。
- `white-sandbox.blend`：保留分区、独立物体、材质、灯光及相机的可编辑 Blender 工程。
- `white-sandbox.glb`：按功能分区合并的网页模型，节点 `extras.zone` 保留功能身份。
- `blender-overview.png`：Blender 实际渲染。
- `preview-overview.png`、`preview-risk.png`、`preview-table.png`：真实浏览器全景、风险复核、专业表格状态截图。
- `preview-shadows-off.png`：同一全景视角关闭场景阴影的真实截图。
- `browser-acceptance.json`：本轮浏览器验证结果；`delivery-manifest.json` 保存交付文件哈希。
- `build_scene.py`、`main.js`、`style.css`、`index.html`：建模与交互源文件。

## 沉浸交互

1. 沙盘铺满画布。拖动旋转、滚轮缩放；点击建筑网格或文字锚点选择功能。
2. 选择功能后相机推近，右侧出现可关闭的操作浮层。
3. 左侧聊天可收起和恢复。切换入口、镜头、浮层和聊天显示状态均保留当前草稿。
4. Escape 返回全景；“全部功能”提供普通按钮等效入口。
5. 环游需手动开启，可以暂停；手动拖动立即接管。默认静止，减少动效时镜头直接定位。
6. 空闲时按需渲染；页面隐藏停止帧循环，页面退出释放场景和 WebGL 资源。
7. 右上角“场景阴影”默认开启，控制建筑、管道、树木和地面的实时投影；可用键盘切换，不改变视角、功能状态或聊天草稿。
8. 聊天窗、功能浮层与上下工具条使用半透明背景、背景模糊与轻微色彩增强；背景模型和蓝色水面可以透过面板，正文保持清晰。浏览器不支持背景模糊时自动增加面板不透明度。

## 再生成

从当前项目根目录执行：

```powershell
# 使用本机已核实的 Blender 可执行文件；可替换为其他机器的实际安装位置。
& $BlenderPath --background --python 'Codex-Temp/design-concepts/white-sandbox-v0.1.0/build_scene.py'
node 'Codex-Temp/design-concepts/white-sandbox-v0.1.0/build_preview.mjs'
```

建模脚本只清理其新启动 Blender 进程中的场景，不修改用户已打开的 Blender 窗口。网页通过 Three.js / OrbitControls 加载 GLB，控件使用当前项目的 daisyUI 及 Phosphor 图标；原图标资源与几何不改动。第三方库许可证见 `licenses/`。
