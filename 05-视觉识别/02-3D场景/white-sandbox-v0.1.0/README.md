# 造价智算 · 白模空间交互样机

版本：0.1.10 · 2026-10-13（沿用原交付目录，保持链接有效）

当前维护位置：`05-视觉识别/02-3D场景/white-sandbox-v0.1.0/`。成果总入口见 [上级索引](../README.md)，目录迁移不改变模型版本。旧临时目录为兼容联接，不维护第二套副本。

根据本轮选定的白色工业园区参考和追加要求，用 Blender 5.2.2 LTS 实际建模。三维沙盘是主界面，采用白色建筑、浅天蓝水系及柔和落影；聊天与功能操作采用半透明毛玻璃浮层。河面提高明度并减弱反光，让蓝色信息流成为视觉重点。所有几何为本轮原创示意模型，不代表真实项目 BIM 或计算结果。

## 沉浸交互

1. 沙盘铺满画布。拖动旋转、滚轮缩放；点击建筑网格或文字锚点选择功能。
2. 选择功能后相机推近，右侧出现可关闭的操作浮层。
3. 左侧聊天可收起和恢复。切换入口、镜头、浮层和聊天显示状态均保留当前草稿。
4. Escape 返回全景；“全部功能”提供普通按钮等效入口。
5. 环游需手动开启，可以暂停；手动拖动立即接管。默认静止，减少动效时镜头直接定位。
6. 信息流或镜头运动时连续渲染，其余时间按需渲染；页面隐藏停止帧循环，页面退出释放场景和 WebGL 资源。
7. 右上角“场景阴影”默认开启，同时控制建筑、管道、树木和地面的实时投影与日间静态接触柔影；可用键盘切换，不改变视角、功能状态或聊天草稿。
8. 聊天窗、功能浮层与上下工具条使用半透明背景、背景模糊与轻微色彩增强；背景模型和蓝色水面可以透过面板，正文保持清晰。浏览器不支持背景模糊时自动增加面板不透明度。
9. 一根圆角半透明管线依次连接清单导入 → 智能填价 → 风险复核 → 知识检索 → 报告生成 → 协同复核 → 专业表格。蓝色信号沿管线前进，各建筑接口随信号到达点亮。管线沿道路布置，并在交叉处抬高避让。
10. “信息流”开关独立控制播放和暂停，暂停后保留位置；遵循系统减少动效设置，用户主动开启可覆盖当前页面的默认值。恢复页面时不补算后台时间。此管线是信息传递的视觉示意，不表示真实任务进度或强制业务顺序。
11. 右上角“夜航”切换日间/夜间。首次默认亮色，明确选择后仅写入 `astra.white-sandbox.scheme.v1`；不修改正式应用外观。夜间采用深蓝背景、冷色照明和深色毛玻璃，夜间压暗建筑基色、保留原粗糙度与非金属材质，恢复 0.1.4 的深色建筑与霓虹布局，统一适度降低灯带、窗格及信号发光强度。切换保留镜头、功能、草稿、阴影和信息流播放状态。存储不可用时仍能当页切换。

日夜场景控制集中在 `scene-theme.js`，界面夜色在 `night.css`，实时后处理在 `night-renderer.js`。0.1.8 移除白天 GTAO 和后处理缓冲，恢复直接抗锯齿渲染；接触柔影通过 `contact-shadows.js` 的 22 个固定轮廓和一张 128×128 纹理一次实例化绘制。阴影贴图关闭自动更新，仅模型加载、主题或阴影开关变化时刷新；静态建筑不因信息流和镜头运动重复投影。夜间延用既有 Bloom，返回日间释放该后处理资源。

0.1.7 完善日间模型质感：增加陶瓷压顶、石质设备基础、墙面凹槽、通风格栅、桥梁斜撑、台阶、座椅与少量人物尺度参照。七个功能雕塑及表格大屏继续作为入口标识；新增结构也会随建筑出现在夜航中，但不增加发光饰件。白天调整光比、白色层次与阴影偏移，修正河面法线；保留浅天蓝河面材质。夜航继续使用 0.1.6 的建筑压暗比例、灯带 3.2、窗格 1.05 与 Bloom 0.60，未恢复被否定的雕塑独立提亮方案。修改前模型、源文件和截图在 `backups/before-day-quality/`。

路线与端口坐标集中在 `pipeline-route.json`，网页动画在 `information-flow.js`。Blender 工程保存静态可编辑管线，实际蓝色信号由网页材质驱动。

## 再生成

从当前项目根目录执行：

```powershell
# 使用本机已核实的 Blender 可执行文件；可替换为其他机器的实际安装位置。
& $BlenderPath --background --python '05-视觉识别/02-3D场景/white-sandbox-v0.1.0/build_scene.py'
node '05-视觉识别/02-3D场景/white-sandbox-v0.1.0/build_preview.mjs'
# 可选：在原 Blender 工程之外生成含管线的可编辑副本。
& $BlenderPath --background --python '05-视觉识别/02-3D场景/white-sandbox-v0.1.0/add_blender_pipeline.py'
```

建模脚本只清理其新启动 Blender 进程中的场景，不修改用户已打开的 Blender 窗口。网页通过 Three.js / OrbitControls 加载 GLB，控件使用当前项目的 daisyUI 及 Phosphor 图标；原图标资源与几何不改动。第三方库许可证见 `licenses/`。
