# 沙盘冷白建筑 / 管罐涂层 v2.2.0

对应 UI v0.10.57。采用 A 的冷白建筑光照和 C 的局部白色涂层曲面响应，按用户要求进一步提亮背景与模型。保留实际建筑、管线、业务染色、装配和原聚焦辉光。

## 资产来源与保真

`sandbox-surface.glb` 从相邻 `lighting-v1/sandbox-lightmapped.glb` 派生。只读 Blender 原工程中明确命名的储罐、罐顶、连接管、跨河管道及法兰提供三角形身份依据；不按位置、圆柱形状或整个建筑猜测角色。35 个源对象的 12,912 个有向三角形全部匹配，最大误差 8.6991e-7（阈值 1e-4），无未匹配、歧义或混合组件。

按发布 GLB 的原连通组件分组；所有实际引用的局部属性逐字节复制，不改变节点、矩阵或组件量化焊接关系。保留 183,748 个三角形、717 个组件、8 个光照区；原 60 个 primitive 变为 63 个。新增 1 个 `coated-tank` 批次、2 个 `coated-pipe` 批次，原 `Porcelain white` 基底身份同时保留。原装配算法的 bounds、运动向量/start、每楼 end 和 total 均与 v1 一致。

UV0/UV1 与 v1 完全相同，因此继续使用 v1 的八张烘焙图、HDRI 和法线图；无新增纹理，不需要重新烘焙。`surface-manifest.json` 包含输入/输出 SHA256、逐区三角形、属性/组件指纹、717 个组件的来源及实际装配核验。v1 和原工程未改动。外部资产许可沿用 [v1 来源记录](../lighting-v1/README.md)，本轮未下载外部资源。

## 离线复现

在项目根目录执行；Blender 使用本机安装路径或 PATH，不写回源工程：

```powershell
blender --background --python tools/sandbox/extract-surface-evidence.py
node tools/sandbox/derive-surface-roles.mjs
npm test
npm run build
```

中间证据写入 `Codex-Temp/sandbox-ac-v01057/`。提取脚本只读取原工程；派生脚本读取 v1 二进制并核对运行时 GLTFLoader / 原装配算法。验证失败即停止，不输出近似替代几何。

## 运行与回退

日间参数集中在 `03-Src/studio/project-sandbox/render-profile.mjs`。曝光 1.03；背景按原地面偏好向白色混合 42%；主光 4.2、柔光 0.18、半球光 0.06、环境 0.26；GI 0.62、归位后 450ms 恢复。墙体/建筑瓷白粗糙度 0.76/0.66，储罐/管道 0.34/0.42、metalness 0；管罐不用墙面法线。

增强日间使用涵盖原装配峰值的固定阴影视锥、2048 阴影图、normalBias 0.035、bias -0.00045、radius 1.2、intensity 0.72。1024 对照近景出现明显阶梯/随机采样颗粒，2048 在本机 20 秒实测仍约 60 FPS、P95 16.9ms，故保留。关闭增强或夜航恢复原灯位、1024 阴影及原材质行为；不写用户偏好。

每次挂载只选择一次资产：v2 → v1 → 原始 GLB；HTTP、解析或结构验证失败均可回退。中断不重试，拒绝的已解析模型先释放。照明失败沿原基础画面降级，增强 off→on 可重新加载。静止不持续渲染，辉光保持原地面局部实现。

完整实机证据、设备与恢复步骤见 [验收报告](../../../00-docs/handoff/2026-10-21-沙盘A-C质感验收.md)。

## v0.10.67 · 本地水景与 AO 复用

合并远端 A-C 后，`water-normal.png`、`water-sky.png` 与 `ao/` 八张图集作为「视图 → 水景质感」独立开关保留，默认关闭。资源仍在本目录，通过 `local-surface.mjs` 按需加载；不替换 `sandbox-surface.glb`，也不改写 A-C 材质实例。

河面 UV0 在当前 surface 模型为拉伸 0–1，需按世界坐标换算 `u=0.35x`、`v=0.35z` 才能与本地 detail 模型的波纹尺度一致（逐顶点误差 0.000000）。AO 图集使用两模型完全一致的 UV1，可直接叠加。关闭开关时恢复 A-C 的粗糙度、金属度、环境反射、光照图与 AO。日间纯色版启用期间不叠加本地效果；夜航使用独立深色水面与较弱的 AO。
