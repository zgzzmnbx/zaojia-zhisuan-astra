# 集团 Logo 三维资产

版本 **1.0.0** · 2026-10-15。来源为用户提供的 `管网Logo.png`（129×127），原文件保持不变，权利归原标识权利人。

- `管网Logo-原色.glb`：源图主红色 **#C00000**，哑光非金属材质。
- `管网Logo-白模.glb`：同一几何，冷白 **#F4F6F8**。
- `管网Logo-红色轮廓.svg`：透明背景的轮廓矢量，可继续编辑。
- `contours.json` / `model.mjs`：可复现轮廓与 Three.js 挤出模型；`trace_logo.py` / `export_glb.mjs` 为生成入口。

仅红色区域形成五块实体，白色笔画及透明背景都是贯穿的空隙，无圆形背板、白色填充或透明贴图。两款共用轮廓和厚度，Y 向上，正面朝 +Z，高约 1 单位、厚 0.1 单位，边缘使用极小倒角。分离块作为同一逻辑组摆放；这是一份虚拟沙盘资产，不是可直接独立站立的实体制作方案。

轮廓按 PNG 红色色度和透明度在 50% 覆盖位置提取，简化误差 0.22 像素；受原图分辨率限制，不声称等同官方矢量母版。源文件 SHA256：`10f4aca97ae0f02cba55428580512f3136c240d937bc261b5014923e6750abfa`。

沙盘入口：**视图 → 集团 Logo → 隐藏 / 原色 / 白模**。默认隐藏；偏好存于 `astra.sandbox.group-logo`，不影响任务、建筑材质与聊天。v0.10.26 起，标识放在清单导入建筑左前方空地（场景坐标 -14.8 / 0.13 / 10.65），配两层倒角白色台座；Logo 高 1.48，底座高 0.34，总高 1.82，约为第一栋建筑的一半。台座与 Logo 一起隐藏；v0.10.27 起夜航采用暗色台座与红色荧光，日间恢复用户选定的原色或白模；复用场景夜航泛光，不新增渲染循环。布局源码为 `03-Src/studio/project-sandbox/logo-monument.mjs`，独立 GLB 仍为无底座的复用标识。

项目根目录重建：

```powershell
python '05-视觉识别/03-Logo-管网logo/trace_logo.py'
node '05-视觉识别/03-Logo-管网logo/export_glb.mjs'
```

提取需要 Pillow、NumPy、OpenCV；导出使用项目已安装的 Three.js。运行时不依赖 Python。自动化检查对源图内部红色及空白采样点进行真实几何射线检测，并核验原色、厚度和两份 GLB。
