# 演示回归工具 v1.0.0

根据 2026-11-05 个人练习录音的 41 段时间轴，把录音 09—36 段的系统演示拆为 24 项自动检查和 6 项实际接收端/现场检查。用例主记录为 `cases.json`；操作说明见 `../../00-docs/10-比赛演示功能回归测试流程.md`。

## 使用

在项目根目录双击 **运行演示回归测试.bat**。完成后自动打开本轮 HTML 报告。每轮新建目录，不覆盖历史证据。

```powershell
& .\runtime\astra-service\.venv\Scripts\python.exe .\tools\demo-regression\run.py --open
```

- 默认测试 `runtime/astra-service` **已部署版本**的独立副本；不会测试尚未部署的根目录改动，也不发布任何代码。
- 宿主测试端口 5197，数字化测试端口 18770；占用即停止，不抢占端口、不关闭已有服务。
- 主宿主数据全新；数字化数据使用正式 SQLite 的一致性只读备份。生成、保存、改因子均写入本轮副本。
- 正式 5189/18768 不用于业务测试；测试进程禁止访问正式端口与外部网络。正式服务可继续使用。
- 使用本机 Chrome、Node、本机已安装的 Playwright、正式宿主和数字化模块各自 Python 依赖。缺失依赖明确失败，不临时联网下载。首次机器准备时安装 Playwright 即可，Chrome须已安装。
- 保留当前构建需要的静态资源，避免复制历史资源代次；正式文件在复制时及结束时校验 SHA256。
- 输出可能包含本机项目资料，只保留在当前工作区；不上传云端。空间随轮次增长，可人工归档已完成的旧轮次，脚本不会自动清理。

## 结论与退出码

| 退出码 | 结果 | 含义 |
|---|---|---|
| 0 | 全部通过 | 所有必需自动检查、流程门禁和六项人工证据已通过 |
| 1 | 失败 | 至少一个断言或流程失败；查看截图、trace、对应日志定位，不直接推断都是程序缺陷 |
| 2 | 未全部验收 | 已执行项未失败，但仍有人工或其他必需项未执行；首次自动跑完通常为此状态 |

`--api-only` 仅排障，不能得到完整演示通过。手动结果按 `manual-checklist.md` 录入，保留执行人、时间、证据副本及哈希。正式版本变化后拒绝向旧报告补验收。

## 证据

`Codex-Temp/demo-regression/<时间-随机标识>/` 内包括：

- `report.html`、`report.md`、`report.json`：用例结论、各层结果和流程门禁。
- `manifest.json`：实际运行版本、构建时间、复制来源/工具哈希、数字化版本、准备数据哈希。
- `actual.xlsx`、`actual.docx`、`excel-comparison.json`：真实业务输出和独立标准答案逐项差异。
- `browser-D*.png`、`browser-trace.zip`、失败时 DOM 文本：真实浏览器证据。
- `digital-factor-1.json`、`digital-factor-1.21.json`：同一项目的因子变更、工作量、费用和版本。
- `contracts.xml`、各层 `.log`：既有接口回归和执行故障。
- `manual-results.json`、`manual-evidence/`：人工验收声明与证据，自动脚本不替人判断是否实收/听见。

`latest.json` 指向最新轮次，即使运行中断也保留初始未完成报告。运行耗时用于诊断，不是人的演示用时。

## 固定样例及预期

1. 部署的 V3.1 内置 Excel：与 `v31-source.json` 和该清单指向的用户原始样例核验 SHA256；浏览器 multipart 必须包含同一文件字节。100 项，99 项填入，H5=50000，H6=3203；一高一低两项风险。
2. 历史答案原件只读。仅在本轮参考副本把 H5 的 500000 调整为用户确认的 50000，S5 对应偏离率按 `(50000-4274)/4274*100` 独立计算；其余值、公式、填色、状态、隐藏行不宽松归一。六类差异均为零才通过。
3. 录音知识题使用程序现有演示预设，校验 16 根柱、D1422=4500 及来源。价格类知识保存为候选/待审核，不能自动确认为正式知识。
4. 数字化固定历史项目 `task_d9ba3c6c13ec466c8cafb1544f457436`，需求 SHA256 为 `1f6a3a5d2391e262a63e72aeef4b4eff98f8f0d7da91594b8feac1bdb6fd08b9`，已人工确认 11 项功能点、NESMA 52 FP。测试实际段落联动和两次计算；不把预先识别的项目冒充本轮模型识别。缺少此项目时明确失败，不随机挑选另一个项目。
5. 额外反例：坏 XLSX、错误扩展名、路径穿越文件名、重复匹配、关闭报告预设且无模型、刷新恢复、模块退出后宿主仍可用。

## 工具自检与维护

```powershell
& .\runtime\astra-service\.venv\Scripts\python.exe -m unittest discover -s tools/demo-regression -p test_harness.py
```

自检覆盖漏证据、漏测试层、错误价格、流程失败和旧版本证据。更新业务预期必须有独立依据，不能为消除红灯把实际输出直接抄成答案。界面按钮改名可修正定位器，但保留原业务断言。源码/构建未部署时，本工具仍测试旧正式版本；报告必须先看版本。
