自动报告中的未完成项需要以下证据。每次使用本轮版本、本轮独立测试项目；不要用旧截图或历史“已发送”补齐。外部发送不由自动脚本执行；执行人主动核对账号并操作。禁止向不明接收人或其他群扩大发送。

|---|---|---|

## 记录并更新报告

完成一项后准备脱敏的截图或文字验收记录，使用项目正式 Python 运行：

```powershell
& .\runtime\astra-service\.venv\Scripts\python.exe .\tools\demo-regression\run.py --run-dir "本轮完整目录" --record M01 --status passed --reviewer "石萌" --evidence "证据文件完整路径" --note "本轮项目、task、成果版本、轮次、实收与回执时间"
```

失败用 `--status failed`。该操作只保存人工声明和证据哈希，不冒充自动验证。程序版本变化后拒绝给旧轮次补验收，必须重跑。不能只勾选而不留证据。所有必需的自动/人工项均通过后，报告才可能显示全部通过；任何未执行、失败或流程异常均阻止该结论。
