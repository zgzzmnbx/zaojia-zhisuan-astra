# H1 办公室 · 白瓷与七种主题蓝

Astra 办公室沙盘独立 Demo v0.3.1，2026 年 11 月 18 日。20 层楼体采用白瓷立面、钴蓝窗带与退台屋顶。九楼保留原始房间、家具与工位的几何位置，重新制作地面、隔断、桌椅的材质与照明。

## 运行与对照

1. 完整解压本地运行包，双击根目录的 **预览白瓷办公室.bat**。预览需要 Python 3.10 或以上、FastAPI、Uvicorn 和支持 WebGL 2 的浏览器。渲染使用包内的模型、字体和 Three.js。
2. 点 **展开9楼** 拉出办公层，点 **整楼** 收回。在九楼打开工作栏，可以定位房间、点选人物、将人移入复核区或送回工位。**对照原版** 会在同一视图打开原模型，点 **返回白瓷版** 即可切回。
3. 独立预览提供 5 名模拟员工。工位设置保存到当前解压目录，关闭启动窗口即可停止服务。默认监听本机 5278 端口，端口已占用时另选本机空闲端口。可选用 `python tools/office-twin/porcelain/preview.py --port 5279 --no-browser` 指定端口。

## 园区夜景

园区 23 棵树共用一个植被绘制批次。低饱和的灰绿树冠与灰棕树干接受冷色环境光，暗部沿用模型中烘焙的遮蔽。树木的自发光为零。窗带、标识和办公室屏幕继续使用各自的夜间灯光。

与 v0.3.0 相比，全场三角形、白天顶点颜色与三张内嵌贴图逐项一致。入口同机位的日景画布像素一致，夜景实测整楼多 1 次绘制。已检查整楼、展开九楼、七种主题蓝，以及景深和辉光开关。当前模型 12.59 MB。

## 展开9楼与背景虚化

九楼的房间、桌椅和人物保持清晰，其余楼层和园区按与九楼的景深距离虚化。打开 **画面设置 → 九楼背景虚化** 可实时调整 0–100%，默认 45%。调至 0% 可看清周围建筑，点 **保存参数** 可在此浏览器记住选择。整楼使用清晰全景。

展开用时 1.05 秒。托盘沿原轨迹向前 32 米、抬高 3 米，上方楼层抬高 18 米。背景色和夜间发光在低分辨率下柔化，完整分辨率的深度保留楼层之间的实际遮挡。九楼顶盖在归位时闭合。旧九楼链接、嵌入指令、房间和人员入口统一进入展开视角。

在 1440 × 900 和 1024 × 768 两种窗口下，分别从 v0.2.0 提交 8005f19 加载原查看器，同步采样展开和收回各 6 个时刻。两版托盘四角的屏幕偏差均小于 0.1 像素。另在 8 个过渡画面逐像素比对遮挡，九楼可见区域与直接深度渲染一致。鼠标悬停、离开、点击固定和中途反向均按同一轨迹运行。

v0.3.0 本机 Intel Arc B390、Chromium、1440 × 900、DPR 1，5 名模拟人员。持续拖动 4.1 秒，展开九楼日景测得 53.3 FPS、夜景 59.8 FPS。整楼白天和夜间均约 60 FPS。隐藏后停止绘制，返回整楼或关闭虚化后释放景深缓冲。

## 主题蓝

顶栏 **主题蓝** 提供钴蓝、冰川蓝、晴空蓝、湖蓝、群青蓝、钢蓝、海军蓝。首次进入使用钴蓝。点选色样或用键盘选择后，当前视角即时换色，刷新后自动恢复。偏好保存在当前浏览器和预览地址，工位配置由原“工位设置”单独管理。

窗带、桌椅、树冠和标识在建模时标记了三档蓝色颜料。每次切换只更新着色器参数，保留白瓷、人物本色和贴图的光影。夜景的窗光、屏幕和光晕同时取新色，暖光继续按原亮度和色温显示。

浏览器在整楼日景、九楼日景、整楼夜景、九楼夜景分别实测七种配色，共 28 次切换仅加载一次 GLB。每种配色都产生了不同的实际画面，原视角和模型实例全程保留。另用隔离的浏览器验证了点选、键盘选择、刷新记忆、原版对照返回和禁用存储后的当次切色。

## 冻结的平面

以 `models/H1-baked-v0.6.7.glb` 和 `data/office_layout.json` 为依据。生成前校验两份原件的 SHA-256，再逐节点核对九楼结构、家具、元数据、本地及世界变换、顶点、法线和三角索引，并逐层核对 20 层的变换。

| 核对对象 | 结果 |
| --- | --- |
| 九楼几何 | 2,405 个节点，155,460 个三角形，逐项一致 |
| 布局数据 | 82 段墙、29 处门洞、15 根柱、77 个工位锚点 |
| 复核区返岗仿真 | 67 个可分配工位全部到达，428 个复核区出口落点检查通过 |

## 渲染与实测

整楼关闭时跳过被楼板遮挡的九楼家具，展开后恢复其显示和交互。外墙、窗带和设备按层合并。场地及九楼地面使用方向阴影贴图，立体构件的漫射与遮蔽在 Blender 中离线计算，其结果存入模型。夜景继续使用独立的灯光贴图。

v0.2.0 的单个 GLB 为 **12.61 MB**。与 v0.1.0 比对，全场 2,504 个节点、2,037 个网格图元的原有顶点、颜色、法线、索引和 UV，以及全部三张内嵌贴图逐项一致。新增的顶点属性记录颜料分组。

本机 Intel Arc B390 / Direct3D 11，Chromium，1440 × 900，DPR 1。这一版以钴蓝、湖蓝、冰川蓝和海军蓝分别持续拖动整楼与九楼约 4.1 秒，均为 59.8–59.9 FPS。整楼每帧 58 次绘制，九楼 158 次。四次首次出画为 1.09–1.65 秒。

## 模型复核与重建

在项目或解压目录根部执行下列命令。核对与重建使用 Python、NumPy、Pillow 和 OpenCV。完整重建还需 Blender，本轮使用 Blender 5.2.2 LTS。Blender 的可执行文件可用 `--blender` 显式指定。

```powershell
python tools/office-twin/porcelain/build.py --verify-only

```
