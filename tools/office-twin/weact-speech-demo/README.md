# WeAct 发言气泡 Demo v0.1.0

双击 `启动-WeAct-气泡Demo.bat`，或在已运行时打开 [本机 Demo](http://127.0.0.1:5196/)。页面以当前正式版白瓷办公室和工位为底图，首次出画会定位到石萌。关闭启动窗口可以停止 Demo。

等页面显示「等待石萌在群里发文字」，用石萌的 WeAct 账号在「智算测试」发一条新文字。打开或切回 Demo，通常几秒内会在石萌头顶显示气泡。再次查看小人可点「定位石萌」。每次更新展示最新一条文字，超过 240 字的气泡省略末尾。

本机服务使用正式 WeAct 应用身份进行只读历史查询，按群 ID 和已核对的发言人 ID 筛选。展示范围从 Demo 服务启动时开始。最新消息暂存在 Demo 进程内。同一服务最多每 5 秒查询一次，页面隐藏时暂停刷新。服务仅监听本机 5196，正式复核通过 Astra 原有 5189 服务执行。

在正式办公室 v0.46.3 的构建上已核对群与人员身份、WeAct 历史读取、实际 WebGL 出画，以及示例文字气泡和石萌小人的位置绑定。真实新发言的验收可用上面的试用步骤完成。
