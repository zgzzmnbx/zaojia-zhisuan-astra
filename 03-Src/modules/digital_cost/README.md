# 数字化造价模块适配层

宿主 UI v0.11.35 / 独立应用 v0.8.5 / 协议 digital-cost-host/1，2026-10-30。

本目录只维护 Astra 的容器、主题与可见性通信、固定上游转发和按需启动。计数、计价、识别、复核与导出均由独立应用负责，不在宿主复制规则。

- 唯一业务源码：`D:\Codex-Temp\261018-【数字化造价】数字化项目造价智能体`。
- 固定运行包：项目根 `runtime/modules/digital-cost/`。其中 `.venv` 是独立依赖，`frontend` 是构建产物，`release` 是 wheel，`data` 是独立业务数据及私密模型配置，`logs` 是服务日志。禁止删除或用开发目录覆盖 data。
- 模块只监听 127.0.0.1:18768，首次进入由同源 POST 启动，不属于主宿主启动门禁。端口冲突只报错，不停止占用进程。独立服务可跨宿主重启继续运行；再次进入先核对身份与版本，不重复启动。
- 页面及 API 统一位于 `/modules/digital-cost/`。主 CSP 保持 connect-src self；iframe 不含外部导航权限。通信同时校验 origin、source 和协议；主题同步不刷新 iframe。
- 写操作沿用独立服务的会话、CSRF、幂等键和修订校验；模块任务不绑定 Astra 旧 job_id，也不自动读取宿主附件。当前是本机单操作人模式，不是多用户授权方案。
- 同会话导航保留 iframe 与草稿；离开停止界面轮询，已发起的 AI 任务仍由独立服务管理，返回可继续查看。不会因导航自动重发识别。
- 网关限制输入12MB、响应64MB、4个并发请求，连接超时2秒、读写超时150秒，不自动重试写入或模型调用。进程采用较低优先级；这不是内存硬配额，也不是安全沙箱，仍需控制演示资料规模。

## 单独停用与回滚

在正式宿主 `runtime/astra-service/config/digital-cost.local.json` 写入 `{"enabled":false}` 后，模块启动与访问即被拒绝，不需重启 Astra。停用不删除数据，也不自动结束已在执行的任务。恢复时改为 true；配置缺省为启用。

宿主回滚按本轮发布清单恢复已备份文件，新增模块文件可保留但旧宿主不引用。不启动备份目录。模块版本回滚须先核实18768进程身份并正常结束本模块，再恢复对应 wheel/前端；不得回写或清理原数字化工程。

## 重建

先在业务源码构建 v0.8.5 wheel 与前端，再用同版本 Python 执行 `tools/package-digital-cost.py --source <业务源码> --target <新的运行目录>`。工具拒绝覆盖已有目录，依赖复制排除 editable 引用，不共享源码环境。发布清单不含 data 和密钥。
