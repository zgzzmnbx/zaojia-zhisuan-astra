# 项目沙盘工作台 v0.10.0

入口为正式 5189 工作台。默认沙盘模式，经典模式按项目（未分组则按对话）保存。原聊天保持同一实例，支持已有分栏拖动与键盘调整；收起/恢复不清除输入。

## 与独立预览的交互对应

| 原预览特性 | 工作台接入 |
| --- | --- |
| 点击建筑/名称 | 原 GLB 区域拾取，950ms 缓动推近到约25场景单位，突出所选建筑 |
| 右侧功能卡 | 沿用右侧位置，显示功能用途与真实入口；关闭或 Escape 回全景 |
| 下方状态小标牌 | 与名称分开点击；显示当前任务真实状态、匹配数量与金额 |
| 节点结果卡 | 在该标牌旁展开，空间不足改到左侧，避开功能卡、聊天和底部工具；随镜头/窗口移动 |
| 全部功能 | 沙盘右上角保留普通按钮等效入口 |
| 环游/缩放/复位 | 保留；用户拖动或选择建筑停止自动环游 |
| 日间/夜航 | 保留哑光材质、浅蓝河道、夜航发光；接入统一主题 |
| 阴影 | 保留静态接触柔影与1024缓存投影；只在材质/场景/开关变化时更新 |
| 聊天折叠 | 收起/恢复同一个原聊天，原草稿保留 |
| 完成态示例 | 不带入正式平台，改为当前会话/job的真实投影 |
| 蓝色信息流 | 路线保留，开关开启时持续流动；仅为信息传递示意，不冒充真实任务进度 |

## 数据与资源边界

`node-state.ts` 只读 `currentProjectSnapshot` 校验过的当前成果。金额来自原费用汇总；缺失值不变成0。报告存在不等于已批准。协同展示同job最近派发轮次，标明需核对当前成果版本；发送仍走原确认卡。

`ProjectSandbox.tsx` 只提供导航与结果查看。GLB 来自 `05-视觉识别/02-3D场景/white-sandbox-v0.1.0/white-sandbox.glb`；Blender工程和独立样机不改动。`scene.mjs` 持有WebGL资源，离开销毁；关闭信息流和环游后静止停帧；隐藏或设置打开时停止渲染；遵循减少动效。加载失败仍可用普通功能按钮/经典界面。

## 验证

运行根目录 `npm test` 与 `npm run build`。业务纯函数测试位于 `tests/project-sandbox.test.ts`。实际浏览器验收和界限见 `00-docs/handoff/2026-10-14-项目沙盘工作台验收.md`。浏览器只读诊断入口为画布容器上的 `__sandboxState()`，用于核对帧数、阴影刷新和镜头，不执行业务。
