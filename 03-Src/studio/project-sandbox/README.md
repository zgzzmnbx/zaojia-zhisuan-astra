# 项目沙盘 · V11

v0.11.6 只使用 `visual-mode-scene.mjs` → `baked-mode.mjs` → 冻结 V11 模型。原实时写实渲染器、旧模型、光照调试和夜航链路已归档移除；旧选择规范化为 baked，保留 V11 现有参数，不写回或删除旧偏好。

`ProjectSandbox.tsx` 继续投影当前对话、任务、成果、进度、详情和既有业务入口。画面、布局和主题变化不重建业务状态。`baked-surfaces.mjs` 和原显示参数保持本轮改动前内容。

`building-entrance.mjs` 按连通构件计算临时刚性平移；V11 在材质分区后创建私有材质/几何，片元着色不变。只在页面首次可见时领取，减少动效直接显示完成态；隐藏/离屏不推进时钟，导航/任务/参数变化及销毁立即归位并释放。阴影与倒影深度随动画帧失效刷新。鸟瞰距离支持 35–140%，默认及保存值不变。

来源、归档恢复和验收见 [本轮记录](../../../00-docs/handoff/2026-10-23-v0.11.6-原效果归档与V11装配.md)。
