# 项目沙盘工作台 v0.10.46

首次可见开场：`building-entrance.mjs` 按页面生命周期领取一次资格，七栋楼的原有构件先在空中悬浮散开，再从低到高归位，约4秒装配完成后淡入标签。导航/任务开始立即完成，减少动效直接显示，后台冻结；不参与业务进度计算。

默认布局为全幅沙盘底层加左侧磨砂悬浮聊天；经典模式为聊天底层加右侧沙盘卡。两个模式复用同一聊天/任务与 Three 场景；切换不发送业务请求、不清空草稿。

从沙盘开始上传或载入样本，识别完成后保持当前沙盘布局；结构确认留在聊天卡，主动点击“核对字段”才打开编制设置。工作中仅下方状态卡与进度抽屉使用主题色，上方建筑标题保留磨砂样式。

`scene-layout.ts` 统一计算聊天遮挡、标牌及底部工具边界；Three 相机 viewOffset 将当前目标投影到可见区域中心，HTML 标牌使用同一边界。聊天调宽与隐藏通过 ResizeObserver 更新构图。


入口为正式 5189 工作台。默认沙盘模式，经典模式按项目（未分组则按对话）保存。原聊天保持同一实例，支持浮窗右缘拖动与键盘调宽（预留沙盘操作空间）；收起/恢复不清除输入。

## 数据与资源边界

`node-state.ts` 只读 `currentProjectSnapshot` 校验过的当前成果。金额来自原费用汇总；缺失值不变成0。报告存在不等于已批准。协同展示同job最近派发轮次，标明需核对当前成果版本；发送仍走原确认卡。

`ProjectSandbox.tsx` 只提供导航与结果查看。GLB 来自 `05-视觉识别/02-3D场景/white-sandbox-v0.1.0/white-sandbox.glb`；Blender工程和独立样机不改动。`scene.mjs` 持有WebGL资源，离开销毁；关闭信息流和环游后静止停帧；隐藏或设置打开时停止渲染；遵循减少动效。加载失败仍可用普通功能按钮/经典界面。

## 验证

运行根目录 `npm test` 与 `npm run build`。业务纯函数测试位于 `tests/project-sandbox.test.ts`。实际浏览器验收和界限见 `00-docs/handoff/2026-10-14-项目沙盘工作台验收.md`。浏览器只读诊断入口为画布容器上的 `__sandboxState()`，用于核对帧数、阴影刷新和镜头，不执行业务。

## 楼顶标牌

统一使用平面磨砂 DOM 标签，不生成三维牌体、文字纹理或支柱。右上角“视图”的“楼顶标牌”开启后，标签固定在所属建筑屋顶投影处；关闭恢复原悬浮避让。偏好沿用 `astra.appearance.v1` 的 `sandboxRoofLabels`，默认关闭。`roof-labels.mjs` 仅向下拾取所属建筑顶部并提供锚点，不创建场景几何。

标题点击聚焦，下方状态直达已有功能，保留金额、风险及任务进度。进度从状态卡下方展开，正常结束1秒后收回，失败/取消2.4秒后收回。模块导航与键盘操作仍可使用。

右上角常驻“全景”按钮，点击空地或 Escape 也可恢复默认镜头。再次点击已选中的建筑标题返回默认鸟瞰；模块菜单和模型点击仍只聚焦，不叠加飞行。悬浮标牌避让的累计偏移限制为相对建筑投影锚点±120px；切换建筑或返回全景重置布局，飞行期间取消鼠标点击产生的焦点锁，屏幕外较远节点不拉长引线显示。

## 局部雾蓝染色（v0.10.33）

`building-paint.mjs` 迁移已确认示例的局部空间遮罩，`paint-progress.mjs` 共用一个可见时间轴驱动着色和节点进度条。现有请求没有量化完成百分比，运行时渐进趋近 90% 的视觉位置、不显示数字；只有当前有效成果完成后用 700ms 收尾。这个位置是活动动效，不是业务完成比例。请求结束但等待确认时保留未完成颜色，错误/取消冻结；已完成且有风险的复核仍保留完成色，风险含义由原文字/等级表达。

浓度存于 `astra.sandbox.paint-strength`，范围 0–100%，默认 70%；0 为白模。切换夜航、选中状态、冷白和设置不重置进度。历史有效成果直接恢复完成色，不重播。新 job/对话隔离，重跑当前建筑重新开始。页面隐藏/画面暂停不推进视觉时钟，后台业务不受影响，返回时按最新结果收尾。减少动效时不模拟推进，完成直接显示最终颜色。

遮罩针对当前 GLB 的世界坐标校准，更换模型时须重新验收；不染 Logo，不新增后处理、定时轮询或 React 逐帧更新。浏览器诊断 `__sandboxState().paint` 与 `.paintStrength` 可核对阶段及视觉位置。

### v0.10.34 聚焦信息布局

`scene-layout.ts` 提供共享聚焦留白与自然投影裁切：详情占右列，镜头目标落在左侧剩余区域，950ms 同步过渡。楼顶模式及所有近景模式的背景标签只保留能容纳的完整卡片，越界、相交或覆盖焦点建筑时隐藏，不做边缘压缩。全景及全部模块可重新定位；不改业务或任务状态。

### v0.10.35 标签可见性余量

- 鸟瞰始终保留全部七个建筑标题，复用停稳后的小幅避让；次要状态可收起，计价/风险状态优先保留。以下隐藏阈值只作用聚焦或任务近景。

标签不因擦边立即消失：普通遮挡面积超过45%隐藏，降到30%以内恢复；越界面积超过60%且深度超过48px隐藏，回到40%以内或28px以内恢复。目标建筑遮挡门槛35%/22%，选中详情始终优先。可见性历史只归当前镜头选择，切换建筑/模式/回全景清理，不参与业务状态。

### v0.10.36 连续标签让位

`marker-motion.ts` 保存实际渲染位置，切换/恢复从当前位置续接950ms轨迹。近景详情位于焦点右侧210px以内；隐藏背景卡先滑出画布，恢复从退出点滑入，不淡出淡入。纯布局动效，共用既有RAF并遵循减少动效。详情宽度与下拉高度动画同步，无延迟opacity入场。

## v0.10.56 光照与局部辉光

视图面板提供“质感增强”与“聚焦辉光”独立开关。Cycles 离线光照、1K HDRI 和微弱灰泥法线保持冷白风格；仅聚焦建筑底部显示柔光，420ms 切换，不使用全屏后处理。任务完成沿用当前镜头焦点，返回全景后光圈退出。资源、授权及离线复现见 [lighting-v1](../../../05-视觉识别/02-3D场景/lighting-v1/README.md)。只投影既有任务，不改变编制、染色或填写授权。
