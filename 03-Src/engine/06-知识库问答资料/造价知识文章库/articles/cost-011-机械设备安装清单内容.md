# 机械设备安装清单包含哪些工作

通用安装工程第一章把机械设备安装、静置设备安装以及锅炉和辅助设备安装放在同一章。机械设备清单的阅读重点是本体安装、基础灌浆、检查接线、单体调试和试车等工作是否已经组合，不能只凭设备名称判断费用范围。

资料对多级离心泵、LNG高压输送泵、海水工艺泵和消防泵分别描述。不同设备的组合内容并不相同，有的包括泵桶和泵盖安装，有的包括电机安装与检查接线，还有的包括柴油机、烟囱或液位计安装。设备特征直接影响清单选择。

压缩机组项目还可能包含成套橇安装、润滑油系统、干气密封、控制系统、动力和机械配线以及调试。空气冷却器、起重机和气化器也各有自己的组合内容。清单说明中的动作比设备简称更能说明工作范围。

编制时应把设备本体、附件、基础灌浆、试车和外接专业内容分开核对。施工现场出现电气或仪表工作，不代表它们都属于机械设备安装单价，只有清单说明明确包含的内容才能计入。

设备安装项目适合用设备清单和包含内容对照表复核。表中记录设备类型、附件、试验调试、单位和来源定位，遇到缺项或组合冲突时，再回到章节说明和设计文件确认。

设备表还要说明安装位置、基础条件、连接方式和是否需要单机试运转。设备本体、配套管线、电气仪表和保温防腐可能分属不同章节，应按工作对象分别查找，不能只按设备名称合并。
