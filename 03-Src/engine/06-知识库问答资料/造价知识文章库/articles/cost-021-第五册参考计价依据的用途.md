# 第五册参考计价依据怎样辅助查价

第五册的作用在于提供参考计价依据，帮助读者理解油气输送管道工程中一些专业工作怎样寻找可比清单。它与第一册的关系密切，但查到第五册的条目时，仍要回看工程对象、施工方法和项目条件，不能只因名称相近就直接套用。

阅读第五册时，先看目录和章节说明，再看清单名称、项目特征、计量单位以及工作内容。说明中可能写明本项包括的工序、配合工作和材料范围，也可能说明哪些内容应另行计算。把这些信息和设计文件放在一起，才能判断它是否适合当前项目。

参考依据还可以帮助处理新工艺、特殊施工方法和第一册中描述不足的工作。例如管道焊接、放空回收或场站配套工作，可能在第五册或其他册中找到更接近的表达。使用时要记录采用的章节、清单特征和与当前项目的差异。

当参考条目与项目条件不完全一致时，应把差异列成待复核事项。差异可能来自管径、壁厚、焊接方式、施工环境、运输条件或工作内容。需要调整时，调整理由应有资料依据，不能把经验中的数字直接当成正式价格。

第五册更像查找和比对的工具。正式成果仍须结合当前有效文件、项目设计和人工复核结果，文章只提供阅读路径，不代替清单单价裁决。

保存比对记录时，应写明参考条目与项目工作的相同点和不同点。这样即使后续更换设计方案，也能看出原来采用该条目的依据，不会只留下一个无法解释的价格结果。
