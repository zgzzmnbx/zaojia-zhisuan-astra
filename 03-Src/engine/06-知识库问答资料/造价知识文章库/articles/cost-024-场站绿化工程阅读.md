# 场站绿化工程怎样判断计价入口

场站绿化属于管道工程配套内容，可能与站场建设、道路、边坡恢复和环境整理同时出现。查找资料时，先确认绿化发生的位置、施工对象和完成要求，再进入其他工程或相关费用依据中寻找对应说明。只看场站名称，无法判断清单范围。

项目特征需要说明种植区域、植物或草种、土壤处理、灌溉条件、养护要求以及成活验收口径。若设计文件只给出绿化面积，没有说明种植类型和做法，工程量虽有数字，清单特征仍然不足。缺少条件时应提出补充资料要求。

绿化工作还可能和水土保持、临时用地恢复、道路边坡防护发生交叉。查价前要把永久工程和临时恢复分开，把种植、整地、灌溉和养护分别与相关章节说明比较。相邻工作由不同依据表达时，要保留相互衔接的说明，防止漏项或重复。

清单单位应与工程量取定方式一致。面积、株数、长度或成活养护次数代表的计量范围不同，不能把一种单位下的工作内容直接换到另一种单位。采用参考条目时，还要检查当地施工条件和项目合同要求。

场站绿化文章适合帮助读者建立查找顺序。正式成果仍以设计文件、招标范围和当前有效计价依据为准，不能只凭经验判断包含范围。

绿化项目的成活要求和养护期限也会改变工作内容。若合同把绿化恢复、临时占地复原和永久景观工程分开管理，应按各自的设计范围和验收条件分别列项。
