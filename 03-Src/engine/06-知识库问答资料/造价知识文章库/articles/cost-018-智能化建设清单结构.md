# 智能化建设清单怎样拆分

其他工程第四册中的智能化建设章节包含多类项目。资料目录把采办智能化、施工智能化等内容分开，正文还出现工况数据采集、无人机影像数据采集、作业面视频监控、穿跨越工程视频监控、站场视频监控和视频监控中心等方向。

这些项目共同服务于数据采集、现场监控和工程管理，但每项工作的对象不同。编制时应先确认采集对象、安装地点、传输方式和成果用途，再查清单说明。一个系统名称不能替代全部项目特征。

智能化建设经常与通信、电气、仪表或软件系统同时出现。摄像机、传感器、线路、存储和平台可能由不同章节或不同依据计价。清单选择要根据资料规定划分，不宜按照采购包或合同名称简单归并。

工程量还需要和设计方案、设备表、点位表或视频监控布置相互核对。若只知道系统名称，不知道点位、设备类型或服务范围，匹配结果应保持待复核。文章不对项目金额和设备数量作推测。

复核智能化建设时，可以把数据采集、现场监控、通信传输和平台服务分别列出，再逐项记录来源。这样既能看清清单边界，也能减少把数字化项目的所有费用放进一个笼统项目的风险。

各部分还要对应设备表、网络拓扑、软件功能和验收指标。采购设备与开发配置、安装调试和培训服务应分别核对，接口责任不清时要留下待确认记录。
