# 人工工日价格怎样放回计价依据

人工工日价格是费用测算中的基础信息之一。查阅费用定额或相关解释时，先确认工种、工日类型、适用地区、执行时期和价格组成，再判断它能否用于当前项目。不同来源的工日价格不能仅凭数字接近就互相替换。

人工价格可能与定额消耗、地区人工单价、市场信息或项目合同口径相关。使用定额时，要先看该价格是否已经包含工资、津贴、福利或其他费用。使用市场信息时，还要确认采集时间、对象和税费口径，避免把不同口径的数值放在一起比较。

油气管道项目还可能受到偏远地区、冬季施工和特殊作业条件影响。条件是否成立，需要由施工组织、项目地点和有效依据共同说明。没有明确来源的人工调整不能直接写入正式结果，也不能把人工价格变化误认为清单综合单价自动变化。

复核记录应保留价格来源、工种、地区、时期、单位和采用理由。若同一工种存在多个候选，先确认适用范围，再标记待复核。后续更新价格时，要注意与材料、机械和费用定额的时间口径保持一致。

人工价格还要和工程量、定额消耗及其他费用口径相互核对。来源日期不同的价格不能直接拼接，调整过程也要说明采用的基础。项目人员确认后，再把结果用于后续测算，避免把临时询价误写成长期规则。
