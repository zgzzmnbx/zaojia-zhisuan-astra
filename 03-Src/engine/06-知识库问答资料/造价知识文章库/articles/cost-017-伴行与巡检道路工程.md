# 伴行和巡检道路工程怎样查清单

第四册其他工程把道路工程编排为伴行道路和巡检道路。道路项目与管道线路施工关系密切，但它有独立的工程对象和计量规则。编制时应先确认道路用途、位置和施工范围，再查对应章节。

道路工程可能涉及路基、路面、排水、边坡或其他配套内容。清单单价是否已经组合这些工作，需要回到章节说明和具体项目。看到施工现场有机械、材料和运输作业，不能据此把所有费用都并入道路清单。

工程量通常来自路线长度、宽度、结构层和设计断面等资料。不同道路的结构做法和使用条件可能不同，工程量不能用一条线路的经验数值替代。设计资料不足时，应保留需要补充的特征。

伴行道路和巡检道路在功能上都服务管道运行或施工，项目名称却不一定相同。查找时要核对清单编码、道路类型和计量单位，避免把道路修筑、维护或临时便道项目混为一类。

复核道路费用时，建议把道路用途、永久或临时属性、结构做法、工程量来源和清单范围写清。文章用于辅助理解，具体工程仍以有效依据和设计确认资料为准。

还应核对道路服务对象、路基路面材料、排水设施和施工便道的使用期限。道路与运输、巡检或临时施工有关时，费用是否纳入主体工程要结合项目范围和现场方案确认。

道路工程量还要和路线图、断面图及施工组织相互验证。
