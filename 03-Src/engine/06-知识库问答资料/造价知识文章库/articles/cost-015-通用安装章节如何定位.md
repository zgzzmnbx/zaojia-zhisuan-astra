# 通用安装工程章节怎样快速定位

第三册通用安装工程覆盖机械与静置设备、金属结构、工艺管道、自动化控制仪表、电气、通信、采暖通风给排水消防燃气、防腐绝热和阴极保护。目录按专业分组，适合先用工程对象定位章节，再查项目特征。

同一建设项目可能同时使用多个章节。设备安装负责设备本体和相关试车，工艺管道负责管道系统，电气和通信负责各自的线路与装置，防腐绝热和阴极保护又有独立内容。相邻工序需要通过清单说明划分，而不能按施工班组归类。

每个章节通常都会给出包括内容、不包括内容和工程量计算规则。先读这三部分，再看具体清单名称，能减少把措施、试验、材料或配套附件重复计入的情况。表头中的清单编码和单位也应一并保留。

通用安装资料还覆盖油气管道、液化天然气接收站、储气库地面工程和油库等项目。项目类型会影响章节适用范围，设计文件中的站场、设备、管线和系统名称都应作为检索条件。

建立工程对象到章节的索引后，人工复核会更容易。索引只负责帮助查找，最终的单价、工程量和边界仍须按当前有效依据、项目资料和专业判断确认。

定位时可先按设备、管道、仪表、电气、通信、防腐保温和消防等对象分组，再查看章节的工作内容。跨专业项目要保留对象之间的接口说明，防止同一配合工作被漏列或重复列项。
