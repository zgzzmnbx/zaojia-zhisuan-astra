# 自动化控制仪表安装怎样区分范围

通用安装工程第四章专门编排自动化控制仪表安装。仪表项目经常与工艺管道、电气和通信同时出现在一个站场中，清单阅读时应先确认仪表对象，再看章节的包括内容、使用方法和工程量计算规则。

仪表安装可能涉及仪表本体、取源部件、安装附件、配线、检查和调试等工作。具体项目是否组合这些内容，取决于清单说明和项目特征。不能因为施工人员同时完成接线或调试，就把其他专业所有内容都归入仪表项目。

仪表数量与工程量单位需要回到仪表清单、系统图和设备表核对。压力、温度、流量或液位等名称只能帮助定位，不能替代规格、安装方式和控制系统关系。设计文件未说明的特征，应保留待确认。

仪表与通信项目的边界也值得关注。通信工程关注传输系统和线路，仪表工程关注控制测量对象。两者可能共用路径或机柜，但清单项目和计量对象仍应分开判断。

复核结果应记录清单编码、仪表类别、安装位置、单位、组合内容和来源。遇到候选冲突时，先补齐设计特征，再由专业人员确认。文章只提供查阅顺序，不替代正式计价决定。

仪表本体、取源部件、接线、校验和系统调试可能分属不同工作内容。查找时要把现场安装与控制系统软件配置分开，确认每一部分是否已在其他合同或章节中体现。
