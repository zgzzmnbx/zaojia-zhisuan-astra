# 清单子目不足时怎样做补充

当现有清单子目不能完整表达项目工作时，应先确认是否只是名称或项目特征填写不完整，再判断是否需要补充清单单价。补充的前提是已有依据不能覆盖实际工作，不能因为查找不方便就绕过原有章节说明。

补充前要整理工程对象、施工工序、材料设备、计量单位和工作内容。还要检查第一册至第五册及相关参考依据，确认是否存在可以直接使用或经过合理说明后使用的条目。只有完成这一步，补充范围才比较清楚。

补充清单应写明采用的行业或工程所在地依据、参考条目、适用条件和差异处理。若项目采用了参考条目中的部分工作，应把保留内容和剔除内容分别说明。涉及材料、设备、措施或税费的部分，也要明确它们是否已经纳入综合表达。

补充结果需要经过专业人员复核，并在成果中留下可追溯记录。后续若设计条件变化，补充清单也要重新检查。没有依据的估算数字不能伪装成正式单价，更不能直接写回标准知识库。

这类文章帮助读者建立补充流程。实际补充应以当前有效计价文件、项目合同和人工确认结果为准。

补充成果还应注明适用范围、有效期间、工程量来源和后续复核要求。若项目条件变化或正式依据更新，应重新判断补充条目是否仍然适用，不能让一次性的处理结果长期替代标准条目。
