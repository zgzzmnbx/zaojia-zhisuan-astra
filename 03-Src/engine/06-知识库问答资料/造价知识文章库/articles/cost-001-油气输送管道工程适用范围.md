# 从适用范围看第一册油气输送管道工程

读第一册油气输送管道工程，先看它解决的对象。资料把天然气、原油和成品油等油气输送管道安装工程列为适用范围，其他介质输送管道可以参考使用。这个范围决定了读者后面要寻找的工程特征，也提醒我们不能只凭项目名称套用清单单价。

第一册按施工内容分章。土石方和措施工程位于前面，随后是热煨弯管加工、管段防腐保温、管段运输、管段组装焊接、管道穿跨越、清管试压、干燥及氮气置换，后面还有线路附属、无损检测、线路防护、施工便道及便桥和储气库注采管道安装。目录本身就是一次快速定位。

实际查找时，先确认工程对象，再确认施工条件和工程量单位，最后进入对应章节的说明。章节说明会解释清单单价包括哪些工作，哪些内容需要另行计算，以及工程量如何取定。只看清单名称不看说明，很容易把相邻工序混在一起。

第一册还规定，部分地区在冬季施工时应按相关章节的规定计取增加费用。清单单价覆盖不足时，可以按行业或工程所在地的计价依据编制补充清单单价。补充时应保留依据名称、适用条件和工程量口径，便于后续复核。

这份资料适合做查找和理解的入口。正式编制仍要以当前有效依据、项目条件和人工复核结果为准，不能把阅读文章当成具体项目的裁决结果。
