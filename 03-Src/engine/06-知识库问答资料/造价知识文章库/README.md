# 造价知识文章库

本目录承载现有知识库问答资料之外的阅读型造价文章和人工确认关系。首期固定 50 篇，按油气输送管道工程、储罐制作安装工程、通用安装工程、其他工程、参考计价依据、全费用清单单价、建设项目其他费用、概算指标与费用定额、数字与信息化项目投资、软件行业基准数据十个专题组织。

## 数据边界

文章只使用 `../造价AIW资料库/manifest.json` 中状态为 `ready` 的 13 项 AIW Markdown 资产作为依据。文章清单中的 `source_basis` 保存资产编号、输出文件名和可定位标题路径，方便读者回到资料源核对。原 AIW 资产、原 manifest、知识问答索引、结构化计价库、规则表、经验池和知识记忆均不在本目录修改范围内。

这里提供阅读、查找和关系发现，不参与基价、单价、实物工作费调整系数、技术工作费调整系数、风险等级、正式标准或成果文件裁决。文章中的项目条件、金额和版本判断都不能替代当前有效依据、设计文件、合同和人工复核。

## 文件约定

- `manifest.json` 是本目录唯一机器可读清单，保存文章元数据和无向关系边。
- `articles/` 只保存正文 Markdown，不使用 front matter；正文首行是标题，正文长度按汉字计为 450 至 650 字。
- `reports/` 保存内容质量和关系完整性报告，由校验脚本生成。
- 文章和关系是发布期冻结数据，运行时不调用大模型、不扫描全文、不计算向量关系。

## 校验

在项目根目录运行：

```text
python tools/validate_cost_article_library.py
```

校验脚本会检查文章数量、正文长度、文件对应关系、分类数量、来源字段、标签、关系边、连通性、度数和安全相对路径，并更新 `reports/内容质量报告.md` 与 `reports/关系完整性报告.md`。正文硬规则另按项目 human-writing 约定运行 `check_prose.py`，不把文章送入外部服务。

## 运行接口

后端通过独立只读接口提供列表、单篇正文和冻结图数据：

- `GET /api/knowledge-articles`
- `GET /api/knowledge-articles/{article_id}`
- `GET /api/knowledge-articles/graph`

列表只返回元数据，正文按点击读取，图谱页签才请求图数据。文章库缺失或损坏时只显示本模块错误，现有知识问答、填价、预警、报告和协同流程继续按原逻辑运行。
