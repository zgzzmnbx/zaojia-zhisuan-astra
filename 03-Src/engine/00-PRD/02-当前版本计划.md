5. 首期不接现有 RAG，不参与三个数字、正式规则、经验池、知识记忆、风险和成果裁决；模块故障只做局部降级。

红线：实现前后必须提供主 bundle、Network、图谱卸载、宽屏零变化和 V3.1 Excel / Word 成对回归证据。任一现有逻辑变化或性能退化均不得并入稳定版本。

### P2：智能协同场景化编审

项目整体排序仍放在专业主线、回归基线和数字化项目助手联合验收之后；进入本模块开发时，按模块内部 P0 / P1 / P2 推进：

1. **模块 P0-A｜外部任务主动派发模拟**：在“智能协同”页模拟外部造价系统产生标准 `TaskEnvelope`，生成任务专用待填 Excel，先通过第二层应用机器人向“智算测试”授权群发送经典任务卡和 Excel；保存目标编制人平台 ID，群聊 / 单聊共用同一投递服务，精准单聊经主动触达权限实测后启用。
2. **模块 P0-B｜简易多人复核**：完成 `编制 → 并行多人复核 → 复核完成`，冻结成果版本，通过 WeAct 通知和安全链接进入网页处理；独立收集每名复核人的结论和可定位意见，形成意见汇总并由编制人逐条回复；所有复核人通过后完成，任一人退回则生成修改轮次，不强制增加审批人。
3. **模块 P1｜标准编审与风险协同**：增加风险派单、截止时间、催办、可选审批、正式发布和归档；验证企业 WeAct 原生审批或经典卡片回调后，再开放可靠的通过 / 退回轻量动作。
4. **模块 P2｜场景智能与管理治理**：增加材料检查、流程和复核人推荐、审核摘要、版本差异、退回意见转待办、多维表格元数据镜像、统计分析、权限审计和生产监控。

统一边界：网页和后端任务服务是业务状态、成果版本和审核结论的唯一真相；WeAct 只负责人员触达、提醒、安全跳转和经验证的轻量操作，不直接修改价格、系数、规则或风险等级。

## 7. 本阶段不做

- 不重构核心匹配引擎。
- 不让大模型直接裁决最终价格或系数。
- 不批量重命名历史目录、知识库文件、样例和兼容脚本。
- P0 不移动现有结构化计价库、规则表、经验池和报告模板，只通过 Manifest 引用。
- P0 不把“规划中”的通用服务类包装成已上线能力。
- P0 不建设在线 Skill 商店，不安装或执行任意外部 Skill 脚本。
- 对话式工作台不删除专业页面，不用模型文本伪造任务执行，不把全部聊天自动写入知识记忆。
- 不把数字化项目助手业务代码复制进造价智算。
- 不在专业主线和回归基线未收口前优先建设复杂审批、台账和组织权限。
- 不构建或维护任何 Tauri 路线（含 Windows、Linux、deb、AppImage），除非用户明确要求恢复。
