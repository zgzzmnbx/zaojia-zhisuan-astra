- 共享图形基础和 `VIS-01`—`VIS-15` 都有真实入口、真实数据契约、完整状态、自动化和浏览器验收。

## 六、必须完成的 15 张图

详细数据字段、口径、空态和禁止事项以模块 20 PRD 为准；以下任何一项不得省略。

- 固定表达 `Task → Run / ReviewRound → ArtifactVersion → ExperienceLineage`。
- 候选、确认、提升、命中、撤销和疑似失效必须分开。
- 使用稳定 DOM + SVG 布局，不引入力导向图，不回显路径与秘密。

### VIS-03：偏离率—样本数散点图

- X 轴为样本数，Y 轴为现有绝对偏离率。
- 使用本次真实低 / 高风险阈值；阈值不一致时不得伪造统一线。
- 点可键盘聚焦并跳到准确 Sheet / Excel 行。

### VIS-04：经验区间子弹图

- 最小—最大为区间、均值为刻线、当前值为点。
- 当前值超区间时扩展坐标，不裁切。
- 同时保留数值、单位、样本数和偏离率文本。

### VIS-05：AI填价候选价格点图

- 当前值与程序排序后的知识库 / 经验池候选在同一价格轴比较。
- 点选只改变现有待确认候选，不自动写值。
- 必须继续由用户执行原确认写入，不改变候选排序或生成候选外数值。

### VIS-06：结果预览行风险迷你地图

- 以窄轨道显示全量 / 当前可见行状态，并明确当前统计口径。

- 点击准确跳到 Sheet / Excel 行，不压缩主表、固定 AI 列和滚动。

### VIS-07：结算审减金额瀑布图

- 只使用真实上报明细口径、签名差额和审核建议明细口径。
- 支持建议审减和建议增加；三者对不上时显示数据契约错误，不静默修正。
- 保留“辅助审核、结构化明细试算、待人工审定”边界。

### VIS-08：分 Sheet 风险小多图

- 每个 Sheet 使用相同尺度展示审核行、通过、高 / 中 / 低风险、待人工、自动调整。
- 如现有结果缺少聚合，只增加向后兼容的只读 `sheet_summaries`。
- 点击过滤原审核发现，不建立第二份风险状态。

### VIS-09：工作量抓取结果分组条形图

- 展示填写、覆盖、保守跳过、未匹配、一对多预警和预警行等原始计数。
- 指标可能重叠，默认不得做 100% 堆叠或虚假总占比。
- 点击只过滤现有日志，持续区分行数与单元格数。

### VIS-10：复核人状态矩阵

- 行为复核人，列为平台、轮次、投递、复核、意见和更新时间。
- 飞书 / WeAct 平台分开；颜色之外显示明确状态文字。
- 只读，不扩大受众、不重试发送、不通过 / 退回。

### VIS-11：复核轮次阶段带

- 展示真实轮次、成果版本 / 哈希、人员结论、退回 / 通过和时间。
- 旧轮次只读，单个人通过不能显示全轮完成。
- 缺历史接口时只增加原状态机上的只读聚合。

### VIS-12：可信经验来源 / 治理双条图

- 来源事件与治理结果使用两个独立图，不混成同一分母。
- 检索命中、版本更正、疑似失效保持独立指标。
- 只统计真实审计，不估算节省工时、准确率或模型学习次数。

### VIS-13：项目版本阶段趋势

- 使用共享 X 轴的上下两张小图：数量与金额分开。
- 背景阶段来自真实 ArtifactVersion / ReviewRound。
- 少于两个真实版本显示数据不足；点击版本打开真实成果或血缘。

### VIS-14：RAG 检索通道并列图

- 只放大模型调试模式，展示真实 BM25、结构化、向量、融合 / 重排轨迹。

- classic 默认与 hybrid 手动选择保持不变，不外溢到三个数字和 AI填价。

### VIS-15：专业 Skill 能力矩阵

- 使用 Registry / Manifest 真实状态和能力列，不使用雷达图或成熟度分数。
- 已上线、规划、停用、不可创建任务必须明确。

## 八、UI 是硬门禁，字体不能忽大忽小

### 唯一设计来源


### 唯一字体与字号

- 页面标题：28px。

- 图形 / 面板标题：16px。
- 正文和关键解释：14px。
- 表格、控件、图例和按钮：13px。
- 来源、单位、空态和图形摘要：12px。
- 纯数字技术坐标：只有空间确实受限时才可使用带 CSS 注释的 `--dws-font-size-11`。

- 纯白工作区、1px 浅边框、6—8px 圆角、无常驻阴影、无渐变、无卡片套娃。
- 中性分析使用现有多蓝 token；标准命中绿、经验琥珀、待人工橙、高风险 / 失败红、处理中蓝、未运行灰。
