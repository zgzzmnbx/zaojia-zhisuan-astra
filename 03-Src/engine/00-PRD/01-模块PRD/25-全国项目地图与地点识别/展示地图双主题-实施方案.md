# 展示地图双主题实施方案

文档版本：v1.1.0｜2026-09-13｜状态：已批准方向，按独立页面架构实施中。

这是模块 25 的增量设计附录，仅负责原“全国项目”地理地图页面与新增“地图展示”页面的并列共存，以及展示地图的视觉和交互。模块主 PRD 继续管理项目、识别、人工确认与数据安全。本文不代表原 G0—G6 已完成，也不授权重做地点识别、模型适配器或计价逻辑。

## 1. 做成什么样

设计名：冰蓝蜂巢项目地图。基于用户提供的浅色数据可视化参考，用正面中国地图、细密六边形陆域、轻柔厚度、白色悬浮项目标签构成主视觉。让观众先看见项目分布，再看见选中项目的业务摘要。

两个主题：

| 项目 | 地理地图 | 展示地图 |
| --- | --- | --- |
| 用途 | 地理浏览、地点核对 | 项目汇报、比赛展示 |
| 渲染 | 保留现有 L7 / MapLibre | 新增 SVG 矢量渲染器 |
| 地图 | 现有世界底图，默认中国视野 | 中国正面轮廓＋六边形纹理＋轻省界 |
| 标注 | 保留已有行为 | 锚点、短引线、避让标签、选中高亮 |
| 数据 | 现有 SpatialMapItem[] | 同一份 SpatialMapItem[] |
| 页面 | 保留已有布局与入口 | 新增“地图展示”并列二级页面，宽地图＋业务摘要；支持全屏展示 |

“全国项目”继续使用原有地理地图页面；“地图展示”是填价工作台下的独立二级页面，不把两种渲染器塞进同一页，也不互相替换或重置。两页可共享同一接口返回的 `SpatialMapItem[]`，但筛选、选中项目和渲染器状态在各自页面内维护，打开或切回展示页不改变原地理地图的相机、筛选和业务行为。不触发地点确认、上传、重算或创建项目。展示地图是项目展示视图，不是项目管理第二套实现。

## 4. 固定布局

用内容容器宽度而不是浏览器宽度选择布局。遵守现有 1024px 窄屏隔离约束。

| 内容宽度 | 展示地图布局 |
| --- | --- |
| >=1180px | 地图剩余宽度＋320px 详情，间距24px；地图约70% |
| 900—1179px | 地图剩余宽度＋280px详情，间距16px；地图标签最多3张 |
| <900px | 地图满宽；点击打开详情抽屉；下方保留项目列表入口 |

标准地图舞台高度 `clamp(460px, 62vh, 720px)`；手机高度 `clamp(360px, 55dvh, 560px)`。不强制挤到一屏，375px 下可纵向滚动。地图轮廓通过 fitExtent 自动适配，四周预留顶部32 / 左右40 / 底部44px 的最小安全区；小容器允许缩至16px。

页头：原“全国项目”页保持既有标题、筛选和刷新入口；新增“地图展示”页使用独立页头，并提供自己的刷新、范围和全屏展示控件。全屏动作只在展示页出现；数据范围“演示项目｜真实项目”独立，不与页面入口混成多个主题标签。

展示模式只保留一行紧凑摘要：当前范围项目数、已完成数、待复核项目数。后两项没有可靠字段则不显示，不能拿风险数代替复核数。每个数字均按去重项目计算，并与列表一致。

普通页面不新增常驻统计卡阵列。全屏模式保留展示页标题、范围、退出入口和来源折叠项，隐藏项目主壳干扰；使用布局覆盖模式即可，不依赖系统 Fullscreen API 权限。退出 / 离开展示页 / 返回“全国项目”页自动恢复滚动和原布局。Esc 先关闭最上层弹窗，再退出全屏。

## 5. 视觉规格：不能自行发挥的部分

以下色值是展示主题局部令牌，禁止修改全局主题。字体复用自托管苹方及现行字号 token。

| 局部令牌 | 浅色建议值 | 用途 |
| --- | --- | --- |
| --dmt-surface | #F7FAFF | 地图舞台 |
| --dmt-land | #E2ECFA | 陆域连续底色 |
| --dmt-hex | #EDF4FF | 小六边形填色 |
| --dmt-hex-border | #C8D9EF | 纹理边缘 |
| --dmt-land-active | #C3DAF5 | 有项目行政区域 |
| --dmt-outline | #A3BDD9 | 外轮廓 |
| --dmt-boundary | #C4D5E9 | 省界 |
| --dmt-ink | #20344E | 主文字 |
| --dmt-muted | #5E7089 | 辅助文字 |
| --dmt-blue | #2878D6 | 处理中 / 选中 |
| --dmt-green | #639A84 | 已完成 |
| --dmt-amber | #B7791F | 待复核 |
| --dmt-red | #C34B50 | 高风险 / 失败 |
| --dmt-gray | #8996A8 | 归档 / 未知状态 |

地图背景只允许一个低透明度径向冰蓝光晕，例如 `#DFEBFF` 向透明过渡；不加星空、网格背景、随机粒子或霓虹光圈。

厚度：只给完整陆域底层偏移(0,3px)，使用低透明蓝灰；最多一个轻柔阴影。地图保持正面，不用 perspective、rotateX 或三维地球。轮廓及项目锚点共用投影。

六边形：最终屏幕边到边约6—9px、间隔约1px。优先使用 SVG pattern 加 clipPath，避免每个六边形成为 React 节点；不要让大网格吞掉省界。地图所在省份用底色 / 纹理深浅强调，六边形数量不代表项目数、投资额或工作量。

阴影局部例外：仅新展示主题的地图底层和悬浮标签可以用 `0 8px 24px rgba(47,78,121,.10)`，普通详情区域、项目列表和原地理主题继续服从无常驻阴影规范。圆角：标签10px，其他沿用项目规范。不要给每个数字、字段、标签再套卡片。

文字：页标题28px、模块20px、详情标题16px、标签项目名14px、正文14px、按钮13px、辅助12px。不能靠缩成10px解决拥挤。地图节点文字用 SVG text 或 HTML 覆盖层，明确继承苹方；文字不参与整张地图缩放导致变小。

深色环境：定义在展示主题且暗色组合类内，舞台深蓝灰、陆域中蓝灰、正文高对比浅色，保留蓝 / 绿 / 琥珀 / 红状态语义。不得简单反色图片或把浅色地图背景硬塞进暗色主壳。浅色作为第一视觉基线，暗色单独验收。

## 6. 图层顺序与地理准确性

从底到顶：背景光晕 → 陆域厚度 → 陆域底色 → 六边形纹理 → 有项目省份强调 → 省界 / 外轮廓 → AREA提示 → CORRIDOR示意线 → 项目锚点与风险外环 → 引线 → 项目标签 → 焦点 / 弹层。

沿用当前测试地图使用范围与来源说明，不新增审批环节。展示版需可本地加载：中国轮廓和省界必须来自现有可用资产或当前已采用来源的本地版本，记录来源链接、许可和内容版本。不能从参考截图描中国轮廓，也不能拼造边界。不能把其用途升级为正式测绘地图。

实现时检查已有 `chinaTestMask.ts` 的结构和精度；它不足以支撑省界时，使用当前地理主题已经采用的省级几何数据建立本地资产。不要在每次页面打开时拉外部 GeoJSON。素材下载与依赖获取是开发行为，展示运行不能依赖网络地图请求。

首选成熟地理投影工具（例如明确锁定版本的 d3-geo，使用前检查现有依赖）；同一 geoPath / projection 生成陆域、省界、节点和线路。所有坐标使用当前 WGS84 数据，不人工摆点。先验证 MultiPolygon、孔洞、几何绕序和经纬度顺序，防止出现填满整个画布的反向多边形。

台湾及岛屿按当前资产表达；若使用南海插图，必须标注“示意插图”，有独立投影，不能把主地图点位按同一像素比例强塞进插图。首版优先完整展示已有轮廓，不自行扩展岛屿绘制。

境外项目 / 无坐标 / 地图范围外数据：保留在可访问列表，注明本展示图未覆盖，不夹到地图边缘、不生成虚假位置。

## 7. 项目锚点、线路与标注

### 7.1 项目锚点

POINT：实心核心半径4.5px，外围命中区域至少24px，触控至少44px。核心颜色表达业务状态。高风险红色外环、待复核琥珀外环；优先级高风险 > 待复核 > 无环。选中另用蓝色虚线外圈或清晰的蓝色标签边框，不复用风险琥珀色。状态未知显示灰点与“状态未知”。

AREA：相同中心锚点，加半径18—26px、透明度<=.12的光晕。光晕固定为视觉提示，不代表面积、距离或行政边界。

CORRIDOR：至少两个有效节点，按已有顺序连接，默认2px低饱和蓝线，选中3px高对比线；线也能点击。允许轻微平滑曲线，但不额外添加途经点。主标签锚在首节点，节点保持真实地区位置，始终可查看完整地区顺序。显示“线路为涉及地区示意”。缺节点不补坐标。

首版不按投资额或行数改变气泡大小。参考图里的大数字改为业务真实状态；用户以后需要规模编码，再定义统一指标与图例。

### 7.2 白色悬浮标签

标签宽168—208px、高56—72px，内边距10—12px；左侧24px状态图标，右侧项目名最多两行。第二行 / 底部放“已完成 · 待复核 3 项”之类真实数据。缺字段省略该指标，预警没运行显示“预警未运行”，不写“零风险”。标签不显示完整坐标、provider、dictionary version或项目 UUID。

默认标注数：地图宽>=900px最多5张；600—899px最多3张；<600px最多1张。默认优先级：当前选中 → 高风险 → 待复核 → 最近更新 → project_id稳定排序。未常驻标签的项目仍有锚点和列表。选中标签永远优先。

引线1px、低对比蓝灰，最多一个折点；从锚点到标签最近边缘。首选锚点右上，不可用时按右下、左上、左下轮换；长度尽量<=96px。不得穿过其他标签正文。标签可点击，不要让鼠标从锚点移动到标签时立刻消失。

### 7.3 标签避让算法（必须为可测纯函数）

输入：投影后的anchor、测得的标签宽高、优先级、舞台矩形、保留区域。输出：labelRects、leaderPaths、hiddenLabelIds。采用确定性贪心布局即可，不使用长期力导向模拟。

1. 先放选中标签，再按优先级放其他标签。
2. 生成8个候选位置（四对角＋四正向），锚点间隔12px。
3. 依次排除超出舞台安全区、覆盖工具条 / 来源 / 插图、与已放标签加8px外扩框相交的位置。
4. 对可用位置按引线长度、线交叉惩罚评分，取最小值；相同分数固定顺序，不能随机。
5. 全部位置不可用时隐藏非选中标签，保留锚点；选中项目在地图外显示紧凑摘要，不用遮挡其他标签来强行安放。
6. Resize 后重算，选择变化后重算，普通悬停不反复重排全图。DOM测量使用ResizeObserver或字体就绪后测量，避免测量—更新死循环。

同一坐标多个项目显示数量标记“3”，点击打开项目选择列表，选择后详情与标签联动。不对地理位置做随机偏移。项目总数按project_id去重，聚合数与实际项目一致。支持同点、近点、长中文名、20个密集点和500条输入。

## 8. 业务详情与数据共享

展示主题详情顺序：演示 / 真实范围 → 项目名称 → 涉及地区 → 当前状态 / 待复核 / 预警 → 可用的成果入口 → 折叠“位置与来源”。没有Skill或成果可用性字段时先复用现有接口核对，拿不到则隐藏，不写假按钮。

不要改动地理主题的 `ProjectMapDetail` 默认输出；新建展示详情，或显式 variant 且默认仍是原样。确认位置继续调用现有回调，不做新的确认状态机。地图选择不会触发保存。

不在 `ProjectSpatialMap` 内增加 `mapTheme` 分支。`App.tsx` 只增加独立的 `地图展示` 页面宿主：原 `ProjectSpatialMap` 继续只负责地理 L7 页面，`ProjectShowcasePage` 负责展示 SVG 页面。两页都消费 API 返回的 `SpatialMapItem[]`，不得复制一份 DEMO 数组；页面级 scope、filters、selectedProjectId 各自维护，避免新页面的点击或复位动作改写旧页面。

展示页状态按当前会话保存即可；不增加全局配置字段。两个页签分别挂载各自渲染器，切页只控制页面可见性，不把 L7 相机或展示 SVG 状态相互覆盖。展示地图不依赖 `map_ready`（它属于外部 L7 可用性），应根据本地展示资产是否可用单独判断；服务失败时沿用现有真实 / 演示降级边界。

原地理页相机中心 / zoom 如未能从现有组件安全恢复，明确记录这一限制，不能为了保存相机重写 L7。展示页自己的项目选择、筛选和范围必须恢复；不得让展示页的“复位视图”清空自身筛选，也不得改写原页筛选。
