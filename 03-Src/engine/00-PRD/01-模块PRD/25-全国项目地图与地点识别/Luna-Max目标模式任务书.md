### 固定产品行为

1. 顶部二级页签实现为 `项目看板｜全国项目｜新建填价`；不新增左侧一级菜单。
2. 中间容器 `>=1180px` 时地图约 68%、详情约 32%；更窄时地图全宽、详情抽屉。`>=1025px` 其他页面宽屏表现零变化，`<=1024px` 走既有独立窄屏层。
3. `演示项目` 和 `本机项目` 明确切换。8 个演示项目是只读 fixture，所有响应标记 `data_scope=demo`，永不进入项目台账、KPI、问答统计或正式成果。
4. 真实地图只显示 `confirmed` 空间档案；`unlocated / proposed / conflict / rejected` 进入待定位列表。
5. POINT 只含一个节点；AREA 首版用可信行政区中心点和范围光晕；CORRIDOR 至少两个确认节点，按文本顺序画示意线并常驻说明“不代表真实施工走向”。
6. 状态用核心点颜色，风险 / 待复核用外环和文字 / 图标；不能用同一种颜色混淆两套业务语义。
7. 地图和 L7 只在进入全国项目时懒加载；退出时销毁 Scene、监听器、Observer 和请求。地图失败降级为项目地域列表，主业务继续。
8. 上传 `/api/inspect` 同步阶段只做机械识别，返回可选建议，不等待 AI；AI 消歧异步、独立限时，失败转人工。
9. 模型只能从服务器候选 ID 中选择并引用当前文件证据，不能生成坐标、行政代码、边界、价格、系数或任意路径。用户确认前不进入真实地图。
10. 确认时服务器从冻结词典重新读取地点和坐标，以 revision 乐观锁和幂等键保护；后到模型结果不能覆盖用户值。
