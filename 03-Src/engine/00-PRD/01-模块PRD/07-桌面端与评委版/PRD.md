# 运行入口 PRD

## 模块目标

当前维护传统网页开发版，云端按明确任务发布；Tauri 已暂缓归档；Windows 绿色版不再作为默认交付物，仅保留为按需兼容构建资产。

传统开发版用于本机开发调试，依赖本机 Python、Node 和 npm 环境；Windows 绿色版仅在明确要求时用于其他 Windows 电脑兼容运行，随包携带 Python、Node、npm、后端依赖和前端依赖。

**Tauri 路线已于 2026-09-26 暂缓并归档。除非用户明确要求恢复，否则不再构建、维护、升级依赖、同步版本或执行 Tauri 专项验证；日常开发、发布和验收均不包含 Tauri。** 历史资产见 `docs/归档/Tauri-20260926/README.md`。

## 功能边界

- 当前不维护旧静态评委版；网页绿色版不使用桌面壳，Tauri 已归档，不作为当前交付物；绿色版仅按需构建。
- 绿色版只解决 Windows 电脑免安装 Python / Node / npm 的网页运行问题，不重写前端和后端业务逻辑，也不作为默认交付渠道。
- 按需绿色版打包时可以携带 `.env.local`，但不得把 API Key 写死到源码或进入代码存档。
- 启动和导出脚本应避免一闪而过，错误必须可读。
- 统信兼容不得牵动核心匹配引擎、三数字规则、知识库字段、经验池规则和报告生成口径；只处理运行环境、路径、启动脚本、依赖安装和浏览器访问适配。

## 验收口径

- 传统开发版不受影响：本机仍可运行后端 `8000` 和前端 `5174`。
- 按需构建的绿色版双击入口能启动后端和前端，并自动打开浏览器。
- 后端健康检查能返回当前版本。
- 绿色版可以在未安装 Python / Node / npm 的 Windows 电脑上运行。
- 绿色版覆盖上传 Excel、执行匹配、表格预览、下载 Excel、生成 Word 报告、经验池预警、工作量抓取和大模型 Key 配置读取。
- 未配置 DeepSeek API Key 时，主价格匹配、Excel 输出和 Word 报告仍可运行。
