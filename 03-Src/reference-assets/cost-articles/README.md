# Astra 造价知识文章库

2026-10-09：100篇文章、202条人工核对的主题关系；10类各10篇。

- cost-001—050保留冻结来源的原ID、正文、元数据和74条既有关系；校验记录见provenance.json。
- cost-051—100从已有获准AIW资料整理，包含独立阅读要点、核对清单和来源。2005、2012历史资料明确标注版本，不能当作当前默认计价依据。
- manifest.json负责目录和关系；articles/保存完整正文；provenance.json记录原文件SHA256、来源ID、原文范围及核对摘录。
- 由Astra knowledge_host.py配置只读接口的数据根目录，不修改冻结引擎、原工程和现有运行库。
- 用途为文章搜索、阅读和二维／三维知识图谱；不扩大WeKnora授权资料范围，不自动进入RAG索引、记忆或价格裁决。

运行`python tools/validate-article-pack.py`核验文章、原文保留和关系完整性；可用`--sources`指定本机已导入的AIW目录验证来源SHA和摘录，用`--live-url http://127.0.0.1:5189`逐篇核验真实接口。缺少或损坏发布清单时返回模块错误，不回退成旧50篇并伪装成功。
