# 消防与给排水安装的清单定位

第三册第七章将采暖、通风、给排水、消防和燃气安装纳入同一章，定位时仍需按具体设备和系统分节查找。消防水泵接合器、喷头、管道及其他器具的计量单位和主材行可能不同，不能从一项设备的单位推广到整个消防系统。

Excel问答版中，清单行与主材行分别列出。例如水泵接合器安装清单按套计量，并有对应主材用量行；喷头安装则可按个计量，还区分安装条件。阅读时必须连同表头和邻接主材行核对，避免将主材数量误读为安装工程量或将材料单价误读为清单单价。

## 核对要点

- 依据消防、给排水设计分别定位设备、管道和器具。
- 每行记录编码、规格、单位、主材用量及安装条件。
- 核对供货与安装报价边界，检查成套设备包含内容。

本章定位结果应与设计系统图和设备表一致，不能以名称近似代替规格确认。
