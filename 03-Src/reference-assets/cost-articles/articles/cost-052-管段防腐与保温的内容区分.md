# 管段防腐与保温的内容区分

管段防腐与保温服务于不同的设计要求。第一册第四章分列三层PE外防腐、热煨弯管防腐、内减阻涂层以及保温绝热；章节同时给出各项施工内容，不应只依据“涂层”或“保温管”这样的简称套用同一个子目。

三层PE和热煨弯管防腐包含除锈、防腐层制作及检测，内减阻涂层包含除锈、喷涂与检测；保温绝热还包含保温和保护层预制、检测、有关材料以及热缩防水帽安装等内容。章节按防腐保温面展开面积及规定损耗率计算工程量，并将管段防腐、保温列入设备购置费。

## 核对要点

- 按设计区分内外表面、防腐体系、温度等级、保温层及保护层。
- 核对展开面积及章节规定的损耗，不能把管道长度直接作为面积。
- 成品管报价与现场补口补伤分别核对，避免把预制层和现场接头处理重复计列。

规格选择和材料范围以本章说明及设计文件为依据；其他章节的补口规则不能自动替代预制防腐的计量规则。
