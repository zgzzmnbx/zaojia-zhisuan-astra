# 伴行与巡检道路的计量单位

伴行或巡检道路的名称描述用途，计量单位仍由第四册具体清单决定。砂砾石、三合土、混凝土主干道路和沥青混凝土路面等表列项目均需按对应平方米单位核对，而不是按道路条数或公里直接计价。

将设计长度转为面积时，应有宽度与分段范围依据，交叉口、变宽和不同路面类型分别列清。永久征地及临时占地与道路面积虽然都可能以面积记录，但属于不同对象；大型土石方也有单独的排除条款，不能把这些面积或方量并入路面工程量。

## 核对要点

- 分段保存长度、宽度和路面类型，核对单位换算。
- 区分路面面积、用地面积和土石方体积，保留各自来源。
- 与施工便道核对用途和保留条件，不把临时施工设施当作永久道路。

最终工程量以设计和确认的计量范围为准，本篇不从道路名称自动推定宽度。
