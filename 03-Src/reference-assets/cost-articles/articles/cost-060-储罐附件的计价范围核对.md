# 储罐附件的计价范围核对

储罐附件的“安装工作已含”和“附件重量纳入本体重量”不是同一问题。第二册金属储罐章列明人孔、透光孔、排污孔、罐顶及罐壁结合管、阀门、导向管、量油管等附件安装内容，但本体计价重量另有范围规定。

不同罐型的附件和试验内容不同。浮顶储罐还涉及密封装置、浮船或单盘支柱、浮梯以及升降和严密性试验；不锈钢拱顶储罐则有自己的清单内容。若只按“附件”二字拆成独立报价，容易把已综合的安装再次计列。

## 核对要点

- 按罐型建立附件表，标明供货、安装和材料费是否已含。
- 对人孔、接管、阀门与消防喷淋分别查本章和对应专业章节。
- 核对附件是否计入本体重量，不能用重量排除条款推断安装工作排除。

成品附件与现场制作附件应依设计和采购合同区别核对，最终计列需保留分项依据。
