# 金属结构制作安装的工作内容

第三册第二章为金属结构制作安装的定位入口。工程量核对不能只使用设备总重或整个站场的钢材采购量，应先划清钢结构、支架及其他金属构件的实际对象，再查制作安装的分节和单位。

第二章明确金属结构防腐、防火不在包含范围，高强螺栓连接管廊和设备框架中的高强螺栓主材费也不包含。工艺金属结构以吨计量，低温保冷成品管道支架按公称直径以个计量；防腐、防火涂装另查第八章，不能只看到结构安装完成就认定涂装已含。

## 核对要点

- 以设计构件表对应制作、组对安装与成品安装的工作对象。
- 分开核对构件重量、表面处理面积及涂层要求。
- 对支架、平台和钢结构逐项查包含说明，不按材料名称统一套项。

本篇提供查找顺序；具体是否另计仍以所选清单的完整工作内容和章说明为准。
