# 国内设备运杂费的费用内容

2024其他费用依据第二十五条说明，国内设备运杂费包括从制造厂至施工现场的运输、装卸、包装、采购管理、保管、港口建设及运输保险等，明确不包括超限设备运输特殊措施费。

一般国内设备按出厂价和地区费率计算，但油气输送管道管段另按制造厂至中转库的实际运输情况核对。采购管理费还有以采购合同不含税金额为基数、超额累进计算的规定，不能把设备运杂、主材运杂和采购管理的表格互换。

## 核对要点

- 核对出厂价、交货地点及合同已含运输保险等范围。
- 对管段记录工厂、中转库和现场之间的区段，防止与运输清单重叠。
- 将超限特殊措施单独核查，不因一般运杂费已列就认定已包含。

地区费率及采购基数应以对应版本和真实合同为依据，不沿用同类项目的最终比例。
