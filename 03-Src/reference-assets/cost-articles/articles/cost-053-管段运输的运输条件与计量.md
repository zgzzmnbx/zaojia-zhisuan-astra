# 管段运输的运输条件与计量

管段运输应先划清运输区段，再选择对应清单。第一册第五章与储气库注采管道安装章均包含运输内容，但两章的工程对象、分档方式和包含条件并不完全相同，不能仅因名称相近就共用一套规则。

第五章表中，防腐管段场外运输按管径划分并以公里计量；热煨和冷弯弯管运输则可按管径档次以个计量，工作内容包含准备、吊装、运输、卸车和返回。储气库章节另有按管径、壁厚及运距划分的钢质防腐或保温管段运输清单，包含条件应在该章内确认。

## 核对要点

- 记录运输起止点、运输对象和数量，区分工厂至中转库及后续场外运输。
- 逐行核对公里、个等单位以及运距增减清单，不将运距与管道工程量混淆。
- 管件及保温层影响是否已经综合，依所选章说明核对，不跨章推断。

运杂费、管段运输和施工运布管应分别建立范围对照，再检查合同或采购价中的重叠部分。
