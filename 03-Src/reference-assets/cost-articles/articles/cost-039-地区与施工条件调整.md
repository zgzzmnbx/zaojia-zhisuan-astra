# 地区与施工条件调整怎样核对

油气输送管道工程的计价可能受到地区、季节、地形和施工条件影响。查阅相关说明时，先确定项目所在地、施工时段、地貌条件和作业环境，再看依据是否给出了调整范围和使用前提。项目有调整条件，不代表所有费用都能按同一比例处理。

第一册对部分区域和冬季施工情况给出相应说明，章节中的标准条件也可能影响调整。读者要确认调整对应的工程内容、清单范围和计量基础。若条件只影响某一类工序，就不能把它扩展到整个项目或全部专业。

施工方案、线路走向、气象资料和地形资料可以帮助判断条件是否成立。资料缺失时，应把条件判断列为待复核事项。特殊地区、冻土、山地或运输困难等情况，还要检查是否已有专门条款或参考依据。

调整记录应写明条件、适用章节、计算基础、调整范围和来源。若不同依据给出不同口径，应保留差异并由人工确认，不要用相似项目的比例直接替代。调整后的结果还要与清单说明和工程量取定保持一致。

本文只提供条件核对顺序。实际调整须以当前有效规定、项目资料和专业复核为准。

条件调整还应与受影响的清单行和工程量对应。若同一项目同时存在普通地段和特殊地段，应按实际范围拆分，不能把局部条件平均到所有工程量上。

调整记录还应注明资料日期和确认人员。
