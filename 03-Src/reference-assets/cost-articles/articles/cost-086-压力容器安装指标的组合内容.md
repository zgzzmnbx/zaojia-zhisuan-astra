# 压力容器安装指标的组合内容

2005概算指标的静置设备安装章区分整体安装与分段分片组对。指标包含设备本体安装和基础二次灌浆，特定容器或塔类组对还含胎具、加固、焊缝热处理、检测及试验等列明内容。

与此同时，未包括内容列出压力容器安装检验费，以及除特殊说明外的有关试验、防腐绝热、设备本体法兰以外管道和非自带附件等。阅读时应先看具体子目的特殊包括条款，再看一般排除项，不能把所有设备安装都认定为含相同试验。

## 核对要点

- 区分设备整体吊装、分段分片组对及相关检验对象。
- 保存设备材质、重量和附件归属，对照指标选项。
- 压力容器安装检验费与施工焊缝检测分别核对，不因名称接近合并。

本篇对应2005指标阅读；实际项目是否适用及后续版本变化须另行确认，不作为当前默认价格依据。
