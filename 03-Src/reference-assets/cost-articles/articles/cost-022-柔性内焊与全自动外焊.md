# 柔性内焊与全自动外焊怎样分清工作内容

柔性内焊和全自动外焊属于管道组装焊接中容易混淆的施工方法。阅读相关依据时，先确认焊口位置、焊接设备、施工顺序和适用管径，再判断清单工作内容。只看焊接方法名称，容易漏掉组对、调整和辅助作业。

第五册参考依据对这类工艺提供了补充阅读入口。柔性内焊关注管内焊接设备或工艺条件，全自动外焊关注管外自动化设备和焊接过程。两者可能服务同一条管线，却不等于可以把两个条目任意相加，也不等于所有焊口都按同一方法计价。

查找时应结合施工组织设计、焊接工艺评定和焊口统计表。资料需要说明内焊或外焊的实际范围，哪些焊口采用人工方法，哪些焊口使用自动化设备，还要确认是否包含焊前准备、焊后处理和检验配合。

若项目使用的组合方式与参考依据不同，应把清单特征和参考条目的差异写清楚。对于清单中未表达的配合工作，应回到章节说明核对，必要时设置补充清单。补充清单要保留工序边界和工程量单位，避免同一工作在不同条目重复计算。

这类条目适合用于专业工作定位和人工比对。最终选择仍以项目实际施工方法和适用依据为准，不能由相似词语自动决定价格。

焊口统计还应与施工段划分、焊接工艺文件和设备配置互相核对。若同一管段采用多种方法，应按焊口范围分别记录，避免把参考条目的全部工作误套到每一个焊口。
