# 消防安装指标的范围核对

消防安装指标应与储罐本体指标分开核对。2005资料明确金属罐和气柜指标不包括空气泡沫产生器、喷淋与消防装置的制作安装；给排水等章节另描述水灭火、气体灭火、泡沫系统及消防器具。

油罐空气泡沫产生器子目具有自己的组合范围，包括泡沫器、过滤器、金属软管，以及列明的立管、管件、支架和接口等；金属软管之前水平管道及管支墩另计。不同器具的材料费是否已含，还需结合具体说明确认。

## 核对要点

- 依据消防设计确认系统类型、器具和安装方式。
- 将储罐本体、泡沫器及连接管道划清范围，保存接口位置。
- 对器具数量和主材费查对应条文，不按每座罐统一推定数量。

该篇只解释2005指标的范围，不能据此改变消防设计或直接决定当前项目费用。
