# 架构看护与第三方咨询费用

架构看护与第三方咨询均列入数字项目建设管理费用，但服务对象和计算方法不同。2024依据将架构看护分为业务、数据、应用和技术架构，依项目复杂程度按工程费相应比例计取，不开展时不计取。

第三方咨询则针对管理制度梳理、授权事项提炼和流程评估等，按人天工作量与人员基准价计算。它不能仅因项目设有架构看护就同步增加，也不能用同一个比例替代工作量。两种服务须各自明确成果和任务边界。

## 核对要点

- 分别核对架构看护技术要求与第三方咨询任务书。
- 架构看护保存复杂程度和基数依据，咨询保存人员类别及人天。
- 与软件开发和实施服务检查成果范围，避免同一活动重复计列。

确认没有开展的服务应按原文不计取，不能把表中费用名称视为每个项目的必选项。
