# 五册全费用清单单价怎样形成查找地图

2024全费用清单单价资料按五册组织。第一册是油气输送管道工程，第二册是储罐制作安装工程，第三册是通用安装工程，第四册是其他工程，第五册是参考计价依据。读者先按工程对象确定册，再按施工内容进入章节，可以减少在大表中反复搜索。

第一册主要处理输送管道线路和相关工序，第二册聚焦储罐制作安装，第三册覆盖设备、管道、仪表、电气和防腐保温等通用安装专业。第四册收纳通信、道路、智能化、内检测和中转站等其他内容。第五册用于补充和比对参考条目。

一个场站项目往往跨越多个册。设备可能进入第三册，储罐进入第二册，道路和通信进入第四册，管道主体工作进入第一册。划分时应以清单对象和工作内容为依据，不能按项目地点把全部工作归入同一册。

册与册之间可以互相提供线索，但每个条目的包含范围仍要独立核对。使用第五册参考条目时，要记录它与主册条目的关系和适用差异。跨册查找后的结论，应回到设计文件、施工方案和计量单位复核。

这张查找地图能帮助定位资料，不替代具体清单的专业判断。正式编制仍须按当前有效依据和项目条件执行。

实际查找可以先建立项目对象清单，再把每个对象映射到册和章节。映射完成后仍要检查跨册接口、清单单位和说明范围，避免目录定位正确却漏掉配套工作。
