# 数字项目硬件费用的组成

2024数字与信息化依据将硬件费用分为设备购置费和资源租赁费。服务器、存储、网络、安全等设备购置费用包含设备价格及相应安装调试、材料和运杂等；资源租赁对应建设期所需硬件、云服务和云平台资源。

两类费用可参考指导价格、同类工程历史采购价及市场询价综合确定。报价核对时，需辨明购置或租赁、配置和服务期限，并检查设备价格已经包含的安装、运输等内容，不能把这些内容再作为实施费用重复列入。

## 核对要点

- 保存设备配置、数量、租赁期限和计价单位。
- 标注询价、历史采购价及指导价的来源和日期，检查可比条件。
- 将建设期资源与长期运营资源分开，核对含税与不含税口径。

相同“云资源”名称不能替代容量、使用时长和服务等级，缺少规格时应先补齐采购需求。
