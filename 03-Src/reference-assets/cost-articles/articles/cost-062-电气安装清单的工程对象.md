# 电气安装清单的工程对象

第三册第五章是电气安装工程的主要入口。专业名称并不总能决定计价章节：自动化控制仪表安装中的电气设备和元件、电缆保护管、电缆沟土方及铺砂、电缆敷设、桥架和防雷接地等，章说明明确转执行第五章相应清单。

因此，仪表系统报价中的电缆、接地或桥架应先核对是否属于该跨章范围，再与电气设计材料表对齐。系统设备安装、电气连接和系统调试需要依据各自子目确认，不能把同一段电缆同时在仪表和电气两份清单中计列。

## 核对要点

- 核对电气设备规格及清单对应单位，不以系统总价代替分项对象。
- 标明跨仪表、电气章节的电缆、桥架和接地项目。
- 将设备供货、安装及调试范围与合同和章节说明逐项对应。

跨章引用属于原资料的明确规定，不是将所有仪表工作都转为电气安装；未列明的对象仍需核对原章节。
