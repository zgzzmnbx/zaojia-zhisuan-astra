# 安全生产费的清单表达

2024清单中的安全生产费同时具有费用定义和单价构成位置。总说明将其解释为用于完善和改进安全生产条件的资金，并说明清单单价已按相关规定综合计取；表中安全生产费通常位于“其中”栏。

核对报价时，应先看是否使用该不含税全费用综合单价，再检查安全生产费在表格和汇总表中的呈现。把单价中的安全生产费当成外加费用，会使同一金额被计算两次。不同表格的列标题可能分行显示，需要连同上一行表头核对物理列位置。

## 核对要点

- 保存清单编码、综合单价与安全生产费分项的对应关系。
- 检查汇总公式是否已包含该分项，区分展示金额与追加金额。
- 原表空白或转换异常时标记待核对，不自动生成费率或金额。

安全生产费与某项具体安全措施的工作内容还需分别核对，不能仅凭费用名称判断措施是否已含。
