# 管道穿跨越清单选用

第一册第七章覆盖穿跨越管段组装焊接、铁路穿越安装就位、公路和河流穿越、定向钻、交叉穿越及管道跨越等工程对象。“穿越”只是上位名称，实际清单还取决于设计方案和施工方法。

例如，铁路穿越安装就位区分顶箱涵与顶管，开挖公路穿越区分不带套管、钢套管和混凝土套管；隧道内组装焊接与一般穿跨越组装焊接的工作内容也分别列出。选项前应将穿越位置、套管形式、管径壁厚及焊接方式与章节分节逐一对应。

## 核对要点

- 按审批设计和施工方案确定穿越方式，不以道路或河流名称代替方法。
- 对照管段焊接与安装就位的包含内容，避免同一工序重复套项。
- 将管线交叉穿越、隧道内安装和定向钻分别定位到实际分节。

本章用于核对清单适用范围，不能从名称自动生成未经确认的施工方案或工程量。
