# 概算指标中的费用组成怎样看

概算指标用于投资估算或设计阶段的快速测算，读者不能把它当成施工阶段的逐项清单。查阅2005石油建设安装工程概算指标说明时，先确认指标对象、适用工程、计量单位和费用组成，再判断它能否服务当前阶段的测算。

指标通常以单位工程量或工程对象表达综合消耗，可能包含人工、材料、机械、管理和其他相关内容，也可能明确列出未包含的费用。不同章节的说明不一定完全相同，设备、储罐、工艺管道和辅助工程都要分别阅读目录和编制说明。

使用指标时，工程规模、结构形式、设备条件、地区和施工条件都会影响可比性。当前项目若与指标的标准条件不同，应把差异列出，再按说明采用允许的调整方法。没有明确调整依据时，不要把指标结果直接当成控制价或结算价。

复核结果应记录指标名称、单位工程量、适用条件、包含内容和调整依据。概算阶段的数据还可能随着设计深化变化，后续应回到新的设计文件重新测算，而不是长期沿用初始结果。

本文用于说明指标的阅读边界。具体投资金额须结合当前有效依据、项目资料和专业复核确定。

使用指标时还要记录编制阶段和设计深度。指标适合支持早期测算，设计条件明确后，应逐步用设备表、工程量表和合同资料替换概略参数，保持不同阶段结果各有依据。
