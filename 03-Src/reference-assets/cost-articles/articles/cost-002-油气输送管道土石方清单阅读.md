# 油气输送管道土石方清单怎样阅读

第一册土石方工程把作业带扫线、作业带土石方、管沟土石方、土石方运输和恢复地貌放在同一章。它们对应施工过程中的不同对象，清单名称相近时，读者应先看工作范围，再看计量单位和章节说明，不能只按土方两个字判断。

作业带扫线包括一定范围内的场地平整和零星附着物清理。作业带土方、淤泥和石方分别组合了相应的挖掘、推运或破碎工作。管沟项目还区分开挖、筛细土、回填和运输，恢复地貌又按水田、旱田和荒地区分。每一种区分都对应不同的工程条件。

资料同时列出若干不包括内容。渣土外运、爆破时的安全防护措施、爆破物资的运输保管以及细土采购和运输，都不能因为出现在施工现场就直接并入同一项清单单价。编制时应把这些内容与主项的包含范围逐项对照。

使用作业带土石方清单时，还要注意重复计算。已经计算作业带开拓土石方的线路段，不再计算作业带扫线费用。冬季施工增加费也有专门条件，资料给出了相关比例，但冻土开挖和冻土破碎不按这一条简单处理。

工程量计算涉及管径、土石质类别和取定标准。标准范围内的工程量与超过部分有不同调整方法，超过部分还区分土方和石方。实际项目应回到原表和章节说明核对，不能把一个管径或一个地区的取定量直接搬到别的项目。
