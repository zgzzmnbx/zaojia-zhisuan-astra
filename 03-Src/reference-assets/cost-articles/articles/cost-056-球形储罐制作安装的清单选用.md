# 球形储罐制作安装的清单选用

第二册第三章的金属球形储罐清单适用于球罐组对安装，选用条件包括容量和球皮厚度。工程量按设计图纸中的球壳板、支柱、拉杆、接管、加强板及人孔等重量核对，附属梯子、栏杆和扶手另对照第三册。

本章包含球罐组装、立柱组对、规定试验、焊缝预热和热处理、检测、整体热处理、防护棚及组装平台和胎具等内容。它不包括附属梯平栏、消防装置、加热器以及防腐保温、脱脂、防火和防雷接地等列明内容，不能按“球罐安装”名称把全部专业工作都视为已含。

## 核对要点

- 核对容量、球皮厚度、材质及设计重量范围。
- 同容量多座连续交替试压与单座试压分别核对章说明。
- 本体、附属结构、消防和防腐保温建立分项包含表。

低温钢调整有专门条件，应在确认材质后按原条文处理，不扩展到其他储罐类型。
