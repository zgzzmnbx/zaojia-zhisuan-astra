# 生产与安装同时进行的降效调整

安装与生产同时进行的降效费有特定条件。2024清单总说明针对部分改建项目，考虑施工效率降低因素给出降效口径，并明确油气输送管道工程、采取硬隔离措施的LNG低温储罐及金属储罐工程不计取。

“改建项目”或“生产区域内施工”本身并不足以确认降效，需核对安装与生产同时进行的实际安排，以及是否采用硬隔离等措施。经确认适用后，仍应依总说明调整公式与其他调整项衔接，而非直接改写基础清单价格。

## 核对要点

- 保存生产与施工同时进行的方案和时间范围。
- 核对工程类型及隔离措施，排除原文明确不计取的项目。
- 将降效、特殊地区和估概算幅度差分开记录，再按原公式计算。

安全措施投入与生产降效属于不同核对事项，不能以一项费用替代另一项的适用证据。
