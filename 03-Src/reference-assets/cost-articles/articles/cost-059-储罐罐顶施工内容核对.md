# 储罐罐顶施工内容核对

“罐顶”在不同储罐中可能指拱顶板、浮顶、铝吊顶或吊顶吊杆，不能以同一名称套用相同计量方式。第二册对低温储罐本体、铝吊顶、罐内金属结构与吊杆、接管分别给出计量规则。

低温储罐内外罐、铝吊顶及罐内金属结构按吨计量；不锈钢吊顶吊杆和有关罐顶接管按储罐容积，以座计量。金属拱顶罐、浮顶罐的重量范围则将罐顶板或浮顶与罐底、罐壁及加强构件一起核对，并有相应的容量和重量表。

## 核对要点

- 先确定罐型和部件名称，分开列出顶板、吊顶、吊杆与接管。
- 核对吨与座的对应对象，不以部件数量直接替代整座储罐的计量。
- 查清主材另计条件和本体安装包含范围，避免在综合供货价上重复增加。

罐顶施工方案、罐顶重量和附属接管费用应各自留存出处，不能互相代替。
