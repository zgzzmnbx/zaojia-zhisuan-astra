# 高原施工增加费的条件核对

特殊地区施工增加费应从工程所在地条件和适用项目开始核对。2024清单总说明的表1区分高原海拔档次，并分别列场站与输送管道系数，不能只根据行政区域名称判断高原条件。

总说明指出，表1调整系数除高原特殊地区外不累加计算，场站工程只计取高原特殊地区施工增加费。阅读时还应检查总说明前述适用范围及排除项，避免把一个地区系数推广到工厂加工或其他不适用内容。

## 核对要点

- 保存工程平均海拔及来源，按原表档次核对边界值。
- 区分场站和输送管道，并核对拟调整清单是否适用。
- 将特殊地区增加费与地区差异调整分别记录，按原公式组合。

气候或地形描述不能代替海拔证据；跨区域工程应明确分段依据，未核实前不自动调整价格。
