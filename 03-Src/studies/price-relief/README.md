# 价格匹配 · 三层浅浮雕

独立 demo **v1.0.0** · 2026-10-17。正式价格匹配窗口保持原样。

- 入口：`http://127.0.0.1:5189/price-relief-study/`
- Three.js 真三维浅浮雕，React DOM 文字/按钮始终正向；未使用 React Flow / xyflow。
- 三层台面：清单条件 → 候选依据 → 填写结果。点击候选切换来源/逐项差异；点击条件集中高亮关系，蓝色一致、棕色差异。
- 固定正交镜头；展开层次、亮暗预览；一次6秒的匹配说明，阶段文字明确为演示。停止/后台取消播放，空闲停止 RAF，减少动效下不移动光点、层次立即切换。
- 模拟填写经原生 dialog 确认，仅更新本页状态。切换候选撤销演示结果，不读写业务接口、任务、工作簿或 localStorage。
- 6条候选来自已有二维研究页的截图摘录；一致比例按4个示例要素比对，不是价格正确概率。经验样本独立展示，不参与要素相似度。未调用模型。

## 构建

项目根目录运行 `node tools/build-price-relief.mjs`，生成 `public/price-relief-study/`；随后 `npm run build` 将独立页复制进正式静态输出。依赖沿用项目已有 React / Three.js，按钮与弹窗复用本地 daisyUI。

## 验收

浏览器核对全部一致、1项差异、2项差异；来源行随候选变化；确认前保持尚未填写，确认后更新演示结果；展开/收拢、深色、停止说明与自动停止；最终控制台无错误。测试、构建与验收记录见 `Codex-Temp/price-relief-*`。

## 后续接入边界

当前是独立交互概念，没有接入正式 row-assist 数据或填写动作。需要采用后再复用真实候选、要素、来源与原有确认门禁；不能把示例数据作为业务结果。
