# H1 白瓷办公室查看器

Astra 工作台的 **多人复核** 打开本目录的 index.html。release.js 记录查看器协议与展示模型版本，模型、布局和预览图由本地发布包提供。九楼的房间、工位和家具锚点采用原始布局。

整楼总览中，两座楼顶分别显示 **H1 天津运营中心** 和 **H3 天津运营中心**。楼名沿各自正立面的屋檐方向竖立，绕楼可看见侧面，背面也可正读。展开九楼时楼名收起，返回整楼时恢复。

项目员工配置提供人员、工位和外观，宿主提供成果、人选权限、选择与回执。直接打开查看器时展示已保存的项目员工。画面设置与主题蓝保存在当前浏览器。[白瓷模型与操作](../../../tools/office-twin/porcelain/README.md)
