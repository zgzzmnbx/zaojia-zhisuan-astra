Console sampler currently uses the minimum interval, matching the designated source rather than claiming parity with the upstream reference website's random blink behavior.

Intermittent look: original 12-second cycle with a resting pause, smooth turn, short hold and return; five source target directions. It is a deterministic varied schedule, not fabricated random robot behavior.

Astra addition: welcome-page mouse input smoothly blends head orientation through the same geometry renderer, with no additional RAF and no hardware/network connection. Busy/reaction states keep priority. Astra does not use CSS scaling or tilting as a substitute for these expressions.

User playback preference (2026-10-06): the Astra renderer copy adds only an explicit forceMotion option to the reduced-motion guard. This application always enables it for animated visible Gork instances. The original geometry, poses, timing, idle schedule and blink calculations remain unchanged.
