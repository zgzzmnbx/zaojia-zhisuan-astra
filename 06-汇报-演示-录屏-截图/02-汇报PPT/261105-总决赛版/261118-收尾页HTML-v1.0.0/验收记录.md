# 收尾页 v1.0.0 验收

日期：2026-11-18。执行环境：本机 Windows、Playwright Chromium；适用范围为独立 HTML 及隔离的同源 iframe 宿主。

| 项目 | 结果 |
| --- | --- |
| 原第四页读取 | 从 PPT XML 提取媒体与文字，以 PowerPoint 1920×1080 导出核对实际可见页 |
| 讲稿对应 | 【P4】自主研发、经验复用、更多业务和第一公里收尾落实；团队名取【P1】 |
| 三版本实渲 | 1920×1080 完整检查，所有内嵌图片正常加载，标题和底部流程无截断 |
| 视觉修正 | 修正星轨版说明与经验链路重叠；统一控制按钮为16px并修正浅色版对比度，复检通过 |
| 其他桌面尺寸 | 1440×900、1366×768、1280×800 的 iframe 缩放、边界、无滚动溢出检查通过 |
| 实际控件 | 三版本播放、暂停、重播均通过；补测空格、R、全屏按钮通过 |
| 嵌入接口 | 本地独立 HTTP 服务器同源 iframe 的 seek / set-visible / dispose 验证通过 |
| 暂停与停算 | 暂停和宿主隐藏后时间与绘制计数不增加；恢复继续；dispose 后停止 |
| 消息边界 | 非可信 origin 的控制消息被忽略；仅接受父窗口同源 HTTP(S) 消息 |
| 减少动效 | 三版本模拟 prefers-reduced-motion: reduce，文字完全可见，无动画循环 |
| 网络与错误 | 本轮零外部请求、零 JavaScript 页面错误 |
| 视觉规则检查 | 三版本 design_lint 通过，无红灯及模板装饰警告 |
| 静态附件 | 各导出一张 JPG 和一页 PDF；PDF 页数及文本层检查通过 |

采用 modern-web-guidance 的 `motion` 指引：入场只改变 opacity / transform，提供可键盘操作的暂停；减少动效时显示最终内容。对应规则为“Provide a pause mechanism”和“Keep the final state”。背景画布约30 FPS、设备像素比上限1.5，隐藏停算，不以测试设备结果承诺其他设备帧率。

本次没有修改应用业务程序、原 PPT、原讲稿或正式服务。未进行正式宿主发布、真实业务验收、投影设备和其他浏览器实测；正式嵌入仍须确认菜单入口、服务 CSP、面板状态联动与宿主回归。

过程脚本、原页导出和详细检查 JSON 位于项目 `Codex-Temp/closing-page-20261118/`，不属于展示运行依赖。
