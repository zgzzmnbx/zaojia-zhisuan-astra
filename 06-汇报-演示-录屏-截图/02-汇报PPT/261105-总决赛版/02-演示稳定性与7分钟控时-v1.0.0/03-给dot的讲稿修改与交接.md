## 3. 按领导建议落到稿子上

以下依据用户版本总表中的既有领导建议整理，不冒充本轮重新听完领导录音的逐字结论。

- **一例讲透**：以清单、匹配、异常依据、复核责任串起主线；不要平均分配给全部菜单。
- **少解释布局**：删“左边是什么、右边是什么、点击哪里都可以”等重复指路，把时间留给价格为什么取这个数。
- **风险可核对**：让评委看到原值、参考值、单位及定位。高风险和低风险都是提示，不等于自动判错。
- **硬件有业务原因**：完成或待复核时提醒一次。删“为什么没播报”和临时排障，不为了秀设备反复发指令。
- **扩展有取舍**：看板、知识图谱和NESMA短展示；模式切换、第二渠道及重新提问放答辩备用。

## 4. 计时与素材交接

请使用《02-7分钟系统演示流程与控时卡》的结束点。等待和口述重叠计时，例如匹配16秒期间讲15秒，不能再额外追加15秒。报告生成及预览共约21–25秒，提前打开能减少连续静默。

配套实测：导入8–11秒、转换6–7秒、匹配13–16秒、风险约14秒、Word预览10–11秒、看板热开约9秒。仅为本轮隔离副本观察，非手机热点实测和性能上限。

建议PPT四页继续采用“作品/场景、业务痛点、方法与演示入口、可核验价值”结构；视频位保持明确占位，实际素材验收后再替换。不要为了填满页面把尚未验证的数字或假回执写进去。

需要收齐的比赛素材：同版本同样例预跑任务、对应Excel/Word、一个主渠道实收及回执、可离线播放的本机录像。每件素材记录任务ID、成果版本、制作日期、实际验证人。当前本轮已交付的是测试记录、操作时间表和修改意见，未新制这些外部闭环录像。

正式程序暂不修改。本轮意见先落实到讲稿、操作顺序和素材选择；若后续决定修复报告模板等程序问题，先在副本验证，再由用户决定正式替换，不在赛前混入未经验收的新功能。
